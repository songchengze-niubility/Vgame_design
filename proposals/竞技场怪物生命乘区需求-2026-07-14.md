# Proposal: 竞技场怪物生命乘区需求

**提案编号:** PROP-20260714-ARENA-HP-MULTIPLIER  
**日期:** 2026-07-14  
**作者:** 策划  
**状态:** 草案  
**相关 Design:** [竞技场 Design Doc](../design/竞技场Design%20Doc.md)

## 1. 背景与目标

当前竞技场怪物生命主要由双方角色平均生命决定。后期角色的暴击、暴击伤害、各类伤害增加、攻速、冷却和能量回复成长不会同步抬升怪物生命，导致怪物清理速度随养成乘区成长而显著变快。

本需求仅新增一个**怪物生命修正系数 `K`**：

```text
最终怪物生命 = 当前怪物生命 × K
```

不调整怪物攻击、防御、基地生命、炮台伤害或原有怪物类型倍率。

## 2. 影响范围

| 模块/表/skill | 影响 | 说明 |
|---|---|---|
| 竞技场 PVPVE 战斗初始化 | 需要 | 在怪物属性生成前汇总双方上阵角色属性并计算 `K`。 |
| `PVPVEData` | 需要 | 当前仅携带平均生命、攻击、护甲及炮台属性；需要补充本需求所列的平均乘区输入，或直接补充已计算的 `K`。 |
| `ArenaMonsterMultiplier.xlsx` | 不需要 | 保持当前怪物类型 HP 倍率；`K` 在其后叠加。 |
| 基地 / 炮台 | 不需要 | 不改变既有基地与炮台数值逻辑。 |

## 3. 落地方案

### 3.1 属性汇总口径

对本局双方所有实际上阵且有效的角色，分别汇总下列属性后取平均值；双方角色数不一致时，按实际有效角色数平均。

```text
平均属性 X = (A 方所有有效上阵角色 X 之和 + B 方所有有效上阵角色 X 之和)
            ÷ (A 方有效角色数 + B 方有效角色数)
```

百分比类属性使用小数：`20% = 0.2`；暴击伤害使用倍率：`150% = 1.5`。

| 需求变量 | 含义 |
|---|---|
| `暴击率` | 双方有效上阵角色的平均暴击率。 |
| `暴击伤害倍率` | 双方有效上阵角色的平均暴击伤害倍率。 |
| `伤害增加` | 双方有效上阵角色的平均通用伤害增加。 |
| `物理伤害增加` / `魔法伤害增加` | 双方有效上阵角色的平均对应属性。 |
| `普攻伤害增加` | 双方有效上阵角色的平均普攻伤害增加。 |
| `必杀伤害增加` | 双方有效上阵角色的平均必杀伤害增加。 |
| `攻速加成` | 双方有效上阵角色的平均攻速加成。 |
| `冷却加成` | 双方有效上阵角色的平均冷却加成。 |
| `能量回复加成` | 双方有效上阵角色的平均能量回复加成。 |

### 3.2 生命乘区公式

```text
K = 暴击乘区 × 增伤乘区 × 攻速乘区 × 技能乘区 × 能量回复乘区

暴击乘区
= 1 + 暴击率 × (暴击伤害倍率 - 1)

增伤乘区
= 1
+ 伤害增加
+ 0.5 × (物理伤害增加 + 魔法伤害增加)
+ 0.4 × 普攻伤害增加
+ 0.3 × 必杀伤害增加
+ 0.3 × 普攻伤害增加

攻速乘区
= 1 + 0.4 × 攻速加成

技能乘区
= 1 + 0.3 × [1 ÷ (1 - 冷却加成) - 1]

能量回复乘区
= 1 + 0.3 × 能量回复加成

最终怪物生命
= 当前怪物生命 × K
```

### 3.3 计算时机与叠加顺序

1. 战斗初始化时，使用本局双方的上阵阵容计算一次 `K`。
2. 整局战斗复用该 `K`；不因战斗内临时 Buff、击杀、炮台升级或角色死亡重新计算。
3. 先按现有逻辑计算怪物基础生命与 `ArenaMonsterMultiplier` 中的怪物类型 HP 倍率。
4. 在最终怪物生命写入属性前乘以 `K`。

### 3.4 未纳入范围

- 无视防御 / 护甲穿透。
- 战斗内临时增伤、临时攻速、条件触发回能、概率刷新冷却等动态效果。
- 怪物攻击、防御、基地、炮台和胜负结算规则。

### 3.5 待确认项

增伤乘区当前包含两次“`0.3 × 普攻伤害增加`”。本需求按已确认公式原样实现；若第二项实际应为“技能伤害增加”，需要在实现前由数值确认后更新本提案与 Design Doc。

### 3.6 验证方式

| 场景 | 输入 | 预期 |
|---|---|---|
| 无乘区 | 所有加成 = 0，暴击伤害倍率 = 1 | `K = 1`，怪物生命不变。 |
| 仅暴击 | 暴击率 = 0.5，暴击伤害倍率 = 2，其余为 0 | 暴击乘区 = 1.5，`K = 1.5`。 |
| 仅冷却 | 冷却加成 = 0.2，其余为 0，暴击伤害倍率 = 1 | 技能乘区 = 1.075，`K = 1.075`。 |
| 两侧均值 | A、B 双方属性不同 | 使用全部有效上阵角色的合计除以总有效角色数，不按高/低战力取值。 |

## 4. 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| 公式中重复的普攻伤害项与预期不一致 | 中 | 中 | 实现前确认第二项的字段语义。 |
| 冷却加成达到或超过 1 | 低 | 高 | 计算前校验 `冷却加成 < 1`；异常值拒绝进入公式并输出错误日志。 |
| 属性字段不在当前 PVPVE 初始化数据中 | 高 | 中 | 明确由战斗初始化补传平均属性或在服务端预计算 `K`。 |

## 5. 验收标准

- [ ] `K` 仅由双方有效上阵角色的平均乘区属性计算。
- [ ] 所有公式与本提案 3.2 完全一致。
- [ ] `K` 仅修正怪物生命，不影响怪物攻击、防御、基地或炮台。
- [ ] `K` 在单局初始化后保持不变。
- [ ] 3.6 的四个验证场景均通过。
- [ ] `冷却加成 >= 1` 不会产生除零或负值异常。

## 6. 评审意见

- 待数值确认：增伤乘区中第二个 `0.3 × 普攻伤害增加` 是否需要替换为技能伤害增加。
