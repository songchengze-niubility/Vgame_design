## 0. 阅读约定与来源标签

| provenance / 状态 | 含义 |
|---|---|
| `SOURCE_EXPLICIT` | 来自 `01_源表` 全局事实、`03_沉淀MD` 单系统参数公式裁决、正式决议等原文明示内容 |
| `WORKING_COPY_OBSERVED` | 本机 SVN 工作副本中观察到的表/代码/资源；不证明 LIVE |
| `CROSS_SOURCE_SYNTHESIS` | 多源归纳；需评审确认 |
| `VERIFIED_MIRROR_NOT_LIVE_PROOF` | 06_最终配置镜像已生成并验算通过，但未经用户批准写 SVN Datas，不构成 LIVE 证明 |
| `DESIGN_PROPOSAL` | 候选方案，非既有事实 |
| `UNKNOWN` | 无法可靠判断 |
| `P0_CONFLICT` | 双权威/多源冲突，需裁决 |

**核心原则**（`框架v2/README.md`，`SOURCE_EXPLICIT`）：
- 全局事实回到 `01_源表`，系统参数与公式沉淀在 `03_沉淀MD`，最终 Excel 全量派生，参数 Excel 退出正式链路。
- `04_数值文档` 是派生交付物，**不是参数源**。
- `06_最终配置/` 保存可评审的业务配置镜像，**不是正式 SVN Datas**，未经用户批准不得同步 SVN。
- 稳定参数 ID：`<参数域>/<Sheet>!<Cell>`。

**权威链**（`30-数值框架.md §3`，`SOURCE_EXPLICIT`）：
```
01_源表（全局事实） → 03_沉淀MD（单系统参数/公式/裁决） → 生成器与工作区 → 04_数值文档（派生交付） → 05_验算核算（动态门禁） → 06_最终配置（评审镜像） → 用户批准批次 → 正式 Datas/Luban/回执
```
