## 定位

本文档维护 Vgame 各功能/内容的发布状态。作为版本追踪的真实记录，需要从项目证据持续更新。

## 状态定义

| 状态 | 英文 | 说明 |
|---|---|---|
| 规划中 | PLAN | 已确认要做，未开始开发 |
| 开发中 | DEV | 正在开发，配置/代码进行中 |
| 内测中 | INTERNAL_TEST | 开发完成，内部测试验证 |
| 灰度中 | GRAY | 部分用户可见，观测指标 |
| 已上线 | LIVE | 全量玩家可用 |
| 上线状态未知 | UNKNOWN_LIVE | 仅在当前工作副本观察到配置或代码，缺少发布/开关/运行证据 |
| 维护中 | MAINTAIN | 不再迭代，只修bug |
| 已废弃 | DEPRECATED | 标记废弃，仍有残留配置/代码 |
| 已移除 | REMOVED | 配置和代码已清理 |

## 更新规则

- 状态变更必须标注证据来源（发布记录、服务器开关、运行验证、会议记录或代码提交）；工作副本里存在配置/代码只能标 `UNKNOWN_LIVE`，不能直接写成 `LIVE`
- 废弃功能必须标注原因和残留清理状态
- 每个 Minor 版本发布后更新本文档
- 不确定的状态标记 `待确认`，不假设
