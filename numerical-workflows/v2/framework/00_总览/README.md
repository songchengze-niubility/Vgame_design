# 00_总览

这里放全局数值规划与口径说明，不放单系统展开表。

建议内容：

- `总体规划.md`：项目整体数值目标、模块边界、长期版本规划。
- `数值边界与口径.md`：属性、战力、战斗、经济、节奏等核心口径；奖励与概率归属到经济和具体玩法/系统模块。
- `模块索引.md`：各模块源表、沉淀 MD、数值文档、验算核算表的入口。
- `Vgame配置映射总表.xlsx`：全量配置 Schema、模块映射、配置草案、审批记录与落地回执；不保存正式配置业务数据。

使用规则：

- AI 做数值任务前，先读这里判断全局口径。
- 如果只是某个系统内部调整，通常不改这里。
- 配置映射总表是派生治理入口，不是参数源；用户批准具体批次前不得写入 Vgame 正式配置。
