# Vgame 数值框架 v2（源表事实 + MD 参数 → 最终文档 → 动态验算）

> 原则：**全局事实回到 `01_源表`，系统参数与公式沉淀在 MD，最终 Excel 全量派生，参数 Excel 退出正式链路**。
> 旧 5 张外部 Excel 只作历史迁移对照，不得覆盖当前源表或 MD。

## 当前全局口径

- 主数值域按 `养成 / 经济 / 节奏 / 战斗` 四条链路管理，每条链路都有对应 `01_源表` 入口。
- 奖励、掉落、概率、产出不设独立一级数值模块，归属到具体玩法/系统模块；经济总账只做后置汇总、对比和异常校验。
- 养成投放预算入口以 `01_源表/养成属性分配.xlsx` 为准，不再使用独立 `投放系数.xlsx` 作为入口。
- 正式交付层已收口到 `01_源表`、`03_沉淀MD`、`04_数值文档`、`05_验算核算`；旧 5 张外部表只作为迁移记录。
- `03_沉淀MD/参数基线/*.md` 是单系统参数与公式的唯一维护入口；`04_数值文档` 是派生交付物，不作为参数源。
- `00_总览/Vgame配置映射总表.xlsx` 是正式配置前的 Schema 镜像与批次审阅入口，不保存业务配置行，也不成为参数源。
- `06_最终配置/` 保存可评审的业务配置镜像；它不是正式 Datas，未经用户批准不得同步 SVN。
- 资源副本四类×5层评审镜像已生成到`06_最终配置/资源副本/`；舱室3-5层首通已改单物品包且无需人工插行，按类型共享每日3次仍是正式落表程序阻塞项，SVN未修改。
- 映射装备的完整配置字段映射、正式 ID、生成顺序和落表门禁见 `03_沉淀MD/养成/映射装备配置落地方式-2026-07-13.md`。
- `_shared/共享参数.xlsx` 与四模块 `参数.xlsx` 已在逐格迁移和 MD-only 全量回归通过后删除。

## 跨类引用规则

- 共享、养成、战斗、经济、节奏参数分别维护在 `03_沉淀MD/参数基线/*.md` 的唯一机器参数块中。
- 稳定参数 ID 使用 `<参数域>/<Sheet>!<Cell>`，例如 `战斗/战斗模型参数!B2`。
- 各类脚本通过 `_shared/md_parameter_reader.py` 读取 MD；跨类参数必须显式写出参数域和稳定 ID。
- `01_源表` 保留术语、定价、公式、配置事实等全局证据；只有全局底座变化时才修改，不承担单系统参数表职责。

## 日常用法

1. 全局事实变化先改 `01_源表`；系统参数或公式变化改对应参数基线/单系统 MD，并记录所有权与影响范围。
2. 先运行 `sync_global_sources_to_md.py`（需要落盘时显式 `--write`），再运行 `python run_all.py`。
3. 用 `stage_final_documents_from_md.py` 从本次生成物创建全新的 `04` staging；禁止复制旧 `04` 补文件。
4. 用 `05_验算核算/scripts/validate_rebuild.py --target <staging>` 做动态门禁，并由 Excel 完整重算公式。
5. 门禁全部通过后原子替换正式 `04`，再对正式目录复验。
6. 需要落 Vgame 配置时，刷新 `Vgame配置映射总表.xlsx`，先生成配置草案；只有用户明确批准当前批次后，才进入正式 `Datas` 与 Luban 导出验证。

`python run_all.py` 用于当前权威链的整套生成与回归；它先验证 01→MD，再刷新 22 个生成任务，失败时返回非零退出码，但不会覆盖 `04_数值文档`。

> 想要单跑某类：`cd 框架v2\养成\scripts ; python gen_growth_budget.py`

> 后续如果有新的模块输入文档，原始文件先放 `_inputs/`，再按 `输入文档更新流程.md` 拆成框架草案，确认后再落入参数、生成器、报告和总览。

## 交付记录规则

每完成一次迁移、复现、生成器接入、口径裁决或纠偏，都必须同步更新对应 md：

1. 对应模块的 `_reports/*.md` 记录本次做了什么、源表/页签、复现或校验结果、待确认点。
2. 顶层 `README.md` 或 `_reports/00_总览_全量校验.md` 更新全局状态、生成器数量、已完成/待办。
3. 如果后续发现前一次做法不对，必须回改对应 md，把旧结论修正为当前口径，避免过期判断继续误导。

## 迁移分层规则

不是所有页签都应该直接参数化生成。迁移前先判断页签类型：

| 类型 | 处理方式 | 典型例子 |
|---|---|---|
| 知识/规则表 | 先 1:1 镜像，保留原布局、说明、公式、上下文 | `战斗属性`、`战斗公式`、`属性定价`、`开启节奏和引导` |
| 工具/计算器表 | 先 1:1 镜像，再做结构化参数页和校验脚本 | `技能系数`、`道具定价` |
| 派生大表 | 可以走参数 → 生成 → 对照 | `怪物标准模型`、`玩家战力曲线`、各类难度线 |
