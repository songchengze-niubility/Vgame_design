# 玩家战力曲线数值沉淀

## 沉淀范围

本文件只沉淀玩家战力曲线相关数值口径，包含：

- 玩家战力曲线的输入模块。
- 从养成属性到战斗输出的完整计算链路。
- 房车整备接入战力曲线的边界与当前“含房车”输出。
- 当前正式交付文件与验算报告入口。
- 星盘新口径、专武B兼容迁移期和收容物接入对战力曲线的影响待办。

不展开角色升级、星盘、升星、专武、旅券、映射装备、炮台、房车的单项细节；这些由各自单项沉淀承接。

## 核心口径

- 玩家战力曲线是养成主链路到战斗表现的总线，不是单个养成系统的设计入口。
- 当前生成曲线覆盖角色等级、星盘、专武、映射装备、旅券和房车进度；专武只作为裁决B规定的一个大版本冻结兼容输入。
- 队伍人数不是全程固定5人：正式配置通过 `SystemOpen.Id=28～32 -> UnlockId=4025～4029 -> Unlock` 逐步开放上阵阵位。第1/2/3/4/5个阵位分别于默认、通关0-2、通关1-1、通关1-4、通关2-4后可用。
- 当前版本目标已新增收容物；最终战力曲线需在一个大版本兼容期结束后切换专武，并接入收容物等级、位置、品质、升星二级属性和未上阵收集属性。
- 房车整备已在现有曲线中以“含房车”扩展列计算；玩法对齐过渡期按第55关起使用含房车输出，最终重建时应合并为正式单线输出。
- 曲线输出重点是：
  - 总单位时间伤害。
  - 预计 boss TTK。
  - boss 生命。
- 现有生成器链路中，旧口径计算方式包括：
  - 裸体防御 = 初始防御 + 角色等级进度 × 升级防御 + 星盘进度 × 星盘防御。
  - 裸体攻击 = 初始攻击 + 角色等级进度 × 升级攻击。
  - 额外防御/额外攻击 = 专武、映射装备、旅券等额外属性进度叠加。
  - 防御%、攻击%、攻速、技能、必杀、暴击、暴伤、增伤等倍率随养成权重与进度变化。
  - 总单位时间伤害 = 养成总倍率 × 战斗内总倍率 × 算后攻击 × 队伍人数进度 × `(1 - 减伤率)`。
- 下一轮重建不得再把“队伍人数进度”当作连续倍率或用完整5人队线性缩放。应按当前已解锁阵位实际生成1～5人编队，并分别汇总角色DPS、技能协同和承伤能力。
- 当前星盘基础属性投放系数为0，因此生成结果不再获得星盘基础属性；脚本仍保留旧星盘防御表达式，未来若系数改为非0会出现攻防不对称风险。

## 字段链路

| 字段组 | 字段 | 说明 |
|---|---|---|
| 进度输入 | 角色进度、阵位解锁、星盘进度、专武进度、映射进度、旅券进度、房车进度 | 各养成模块随关卡推进的成长进度；阵位按正式SystemOpen/Unlock链，房车接入节奏待重算 |
| 防御链 | 裸体防御、额外防御、防御%、算后防御、减伤率 | 防御与减伤换算链 |
| 攻击链 | 裸体攻击、额外攻击、攻击%、算后攻击 | 攻击属性换算链 |
| 倍率链 | 战斗内总倍率、养成总倍率 | 技能、攻速、暴击、暴伤、增伤等综合倍率 |
| 输出链 | 总单位时间伤害、预计bossTTK、boss生命 | 战力曲线最终对外输出 |
| 房车扩展 | 额外防御_含房车、算后防御_含房车、减伤率_含房车、额外攻击_含房车、算后攻击_含房车、总单位时间伤害_含房车、boss生命_含房车 | 历史追加列；新版重算时需要转为正式输入/输出链 |

## 待办与边界

- 当前 `玩家战力曲线_数值文档.xlsx` 和 `gen_power_curve.py` 仍包含已废弃专武，且尚未接入现行收容物，只能作为过渡基线。
- 下一轮重算必须移除专武进度和属性贡献，并按收容物独立沉淀接入收容物成长；职业一级属性模板、单体偏移和二级属性具体分配未确认前，不能冻结最终曲线。
- 下一轮重算必须接入阵位解锁：主线计划序号1～2按1人、3～6按2人、7～9按3人、10～19按4人、20起按5人生成实际编队快照。
- 星盘基础属性继续保持0，只允许星盘二级属性和机制成长进入对应倍率或战斗机制层。
- 房车已有含房车输出；下一轮重算应将其并入正式单线，不再长期保留两套平行列。
- 全玩法难度的统一对齐规则以 `03_沉淀MD/节奏/全玩法难度线数值沉淀-2026-08-04.md` 为准。
- 玩家战力曲线不定义单项养成成本、材料产出或玩法奖励；这些归属经济或具体系统模块。
- 若后续调整节奏锚点、模块开放时间、星盘新口径、房车接入或战斗公式，需要同步重算玩家战力曲线和相关验算核算。
