# 角色升星数值沉淀

## 沉淀范围

本文件只沉淀角色升星相关数值口径，包含：

- 升星星级节点的属性投放结构。
- 升星最终基础属性百分比预算。
- 升星二级属性偏向预算。
- 每个角色星3、星5的升星偏向属性选择。
- 角色升星在玩家战力曲线中的位置。
- 当前正式交付文件与验算报告入口。

不包含角色升级、角色星盘、专武、旅券、映射装备、炮台、房车，也不展开具体玩法产出或经济总账。

## 源表入口

- `01_源表/属性定价.xlsx`
- `01_源表/养成属性分配.xlsx`
  - `模块规划`：角色升星的最终基础属性百分比和二级属性偏向预算入口。
  - `角色属性分配`：每个角色的升星属性1、升星属性2选择入口。
- `01_源表/术语表.xlsx`

旧 5 张原始表只作为复现对照基准，不修改。

## 核心口径

- 角色升星属于角色成长链路，是角色长期深度和付费成长的重要承接点。
- 角色升星不走固定基础属性投放；它投放的是最终基础属性百分比和二级属性偏向。
- 显式属性节点在星3、星5：

| 星级 | 投放内容 | 生命% | 攻击% | 防御% | 偏向二级属性 |
|---|---|---:|---:|---:|---:|
| 1 | 天赋1 | - | - | - | - |
| 2 | 天赋2 | - | - | - | - |
| 3 | 全属性% + 普通二级属性 | 0.15 | 0.15 | 0.15 | 0.3 |
| 4 | 天赋3 | - | - | - | - |
| 5 | 全属性% + 普通二级属性 | 0.15 | 0.15 | 0.15 | 0.3 |
| 6 | 天赋4 | - | - | - | - |
| 合计(显式属性) | - | 0.30 | 0.30 | 0.30 | 0.6 |

- `模块规划` 中角色升星最终基础属性百分比预算为生命/攻击/防御各 `0.9`。
- `0.9` 包含星1、星2、星4、星6四个天赋节点的战力贡献折算，不等于显式属性节点的 `0.3`。
- 二级属性偏向只在星3、星5各投放一次，每次 `0.3`，合计 `0.6`。
- 当前升星稀有二级属性投放为 `0`。
- 物理伤害加成、魔法伤害加成在本表中是二级伤害加成属性，不是物理攻击/魔法攻击拆分；攻击仍按单一攻击属性处理。

## 星3二级偏向伤害类型新口径（2026-09-21 裁决，实施未开始）

> 完整方案见 `proposals/角色升星伤害类型新口径-2026-09-21.md`（PROP-20260921-STAR-DMGTYPE）。本段为交接沉淀：裁决已确认，表结构改造与落表未开始。

**背景**：战斗侧伤害类型已扩展为 9 种（`DamageType.cs`：物理/魔法/真实/火焰/冰霜/神圣/暗影/毒素/雷电），`DamageStrategy.CalculateGeneBonus` 按技能实际 `damageType` 读对应加成。但 `${VGAME_CONFIG_DATAS}/Hero/HeroStarAttrUp.xlsx`（224 行 = 32 角色 × 7 星）星3二级偏向仍用旧口径 `PhysicsDmgBonus`/`MagicDmgBonus` 二分（各 0.12）——技能实际已是元素系的角色，其星3加成在运行时**不生效**。逐技能 `damageType` 实测数据源：`Assets/GameResources/GameData/SkillData/Text/hero/*/`。

**裁决（用户 2026-09-21 确认）**，按预算换算不变（0.3 → 0.12）执行：

- **A 组迁移元素列（15 角色）**：塔拉夏1003→暗影、阿芭1004→神圣、莉莉娅1006→火焰、萨萨莉安1007→神圣、陈双双1011→冰霜、艾德琳1012→火焰、夏提拉1013→暗影、阿莱克西娅1015→冰霜、伊戈尔1017→冰霜、梅梅1021→毒素、梅林1022→**毒素**（技能毒素×4/物理×3，裁决按毒素）、卡薇1024→火焰、碎冰者1035→冰霜、霜狼法师1036→冰霜、小寒1040→神圣。
- **B 组既有字段修正（1 角色）**：凯兰1029 魔法→**物理**（旧口径下也配错）。
- **C 组保持不变（11 角色）**：星海1001、陈单单1005、薇1008（裁决按物理）、克莉丝汀1014、桑尼1019、卡斯帕1020（裁决按物理）、马克1023（裁决按物理）、乔一1026、莫莉1030、霜狼战士1037、商队枪手1039（裁决按物理）。
- **D 组不处理**：约瑟夫1009（`Hero.xlsx` 行首 `##` 停用）、雷诺1016（占位复制行、无自有技能），随实装/启用方案再定。

**实施前置（需程序侧配合）**：`HeroStarAttrUp` 表结构无 6 个元素加成列，须先在 `PoisonDmgBonus` 后扩列（`FireDmgBonus`/`FrostDmgBonus`/`HolyDmgBonus`/`ShadowDmgBonus`/`ToxinDmgBonus`/`ThunderDmgBonus`，Luban `float64#default=0`）并重新生成 `HeroStarAttrUpTable.cs`（Excel 44→50 列），再按 A/B 组改值。

**实施坑**：毒素列必须用 `ToxinDmgBonus`，**勿用 `PoisonDmgBonus`**——后者是中毒持续伤害基因加成，语义不同。星5节点全部与伤害类型无关（暴击/暴伤/技能/必杀/治疗/冷却/能量类），不动。

**遗留待裁决**：梅林在 `HeroEnergyEfficiencyAttr` 体系的能效 C 槽归属（与星3偏向是两个维度，未随本裁决处理）。

## 边界说明

- 本沉淀只确认角色升星的属性投放、二级属性偏向和每角色属性选择。
- 星1、星2、星4、星6的天赋效果属于角色设计内容，本文件只记录其战力折算进入 `0.9` 总预算，不展开具体技能效果。
- 角色升星不定义玩法产出、升星材料、碎片来源或经济供给；相关产销应进入经济模块或角色升星成本沉淀。
- 如果后续调整升星星级节点、天赋折算、全属性百分比或二级属性预算，需要先更新源表，再重算 `角色升星_数值文档.xlsx` 和玩家战力曲线。
