# 映射装备数值总表生成参数

## 定位

本文件只保存 `生成_映射装备数值总表.xlsx` 无法从既有系统沉淀直接推导的阅读/验算场景参数。
属性、掉落、合成、打造、分解、锻造台和爬塔挂机的正式数值仍分别以以下沉淀为准：

- `映射装备养成数值沉淀-2026-07-07.md`
- `21_养成_映射装备经济消耗沉淀-2026-07-09.md`
- `05_玩法_映射副本经济沉淀-2026-07-08.md`
- `08_玩法_爬塔经济沉淀-2026-07-09.md`
- `映射装备配置落地方式-2026-07-13.md`（只负责配置映射和生成方式）

生成器不得读取 `04_数值文档` 作为运行时模板。本文件中的场景参数由旧终稿蓝字输入迁移，迁移后由本 MD 维护。

## 生成约束

- 输出固定包含 19 个页签，顺序为 `00_口径` 至 `18_产销汇总`。
- 蓝字为从 `01_源表`、本文件或其他沉淀 MD 读取的输入；黑字为 Excel 公式。
- `01_源表/养成属性分配.xlsx` 中映射装备的生命、攻击、防御投放用于校验三项 60 级红装目标值。
- `01_源表/属性定价.xlsx` 用于校验百分比和二级属性定价口径存在。
- `01_源表/道具定价.xlsx` 用于确认金币 ItemId 与钻石定价锚点。
- `01_源表/经济口径.xlsx` 用于确认映射装备已删除升级、打孔、鉴定，并保留洗练/宝石的系统边界。

## 配置落地追踪 ID

> 以下 ID 只追踪跨表配置裁决，不新增数值口径；具体数值仍回到本文件列出的权威沉淀 MD。

| 参数 ID | 配置裁决 |
|---|---|
| `ME.CONFIG.CHEST_PROVENANCE` | 五档宝箱如何保留来源层/档位，以正确选择装备等级池。 |
| `ME.CONFIG.ITEM_IDS` | 72 种打造主材、4 种副材及相关宝箱 ItemId 的分配。 |
| `ME.CONFIG.DROP_CHAIN` | `Items / SpecialEquipmentGenerate / Drop / UILevel` 的奖励与预览引用闭环。 |
| `ME.CONFIG.UNLOCK_CHAIN` | 合成 8 档解锁链（2026-09-05 按 SVN 正式实测 `unlock/Unlock.xlsx`、`SpecialEquipment\Portable\PortableRange.xlsx`）：档 1 无解锁条件，档 2～8 UnlockId `1201～1207`＝玩家等级 10/20/30/35/40/45/50；打造 `SystemOpen.Id=54 -> UnlockId=4046`（`UnLock_UUT_WeaponLevel_PassMax=6`，装备副本第 6 层）。旧口径 `1190～1197`/`UnlockId=1198` 作废（正式 Unlock 无此段 ID），生成器参数需按此同步更新。 |
| `ME.CONFIG.RUNTIME_PORTABLE` | Portable 7 表的客户端/服务端运行时消费链接入。 |
