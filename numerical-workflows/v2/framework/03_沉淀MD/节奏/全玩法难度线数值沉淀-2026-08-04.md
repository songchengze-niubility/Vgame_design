## 统一对齐裁决

### DL-R01：每个 PvE 战斗节点必须先有怪物等级

PvE 难度线的正式主轴是怪物等级。主线每个关卡、爬塔每层，以及各副本每个独立难度档，都必须明确怪物等级 `M`。无限挑战暂不纳入本轮；PVPVE 属于例外，按双方实际属性对算，不配置关卡怪物等级。

```text
关卡/层数/波次/难度档
-> 怪物等级 M
-> 查询怪物标准模型(M)
-> 乘玩法生命/攻击/防御系数
-> 得到实际怪物属性
```

每个战斗节点至少配置：

```text
怪物等级 M
生命系数 H
攻击系数 A
防御系数 D
```

`H/A/D` 任一系数为空时，计算值统一取 `1`；只有显式填写数值时才覆盖默认值。

不得用“玩家DPS × 目标TTK”直接替代怪物等级线。该结果只能用来反查或校验所选怪物等级与系数是否合理。

### DL-R02：养成关卡是校验映射，不是难度主键

怪物等级确定后，再给同一战斗节点补充 `对应养成关卡 S`，用于查询同期玩家战力并验算难度。

`对应养成关卡 S` 的定义为：玩家正常首次挑战该战斗节点时，预计主线已经推进到的累计关卡序号。

校验映射优先级：

1. 已确认的玩法开放/推荐挑战主线关卡。
2. 已确认的玩家等级，再通过开放节奏映射到主线关卡。
3. 已确认的目标天数，再通过主角等级日程映射到主线关卡。
4. 都没有时标记 `待确认`；怪物等级可以保留，但不能声称已与养成对齐。

### DL-R03：房车列自动切换

过渡曲线阶段统一按以下方式取玩家基线：

```text
S < 55：使用“总单位时间伤害 / boss生命”
S >= 55：使用“总单位时间伤害_含房车 / boss生命_含房车”
```

最终重建玩家战力曲线后，房车应成为正式输入，不再长期保留两套平行输出列。

### DL-R04：生命难度统一用EHP/TTK判断

```text
怪物有效生命EHP = 怪物生命 / (1 - 怪物减伤率)
预测TTK = 怪物有效生命EHP / 同期标准玩家DPS
难度比 = 预测TTK / 目标战斗时间
```

难度判断：

| 难度比 | 判断 |
|---:|---|
| `<0.50` | 碾压 |
| `0.50~0.80` | 偏简单 |
| `0.80~1.20` | 适中 |
| `1.20~1.50` | 偏难 |
| `>1.50` | 过难或形成卡点 |

当玩法以整场波次为单位时，使用全场敌人总EHP；不能把单只Boss生命直接复制给每一波小怪。

实际怪物EHP必须来自“怪物等级M对应的标准模型属性 × 玩法系数”。`玩家DPS × 目标TTK`是校验目标，不是正式怪物属性源。

### DL-R05：攻击压力独立于生命压力

生命倍率控制玩家需要打多久，攻击倍率控制玩家能否活到打完。两者必须分别配置和验算。

```text
玩家有效生命EHP = 玩家生命 / (1 - 玩家减伤率)
玩家存活时间 = 玩家有效生命EHP / 怪物DPS
```

若玩家存活时间低于预测TTK，则该档位判定为生存不成立；不能只降怪物生命掩盖攻击压力问题。

### DL-R07：奖励档不能代替战斗难度线，PVPVE单列属性对算线

奖励难度、奖励层可以保留在全玩法汇总中，但必须标记为非战斗行。每个实际可进入的 PvE 关卡仍需单独提供怪物等级与生命、攻击、防御系数。PVPVE 的玩家分层也不能直接当成战斗结果，必须另外记录双方属性输入、匹配规则和对算结果。

```text
PvE战斗行：必须有怪物等级
奖励行：可以没有怪物等级，但不得用于生成怪物属性
PVPVE对算行：不要求怪物等级，必须能追溯双方属性输入与计算结果
```

### DL-R08：主线难度母曲线与本轮关卡数分离

主线难度生成必须把“长期节奏母曲线”和“本轮实际关卡绑定”分成两层：

```text
长期母曲线 = Lv1～60 / Day1～65
本轮编译参数 = current_stage_count = 105
本轮实际绑定 = Stage1～105 -> 章节0～7 -> Lv1～39 / Day1～8
未来扩关 = 新增LevelId后继续绑定Lv40～60，不改写既有母曲线
```

105只能作为当前输出数量，不能写死为难度曲线终点。生成器必须允许传入可变 `stage_count`；不存在正式 LevelId 的未来节点只保留等级、天数、DPS/EHP与目标TTK，不生成正式配置建议。

### DL-R09：同期玩家快照必须遵守上阵阵位解锁

玩家基线不能从第一关起默认5人队。正式阵位开放链为：

```text
阵位1：玩家Lv1默认开放
阵位2：通关0-2后开放 -> 从0-3起可用
阵位3：通关1-1后开放 -> 从1-2起可用
阵位4：通关1-4后开放 -> 从1-5起可用
阵位5：通关2-4后开放 -> 从2-5起可用
```

对应本轮计划序号为：1～2关1人、3～6关2人、7～9关3人、10～19关4人、20～105关5人。怪物等级反查使用当前实际阵容的DPS/EHP，不得用完整5人队乘 `人数/5` 近似早期快照。

正式证据为 `SystemOpen.Id=28～32 -> UnlockId=4025～4029 -> Unlock`。`SystemOpen` 备注文本与引用链不一致时，以 `UnlockId` 实际指向的条件为准。
