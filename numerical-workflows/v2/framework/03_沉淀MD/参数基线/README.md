# 参数基线

本目录保存框架 v2 的全部共享、养成、战斗、经济和节奏参数。自 2026-07-10 起，这五份 MD 是参数与公式的唯一维护入口。

| 参数域 | 文件 | 页签 | 非空单元格 | 旧公式 |
|---|---|---:|---:|---:|
| 共享 | `共享参数基线.md` | 4 | 123 | 1 |
| 养成 | `养成参数基线.md` | 15 | 4417 | 40 |
| 战斗 | `战斗参数基线.md` | 7 | 987 | 2 |
| 经济 | `经济参数基线.md` | 1 | 16 | 0 |
| 节奏 | `节奏参数基线.md` | 3 | 344 | 0 |

规则：

- 稳定参数 ID 为 `<参数域>/<Sheet>!<Cell>`。
- 参数块 schema 为 `vgame-parameter-workbook/v1`，读写规则见 `02_AI规则/MD参数契约.md`。
- 旧 `_shared/共享参数.xlsx` 与四模块 `参数.xlsx` 已在逐格迁移和 MD-only 回归通过后删除。
- 修改最终数值文档时，同一变更必须同步这里或对应单系统沉淀 MD，不要求回写旧参数表。
- 日常使用 `02_AI规则/check_md_parameters.py` 校验 MD 参数块；不得重新建立 Excel 参数源。
