# 03_沉淀MD

这里放每个系统从需求、讨论、确认到数值结论的 Markdown 留档，也是单系统参数与公式的唯一设计权威。

建议结构：

- `养成/`
- `经济/`
- `节奏/`
- `战斗/`
- `参数基线/`：共享、养成、战斗、经济、节奏五个完整机器参数块。

奖励、掉落、概率不设独立一级沉淀目录，归属到对应玩法/系统模块；经济总账只做后置汇总和异常校验。

使用规则：

- 每次单系统数值设计先形成 MD 留档。
- MD 是生成或修改系统数值文档的唯一参数依据；旧参数工作簿不再作为入口。
- 没进 MD 的决策，不作为后续 AI 判断依据。
- 参数稳定 ID 为 `<参数域>/<Sheet>!<Cell>`；参数块只保留一份，不在多个 MD 中复制第二份权威值。
- 最终 Excel 紧急直改时，必须在同一变更中同步参数块或对应系统 MD，才算完成。
- 需要正式落配置时，MD 中应写明目标逻辑表/工作簿/Sheet/主键/字段或明确标记“待建立映射”；配置草案只能引用 MD 参数 ID，不得在映射总表中另立一份参数权威。
