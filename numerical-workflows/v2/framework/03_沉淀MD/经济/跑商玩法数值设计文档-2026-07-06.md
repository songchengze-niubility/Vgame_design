## 设计定位

跑商是局外轻量挂机经营与社交护货玩法。玩家用商券购买虚拟货物并消耗行商精力，选择站点进行 6 小时派遣；结算时按锁定收购价出售货物，获得商券利润、行商等级经验和升级一次性奖励，同时结算与地区挂钩的护货战斗并刷新可处理的旅途事件。玩家可邀请好友协同护货，并每日切磋其他运输商队。

本玩法不把货物作为真实道具入账。货物只承担玩法内价格、库存、成本、利润计算。真实道具产出只来自升级一次性奖励、旅途事件额外奖励和后续商券商店。

### R-01A 行商精力

行商精力只使用跑商内循环的等级成长，不读取房车设备、藏品或其他外部系统加成。精力不在每日 4:00 重置，运输中与离线期间正常自然恢复；达到当前上限后停止恢复。点击确认出发且服务器成功创建订单后立即扣除 60 点，订单未创建成功则不扣除。

恢复速度采用加法累计百分比，不再直接配置固定“分钟/点”档位。基础恢复间隔为 18 分钟/点，Lv.3、Lv.11、Lv.18 每次增加 10% 恢复速度：

```text
累计恢复速度加成 = 已获得的恢复速度提升之和
实际每点恢复时间 = 18 / (1 + 累计恢复速度加成) 分钟
理论自然供给 = 1440 / 实际每点恢复时间 / 60 单/天
```

## 价格规则

### R-03 价格倍率

| 项 | 数值 |
|---|---:|
| 今日购入价 | 基础价 * 80%-105% * (1 + 等级购入价格加成) |
| 普通收购价 | 基础价 * 90%-120% * (1 + 等级出售价格加成) |
| 急需收购价 | 基础价 * 160%-200% * (1 + 等级出售价格加成) |
| 最终出售价格加成 | Lv.20 达到 +15% |
| 最终购入价格优惠 | Lv.20 达到 -10% |
| 每站急需 | 每个已解锁站点，从本站 3 个货物中随机 1 个 |
| 急需去重 | 每日各站点急需货物不重复 |
| 复杂利润保底 | 不做 |

### R-04 结算公式

```text
今日购入价 = 基础价 * 购入倍率 * (1 + 等级购入价格加成)
今日收购价 = 基础价 * 收购倍率 * (1 + 等级出售价格加成)
商品实际可购买数量 = CEIL(商品基础购买值 * (1 + 等级购买数量上浮%))
单件利润 = 今日收购价 - 今日购入价
本次利润 = Σ(单件利润 * 出售数量)
等级经验 = max(本次利润, 0)
护货奖励商券 = ROUND(max(本次利润, 0) * 护货胜利场数 * 5%)
好友奖励商券 = ROUND(max(发起者本次利润, 0) * 护货胜利场数 * 5%)
切磋胜利奖励商券 = ROUND(max(目标订单锁定利润, 0) * 5%)
```

均值口径：

| 类型 | 买价均值 | 卖价均值 | 单件均值利润 |
|---|---:|---:|---:|
| 普通收购 | 92.5% | 105% | 基础价 * 12.5% |
| 急需收购 | 92.5% | 180% | 基础价 * 87.5% |

上表为无等级价格增益时的基础均值。实际测算时，买价按当前等级购入价格加成修正，卖价按当前等级出售价格加成修正。Lv.20 时，普通单件均利约为基础价 * 37.5%，急需单件均利约为基础价 * 123.75%。

一次派遣只选择 1 个目的站点，因此只有该站点的当日急需货物吃急需倍率，其余货物按普通收购倍率结算。

### R-05 等级经验

行商等级经验来自跑商正利润累计。负利润不计入等级经验。达到等级上限后不再累计经验。

V27 继续将精力上限和精力恢复速度纳入行商等级永久提升。站点解锁、行商精力、商会补给、商品购买数量上浮、出售价格加成、购入价格优惠都算永久提升；升级一次性奖励不占用永久提升位。Lv.1-Lv.20 的单次派遣载货量仍固定为 30，后续独立载货量养成不纳入本次精力内循环。

### R-05B 商品购买数量上浮

商品购买数量上浮只影响商店供给/可购买数量，不影响单次派遣载货量。同一站点内按货物基础价从低到高，将每日基础购买值配置为 25/20/15；每站合计仍为 60，平均值仍为 20。实际可购买数量按当前行商等级向上取整。

```text
商品实际可购买数量 = CEIL(商品基础购买值 * (1 + 商品购买数量上浮%))
```

## 收益与产销测算

V27 继续使用低/中/高价货物25/20/15的基础购买量和V21的货物基础价，但精力恢复已改为百分比加速，必须重新计算每日有效跑商次数与额外商券来源。V26与旧V22的采购、回款、利润和商店预算只保留为历史，不再作为当前评审通过依据。

每站基础总供给仍为60，单次载货量仍为30。V27收益模型仍按“单次货物利润×各等级标准有效完成次数”计算，并单独叠加每日一次商会补给、每单旅途事件期望、地区护货奖励、好友被助战奖励和每日两次切磋奖励；其中标准有效完成次数必须按新恢复公式重算。后续独立载货量养成仍不计入本轮内循环。

商券产销口径：

```text
采购消耗 = 当日购买货物消耗的商券
出售回款 = 派遣结算卖货获得的商券
买卖净利润 = 出售回款 - 采购消耗
每日货物利润 = 单次货物利润 * 当前等级标准有效完成次数
每日旅途事件商券期望 = 单次事件商券期望 * 当前等级标准有效完成次数
每日护货奖励期望 = 单次货物正利润 * 地区平均胜利场数 * 5% * 当前等级标准有效完成次数
每日净商券流入 = 每日货物利润 + 商会补给 + 每日旅途事件商券期望 + 每日护货奖励期望 + 好友助战收入 + 切磋收入
```

每日净商券流入可按以下结构理解：

```text
每日净商券流入 = 每日货物利润 + 商会补给 + 旅途事件商券 + 护货商券 + 好友助战商券 + 切磋商券
旅途事件商券 = 单次事件池选项1商券加权均值 × 60%玩家选择率 × 当日完成单数
```

行商等级经验仍只吃货物买卖正利润；商会补给、旅途事件、护货战斗、好友助战、切磋和升级一次性商券只影响玩家可用商券，不影响升级速度。V26派生Excel中的周收入、90天事件商券累计和商店结余需由V27模型重新生成。

## 精力消耗 60→30 调整预案（V28 待定，未生效）

2026-09-02 用户提出将常规派遣行商精力消耗由 60 降为 30。本期（V27）数值保持不变，本节仅记录影响分析与落地路径，待方向裁决后随 V28 生效。

### 机制影响

| 等级段 | V27 理论供给 | 30 精力后理论供给 | 截断后实际（按单站日采购池约束） |
|---|---:|---:|---:|
| Lv.1-Lv.2 | 1.33 单/天 | 2.67 | 2.0 |
| Lv.3-Lv.10 | 1.47 | 2.93 | 2.33 |
| Lv.11-Lv.17 | 1.60 | 3.20 | 2.33 |
| Lv.18-Lv.20 | 1.73 | 3.47 | 2.63 |

- 6 小时×1 并发的时间上限 4 单/天改后仍不构成瓶颈（3.47 < 4），精力仍是主约束。
- 每站日采购池（60/70/79 个，载货 30）会在“一次派遣只采购单站货物”语义下取代精力成为实际约束，收入乘数约 ×1.5；若允许轮换站点/混装，Lv.10 后才接近理论 ×2。该语义当前未定（与 TR-Q9 同源），必须先裁决——它直接决定收入乘数是 1.5 还是 2。

### 连锁影响

- 升级节奏：经验=正利润，单量 ×1.5~2 → V27 粗算 97.4 天毕业变为约 50-65 天。保持 89-90 天目标需 Lv.20 阈值 8385000 上调至约 1250 万-1680 万，全表阈值重推；与 TR-Q4 欠下的 V27 逐日模拟合并执行。
- 收入面：按单结算项（货物利润、旅途事件、护货、好友助战）×1.5~2；海港高级事件元晶/旅券投放（TR-Q1）与好友助战增发（TR-Q15）预算需重审；商会补给与切磋等按天收入占比被稀释。
- 商店：周商券收入上升后，每周 580000 重复池更易清空，房车材料 24-25 周毕业压缩至约 13-17 周（跨系统影响，TR-Q12 复核需带新单量）。
- 行为面：吃满精力需每日 3-4 单、约每 7 小时上线结算，挂机定位上移为高频上线；精力上限存量语义由 1/2/3 单变为 2/4/6 单，Lv.7/14 与 Lv.3/11/18 节点边际价值翻倍。
- 事件容量：生成率 2.7-3.5 条/天 × 18 小时 ≈ 稳态 2.6 个并存 > 上限 2，低频登录玩家必然溢出，TR-Q8（列表满时刷新行为）必须先定规则。
- 不受影响项：恢复速度公式、价格倍率、结算公式、护货/切磋系数、事件概率与奖励包、新手免费首单、TR-Q13 首单满载问题。
