# 11_玩法_肉鸽经济沉淀

生成日期：2026-08-04  
最近更新：2026-08-10

本篇沉淀重新启用后的肉鸽玩法（旧日归处）周期、难度、积分与奖励口径。当前只固化已确认数值，不扩展代币、排行、商店或赛季主题轮换。

## 结论摘要

1. 肉鸽以 **7 天为一期**，与系统每周刷新边界一致。
2. 每期结束时，周积分与周积分奖励领取状态重置；新一期重新累计。
3. 周积分上限为 **5000 分**，最高积分奖励档同为 5000 分。
4. 五档难度顺序解锁：必须通关前一难度才能挑战下一难度；难度 1 默认开放。
5. 五档单局积分依次为 **1800 / 2400 / 3000 / 4000 / 5000**。
6. 达到 5000 分所需局数依次为 **3 / 3 / 2 / 2 / 1 局**；高难玩家难度 5 一局满档，普通玩家约 2—3 局满档。
7. 代币字段本期保留但不设计，单局代币配置为 0。
8. 首通奖励合计为 **收容凭证 60 张、元晶 1500**。首通奖励暂按账号一次性处理，不随 7 天周期重置。
9. 每期积分奖励拆为 **7 档**，每档固定只有两项奖励：收容凭证 + 元晶或收容物经验；单期合计为 **收容凭证 60 张、元晶 600、收容物经验 200000**。

## 风险与验收

1. 服务端应只在通关结算时累计单局积分，失败或主动退出不得获得完整单局积分。
2. 每期边界到达时，需要同时验证 `WeeklyScore` 清零与周奖励领取状态清空。
3. 难度解锁与首通领取状态不得随每期重置。
4. `RougeScoreWeekLimit` 必须等于最高积分档位 5000。
5. `RoguelikeLevel.FirstDrop` 必须能在逻辑 Drop 表中完整命中，且五档首通总量必须为收容凭证 60、元晶 1500。
6. 七档每期积分奖励必须严格为两项：第一项均为收容凭证(107)，第二项只能是元晶(2)或收容物经验材料(108/109/110)；不得出现第三项奖励。
7. 七档收容凭证数量必须为 5 / 5 / 8 / 8 / 8 / 12 / 14，单期合计60张；2000/4000/5000分档第二项分别为元晶×100/200/300，其余四档第二项为收容物经验，单期经验合计200000。
