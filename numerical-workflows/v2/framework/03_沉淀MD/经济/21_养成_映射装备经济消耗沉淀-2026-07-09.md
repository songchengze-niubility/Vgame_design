# 21_养成_映射装备经济消耗沉淀

> 日期：2026-07-09  
> 范围：只沉淀映射装备养成侧的经济消耗与回收口径，当前版本包含锻造台、合成、打造、分解；红装洗练本版本先不做。旧正式配置观察中的升级、打孔、鉴定已经废弃。映射装备副本产出另见 `03_沉淀MD/经济/05_玩法_映射副本经济沉淀-2026-07-08.md`；2026-07-09 爬塔新版新增挂机产出装备打造主材/副材，作为打造材料新增来源，产能公式见爬塔篇；正式 ItemId 为主材 `1080-1151`、副材 `1152-1155`。映射装备属性数值另见 `03_沉淀MD/养成/映射装备养成数值沉淀-2026-07-07.md`，完整配置落地方法见 `03_沉淀MD/养成/映射装备配置落地方式-2026-07-13.md`。

## 结论

映射装备养成消耗当前应以 `design/映射装备系统数值设计文档-2026-07-03.md`、2026-07-06 合成 8 档基础和本篇 2026-07-09 锻造台/打造改动为主口径，不以当前 SVN 旧正式配置观察为主口径。

最新设计已经把映射装备从“经验升级型装备”改为“掉落固定等级 + 品质随机 + 锻造台 + 合成 + 打造”的长线随机养成系统。当前版本经济消耗核心是四条线：

1. 锻造台：账号第 2 天随映射装备系统开放，最高 60 级，只由分解和合成提供经验；打造不给经验。锻造台只影响合成和打造获得最高品质的概率，不影响装备等级概率。Lv1→60 总经验为 94,500。
2. 合成：消耗 9 件同品质装备和金币，产出 1 件随机部位装备；产物品质按投入品质和锻造台等级决定。
3. 打造：通关映射装备第 6 层（基础 `LevelId=250061`）后开启；消耗主材 x1、对应 2 种副材和金币。没有打造石、没有图纸，纯靠主材决定装备大类、等级和基础品质池。合成开放口径不变。
4. 分解：回收金币并提供锻造台经验；只有红装额外产出装备高级材料，也就是高阶零件(23) x1。

重要边界：
- 最新设计口径下，映射装备不再升级；旧 `SpecialEquipmentLvUp.xlsx` 的经验升级消耗废弃。
- 最新设计口径下，本篇不承接旧打孔、鉴定、宝石页签；打孔、鉴定当前版本全部废弃。
- 映射之匙(25) 是映射装备副本入场消耗，不是养成消耗。本篇只做引用，不展开钥匙来源、购买、上限和周期。
- 装备高级材料当前复用高阶零件(23)。低阶零件(24)仍只作为旧正式配置观察，不进入当前版本养成消耗。

## 合成消耗

基础规则：

| 项 | 最新口径 |
|---|---|
| 投入 | 9 件同品质装备 |
| 产出 | 1 件按品质池判定的随机部位装备 |
| 部位 | 8 个装备位置均分 |
| 成功率 | 100% |
| 产物等级 | 按合成档的等级池随机；首档固定 10 级 |
| 产物品质 | 只和投入装备品质、锻造台等级有关，不和装备等级挂钩 |
| 锻造台影响 | 只提高获得最高品质的概率 |
| 副属性 | 重新随机，不继承材料副属性；副属性永不重复 |
| 金币 | 基础金币 x 品质金币系数 |

合成品质池：

| 投入品质 | 产物品质池 |
|---|---|
| 绿 | 蓝 / 紫 |
| 蓝 | 紫 / 金 |
| 紫 | 紫 / 金 / 红 |
| 金 | 金 / 红 |
| 红 | 红 |

合成最高品质概率公式：

```text
绿合紫 = 8% + 17% * (锻造台等级 - 1) / 59
蓝合金 = 5% + 15% * (锻造台等级 - 1) / 59
紫合金 = 30% + 30% * (锻造台等级 - 1) / 59
紫合红 = 1% + 2% * (锻造台等级 - 1) / 59
金合红 = 20% + 20% * (锻造台等级 - 1) / 59
红合红 = 100%
```
