# 05_验算核算

这里放最终验算与核算表。

验算范围：

- 输入快照。
- 预算核算。
- 曲线验算。
- 消耗核算。
- 产出核算。
- 战力核算。
- 异常检查。
- 结论状态。

当前收口：

- `动态验算总表.xlsx`：每次运行从当前源表、MD 和目标 `04` 实时生成的总门禁；是发布判定依据。
- `scripts/validate_rebuild.py`：支持 `--target <staging或04>`，校验预期文件集合、工作簿可读性、外链、公式错误及输入门禁。
- `vgame-config-mapping-report.json`：配置映射总表本次 Schema 快照、注册覆盖、异常与源文件指纹；不含业务配置数据。
- `正式交付收口总表.xlsx`：四条主链路总入口。
- `养成/养成验算核算.xlsx`
- `经济/经济验算核算.xlsx`
- `节奏/节奏验算核算.xlsx`
- `战斗/战斗验算核算.xlsx`

使用规则：

- 验算与核算表不作为手改源。
- 如果经济、节奏或产出尚未确认，要标记为“待确认”，不能假装闭环。
- 每个终稿参数和公式都要能回到 MD 参数 ID 或对应系统沉淀章节；源表、正式配置和生成器只作证据或验证链。
- 必须检查 MD → `04_数值文档` 映射完整率、无映射硬编码、终稿版本漂移，以及外部链接/数据连接。
- 旧 5 张原始表只作为复现对照基准，不修改。
- 静态模块验算表只作历史阅读；发布必须以本次动态验算的退出码和 JSON/Excel 报告为准。
- 配置落地另需通过批次审批、公式保护、引用校验和 Luban 导出门禁；数值文档验算通过不等于获准写正式配置。
