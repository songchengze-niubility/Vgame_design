工作流：使用 Codex 已绑定的 Python/Node，先运行 `prepare.py` 提取只读正式证据与哈希，再运行 `update.mjs --inspect` 看原表。按 Spreadsheets 技能记录编辑操作后运行 `update.mjs`，结果先写本目录 `outputs/`。运行 `validate.py`，检查预览，再按报告哈希将四份结果复制到报告的 `out` 目录，最后运行 `validate.py --published`。
