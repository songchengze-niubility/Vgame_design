# 表结构说明

本文件记录 `01_源表` 的推荐字段。后续如源表结构调整，需要同步更新这里。

单系统参数不再使用 Excel 参数表维护，统一遵循 `MD参数契约.md`；本文件只定义全局源表结构。

## 源表清单

| 文件 | 用途 |
|---|---|
| `术语表.xlsx` | 统一属性、资源、玩法、系统、单位和 ID 命名 |
| `属性定价.xlsx` | 统一属性价值、等价换算、战力换算 |
| `道具定价.xlsx` | 统一资源和道具价值 |
| `养成属性分配.xlsx` | 统一养成模块属性预算、投放预算与占比 |
| `战斗属性.xlsx` | 统一战斗属性定义、数据类型、默认值、展示位置与前后端计算边界 |
| `战斗公式.xlsx` | 统一战斗计算规则、投放属性数值和怪物标准模型 |
| `经济口径.xlsx` | 统一产出来源、周期、毕业目标、稀缺度 |
| `节奏口径.xlsx` | 统一开放节奏、等级锚点、章节锚点 |

## `养成属性分配.xlsx` 页签

| 页签 | 用途 | 读写规则 |
|---|---|---|
| `模块规划` | 记录养成模块属性预算、投放预算与模块占比 | 作为养成总预算入口，不写具体角色或专武个体比例 |
| `角色属性分配` | 记录角色职业、稀有度、单角色生命/攻击/防御属性比例 | 作为角色属性比例入口；攻击为单一攻击属性，不再拆物理攻击/魔法攻击 |
| `专武属性分配` | 记录专武生命/攻击/防御属性比例和二级属性入口 | 作为专武属性比例入口；引用 `角色属性分配` 的职业与稀有度底座 |

历史配置字段中的物理攻击、魔法攻击及其百分比加成，进入新框架时统一合并为 `攻击` 与 `攻击百分比`；若表内同时保留兼容字段和统一字段，AI 只能按统一口径读一次，不能重复叠加。随机池合并时权重不累加，同类随机池内各属性保持同权。

## 字段原则

- 所有百分比字段在表头标明单位，例如 `数值(%)` 或 `系数`。
- 所有 ID 字段使用稳定英文或拼音，不直接依赖显示名。
- 所有人工待填字段保留空白，不用生成器猜测。
- 所有备注字段写明来源或设计意图。
