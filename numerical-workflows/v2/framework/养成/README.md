# 养成数值框架

> 养成线的完整参数化框架。参数与公式维护在 MD，最终数值文档全量派生、不得作为参数源；旧参数工作簿已删除。

## 属性公式

```
最终属性 = 裸体 × (1 + 升星%) × (1 + 二级基础属性%) + 额外
```

| 层 | 包含模块 | 说明 |
|---|---|---|
| 裸体属性 | 角色初始 + 升级 + 升阶 | 被百分比加成；星盘基础属性投放已删除 |
| 额外属性 | 专武 + 旅券 + 映射装备 + 房车升级 | 不被百分比加成 |
| 升星乘区 | 升星(星3+星5各0.15) | 独立乘区，乘裸体 |
| 二级属性%乘区 | 各模块给的生命%/攻击%等 | 独立乘区，乘裸体 |

> 分类和投放预算以 `01_源表/养成属性分配.xlsx` 为准。

## 改数流程

1. 找到要改的稳定参数 ID → 更新共享或养成参数基线 MD，并记录系统沉淀。
2. 修改对应 `04_数值文档/养成/*.xlsx`；最后阶段无需回写旧参数表。
3. 只运行受影响生成器/验算；需要全量回归时再执行 `python run_all.py`。
4. 检查 MD、最终文档和验算结果一致。

## 各角色属性由武将系数决定

```
角色属性 = 标准人 × 模块投放系数 × 职业比 × 伤害类型比 × 微调比 × 品质比
```

- 职业(9种): 坦克(输出/生命/防御)、输出(射手/战士/法师)、辅助(均衡/攻击/生命)
- 伤害类型: 物理/魔法/混合只作为伤害类型与历史参数兼容；攻击为单一攻击属性，不再拆物理攻击/魔法攻击
- 品质: SSR=1, SR=0.8, R=0.7
- 微调: 生成输出按生命/攻击/防御三项展示；MD 参数块保留历史物攻/魔攻微调列，统一攻击取旧物攻微调作为兼容源
