## 这是什么

一句话：`numerical-workflows/v2/` 是咱们数值的自动化生产线。

你在 `01_源表/`（全局口径、公式、定价那些 Excel）和 `03_沉淀MD/`（各系统的参数和裁决记录）里改设计，然后跑一条命令，它会从零重算全部数值、组装出 43 份 QA 用的交付 Excel（在 `04_数值文档/`），自动验算，门禁全过之后发布。再往后还接了一条"配置粘贴包"链路，把数值落进 SVN 正式配置。

它解决的老问题：一个数改了，没人说得清它从哪来、QA 手上的表是不是最新、正式配置跟设计有没有分叉。现在这条链上每一步都能查回去。

## 先记住三条，别问为什么

1. **`04_数值文档/` 是结果，不是来源。** 别从里面拷数回源表，也别手改里面的 Excel——下次重建就没了。要改数，去改 `01_源表/` 或 `03_沉淀MD/`，然后重跑。
2. **SVN 正式配置默认只读。** 写正式配置只有一条路：粘贴包 + 按批次审批，流程文档在 `framework/02_AI规则/配置映射与正式落表流程.md`。Luban 导出的东西（server_json 那些）永远别直接碰。
3. **改完源表直接跑生产会被拦下来。** G1 门禁查"源表 ↔ MD 零差异"，拦你是因为你还没把源表改动同步进 MD。这是设计如此。先跑下面"重新出版"那四步里的同步命令，再跑生产。

哦对，提交前跑 `scripts/check.ps1`，这个习惯养成就好。

## 平时怎么用

**只是看数、或者给 QA 发表**：直接用 `04_数值文档/` 里的 Excel；要速查总簿就用 `QA速查总簿/build_qa_quickbook.py` 重新出一本（脚本现在要求先设好 `VGAME_CONFIG_DATAS` 环境变量，本机一般由 `design-harness.env.bat` 注入）。不用跑生产。

**改了设计，要重新出版**：改了源表的话，按这个顺序来（只改了 MD 可以跳前两步）：

```powershell
python numerical-workflows/v2/framework/02_AI规则/sync_global_sources_to_md.py --write --report output/numerical-production-workflow-v2/source-md-authority-sync.json
python scripts/numerical-knowledge/sync_parameter_baselines.py --json-report output/numerical-production-workflow-v2/parameter-baseline-sync.json
python scripts/numerical-workflows/refresh_manifest.py
python scripts/numerical-workflows/run_production.py
```

`run_production.py` 跑一次几分钟：它先把 framework（不含 04）和 legacy 工作簿拷进 `output/` 下的隔离区，从零重算 23 个生成任务，组装 43 份交付，独立验算，全部通过才把 `04_数值文档/` 整个换掉，旧版归档进 `output/previous-published/`。**中途任何一步挂了都不会动已发布的东西**，所以随便跑，跑不坏。

想试跑不发布，加 `--no-publish`。跑完看 `output/numerical-production-workflow-v2/latest-production-report.json`：`status=PASS`、`finalWorkbookCount=43`，就是成了。另外报告里 `independentFinalAcceptance` 永远是 `PENDING`——不是 bug，意思是每次发布本来就该有人独立验收一遍。

**判断手上的 04 过没过期**：看 `latest-production-report.json` 的 `finishedAt`，再比一下 `01_源表/`、`03_沉淀MD/` 里文件的修改时间。输入比运行时间新，就是过期了。（我走的时候正是这种状态，下面细说。）

**落表到 SVN**：链路是 配置草案 → 预检 → 粘贴包 → 用户按批次批准 → 备份后写入 Datas → Luban 导出 → 回写落地回执。每个历史批次（CHG008~CHG057）的落表前备份、候选备份和验算 json 都在 `05_验算核算/` 和 `06_最终配置/` 里——查"当时为什么这么落"，先去那翻，再去翻对应 MD。

**换电脑/新环境**：先跑 `驾驭工程/配置本机路径.bat` 和 `驾驭工程/一键安装.bat`，完整流程看仓库根的 `新人上手指南.md`。`VGAME_CONFIG_DATAS` 这些都在本机 env 文件里，不随仓库走，权限要提前申请。

## 我踩过的坑，你们别再踩

- 生产挂了先去 `output/.../runs/<run-id>/reports/` 翻 log，每一步都有，别瞎猜。
- 发布 04 的时候，把打开着的交付 Excel 都关掉。被占用时运行器会退化成逐文件替换（能回滚），但没必要冒这个险。
- 文本文件哈希按 LF 归一化算，Excel 按原始字节算——别去"格式化"生产链里的文本文件，哈希会炸。
- 专武的源页删了，但裁决要求兼容一个大版本，专武终稿是从冻结的参数 MD 生成的。别想着把源页恢复回来，也别把旧消耗自动迁去收容物。
- 节奏那边公式缓存缺失时保留 MD 值，是裁决过的，别用空值覆盖。
- 想绕过粘贴包直接改正式配置？死心吧，三重锁是故意的，绕过去等于把可追溯性全丢了。
