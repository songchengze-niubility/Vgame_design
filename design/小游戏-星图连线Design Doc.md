## 背景与目标

### 背景

主线章节间需要轻度过渡玩法调节节奏。星海在夜间露营时仰望星空，用手指描摹星座图案，营造宁静的旅途氛围。

### 目标

提供1-3分钟的一笔画连线益智玩法，作为主线关卡内的分支关卡，降低连续战斗疲劳感。

### 非目标

- 不涉及PVP
- 不涉及经济产出重构
- 评价档位不影响后续剧情分支

## 核心规则

### R-01: 触发与进入

- **触发条件**：主线关卡内分支节点出现，玩家可选择进入或跳过
- **前置限制**：无（可跳过，不阻断主线推进）
- **操作流程**：点击分支节点 → 进入小游戏界面 → 开始游戏
- **状态变化**：关卡状态标记为"已进入"
- **UI 反馈**：分支节点以星座图标标识，带"可跳过"提示
- **异常边界**：玩家选择跳过则直接继续主线，无惩罚
- **落地点**：`level.xlsx`（LevelType 标记为小游戏分支） + `UIlevel.xlsx`

### R-02: 连线判定与胜负

- **触发条件**：玩家从起始星点开始拖拽
- **前置限制**：必须从指定起始星点出发
- **操作流程**：拖拽经过星点 → 连通所有星点形成星座图案 → 判定通关
- **状态变化**：星点逐个点亮；通关后关卡标记"已通关"
- **UI 反馈**：连线为金色光线带尾迹粒子；完成后星座图案整体亮起
- **异常边界**：路径重复或断开时连线变红提示，可重新拖拽
- **落地点**：小游戏逻辑模块

### R-03: 干扰机制

- **触发条件**：Lv.2及以上关卡
- **前置限制**：无
- **操作流程**：流星干扰点定时闪烁消失，玩家需避开消失时机经过
- **状态变化**：流星点按周期显现/消失
- **UI 反馈**：流星点消失时半透明，显现时正常亮度
- **异常边界**：经过消失中的流星点不判定为连通
- **落地点**：小游戏逻辑模块

### R-04: 评价与重复游玩

- **触发条件**：通关结算时
- **前置限制**：无
- **操作流程**：根据剩余时间和连线流畅度计算评价 → 显示S/A/B/C档位
- **状态变化**：记录历史最佳评价
- **UI 反馈**：结算界面显示评价和得分
- **异常边界**：评价仅记录展示，不影响剧情分支
- **落地点**：小游戏评价模块
- **重复游玩**：通关后可在关卡界面重新进入，支持刷新评价

## 关卡递进设计

| 梯度 | 星点数 | 新增要素 |
|------|--------|----------|
| Lv.1 入门 | 5个星点 | 纯一笔画，只有一条正确路径，无干扰 |
| Lv.2 初级 | 7个星点 | 加入1个"流星干扰点"（定时闪烁消失2秒，需要避开该时机经过） |
| Lv.3 中级 | 9个星点 | 多条可行路径但只有1条能形成正确星座图案；加入方向约束（某些连线必须从左到右） |
| Lv.4 高级 | 12个星点 | 加入"暗星"（需先经过相邻星点才会显现）；流星干扰频率提升 |
| Lv.5 挑战 | 15个星点 | 星点缓慢漂移（模拟星空转动），需要在移动中完成连线 |

## 数值框架

| 参数 | 数值 |
|------|------|
| 基础时限 | Lv.1: 20s / Lv.2: 25s / Lv.3: 35s / Lv.4: 45s / Lv.5: 60s |
| 流星闪烁周期 | 显现3s → 消失2s → 显现3s（循环） |
| 星点漂移速度(Lv.5) | 每秒移动5-8px（屏幕宽度960px基准） |
| 得分计算 | 基础分100 + 剩余时间×5 + 连线流畅度加成（无回撤×1.5倍） |
| 评价档位 | S≥200 / A≥150 / B≥100 / C<100 |

## 美术风格参考

- **背景**：深蓝-靛紫渐变夜空，带有柔和的银河粒子流动效果
- **星点**：白色核心 + 淡金色光晕脉动（半径约12px），未连接时缓慢呼吸闪烁
- **连线**：玩家拖拽时为明亮的金色光线（带尾迹粒子），完成后变为柔和的星座连线（淡蓝白色）
- **UI布局**：全屏沉浸式，左上角小型计时器（环形倒计时），右下角星座名称提示
- **完成特效**：星座图案整体亮起 → 放大 → 化为一段文字描述（如"猎户座——指引旅人方向的灯塔"）
- **参考调性**：类似《纪念碑谷》的宁静感 + 星空APP的视觉美感

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 玩家不知道从哪个星点开始 | 中 | 低 | 起始星点有脉动高亮提示 |
| 漂移星点导致操作困难 | 中 | 中 | Lv.5漂移速度控制在可预判范围内 |
| 跳过后玩家不再回来体验 | 中 | 低 | 分支节点保留可回访入口 |
