## 背景与目标

### 背景

主线章节间需要轻度过渡玩法调节节奏。星海在夜间露营时仰望星空，用手指描摹星座图案，营造宁静的旅途氛围。

### 目标

提供1-3分钟的一笔画连线益智玩法，作为主线关卡内的分支关卡，降低连续战斗疲劳感。

### 设计意图与体验目标

- **节奏定位**：作为"宁静沉浸型"调节，降低战斗疲劳，氛围优先，适合放在连续战斗后让玩家静下来。
- **核心爽点**：星座图案成形+化为文字描述的叙事浪漫——连线完成的瞬间，星座亮起并化作"猎户座——指引旅人方向的灯塔"这样的诗意描述，把解谜升华为情感体验。
- **简单规则+干扰递进**：一笔画约束简单易懂，难度靠"干扰机制"（流星/暗星/漂移）而非复杂规则递进，认知门槛低。
- **动态操作感**：漂移星点(Lv.5)模拟星空转动，增加动态操作感，但速度控制在可预判范围，非纯随机不可控。
- **设计取舍**：选择一笔画而非多点连线，是因为"不抬笔连续经过"的规则直觉化，无需教学；星座描摹的叙事包装让纯逻辑解谜获得情感落点。

### 非目标

- 不涉及PVP
- 不涉及经济产出重构
- 评价档位不影响后续剧情分支

## 核心规则

### 交互与容错总则

- **起点提示**：起始星点有脉动高亮提示，避免玩家"不知道从哪开始"的茫然；右下角有星座名称提示目标。
- **无惩罚重试**：路径重复或断开时连线变红提示，可重新拖拽，无次数限制无扣分，鼓励反复尝试不同路径。
- **干扰可规避**：流星干扰点显现3s/消失2s循环，消失时不判定连通但显现时可经过，给玩家明确的规避窗口而非随机惩罚。
- **暗星引导探索**：暗星需先经过相邻星点才显现，引导"逐步探索"而非盲连，显现后即可接入路径。
- **漂移可预判**：Lv.5星点漂移速度5-8px/s，在可预判范围内，玩家可提前判断落点，非纯随机不可控。
- **保底兜底**：评价仅记录展示，不影响剧情分支；跳过无惩罚，尊重不想体验的玩家。

### R-01: 触发与进入

- **触发条件**：主线关卡内分支节点出现，玩家可选择进入或跳过
- **前置限制**：无（可跳过，不阻断主线推进）
- **操作流程**：点击分支节点 → 进入小游戏界面 → 开始游戏
- **状态变化**：关卡状态标记为"已进入"
- **UI 反馈**：分支节点以星座图标标识，带"可跳过"提示
- **异常边界**：玩家选择跳过则直接继续主线，无惩罚
- **落地点**：`level.xlsx`（LevelType 标记为小游戏分支） + `UIlevel.xlsx`

### R-02: 连线判定与胜负

- **触发条件**：玩家从起始星点开始拖拽
- **前置限制**：必须从指定起始星点出发
- **操作流程**：拖拽经过星点 → 连通所有星点形成星座图案 → 判定通关
- **状态变化**：星点逐个点亮；通关后关卡标记"已通关"
- **UI 反馈**：连线为金色光线带尾迹粒子；完成后星座图案整体亮起
- **异常边界**：路径重复或断开时连线变红提示，可重新拖拽
- **落地点**：小游戏逻辑模块

### R-03: 干扰机制

- **触发条件**：Lv.2及以上关卡
- **前置限制**：无
- **操作流程**：流星干扰点定时闪烁消失，玩家需避开消失时机经过
- **状态变化**：流星点按周期显现/消失
- **UI 反馈**：流星点消失时半透明，显现时正常亮度
- **异常边界**：经过消失中的流星点不判定为连通
- **落地点**：小游戏逻辑模块

### R-04: 评价与重复游玩

- **触发条件**：通关结算时
- **前置限制**：无
- **操作流程**：根据剩余时间和连线流畅度计算评价 → 显示S/A/B/C档位
- **状态变化**：记录历史最佳评价
- **UI 反馈**：结算界面显示评价和得分
- **异常边界**：评价仅记录展示，不影响剧情分支
- **落地点**：小游戏评价模块
- **重复游玩**：通关后可在关卡界面重新进入，支持刷新评价

## 关卡递进设计

| 梯度 | 星点数 | 新增要素 |
|------|--------|----------|
| Lv.1 入门 | 5个星点 | 纯一笔画，只有一条正确路径，无干扰 |
| Lv.2 初级 | 7个星点 | 加入1个"流星干扰点"（定时闪烁消失2秒，需要避开该时机经过） |
| Lv.3 中级 | 9个星点 | 多条可行路径但只有1条能形成正确星座图案；加入方向约束（某些连线必须从左到右） |
| Lv.4 高级 | 12个星点 | 加入"暗星"（需先经过相邻星点才会显现）；流星干扰频率提升 |
| Lv.5 挑战 | 15个星点 | 星点缓慢漂移（模拟星空转动），需要在移动中完成连线 |

## 数值框架

| 参数 | 数值 |
|------|------|
| 基础时限 | Lv.1: 20s / Lv.2: 25s / Lv.3: 35s / Lv.4: 45s / Lv.5: 60s |
| 流星闪烁周期 | 显现3s → 消失2s → 显现3s（循环） |
| 星点漂移速度(Lv.5) | 每秒移动5-8px（屏幕宽度960px基准） |
| 得分计算 | 基础分100 + 剩余时间×5 + 连线流畅度加成（无回撤×1.5倍） |
| 评价档位 | S≥200 / A≥150 / B≥100 / C<100 |

## 美术风格参考

- **背景**：深蓝-靛紫渐变夜空，带有柔和的银河粒子流动效果
- **星点**：白色核心 + 淡金色光晕脉动（半径约12px），未连接时缓慢呼吸闪烁
- **连线**：玩家拖拽时为明亮的金色光线（带尾迹粒子），完成后变为柔和的星座连线（淡蓝白色）
- **UI布局**：全屏沉浸式，左上角小型计时器（环形倒计时），右下角星座名称提示
- **完成特效**：星座图案整体亮起 → 放大 → 化为一段文字描述（如"猎户座——指引旅人方向的灯塔"）
- **参考调性**：类似《纪念碑谷》的宁静感 + 星空APP的视觉美感

## 玩法参考

- **参考对象**：**一笔画（Eulerian path）** 解谜类型——从起点不抬笔连续经过所有节点；近亲为 **Flow Free**（Big Duck Games，2012）的"规划路径连通全部节点"。
- **对应机制**：
  - 从起始星点拖拽连通所有星点 ↔ 一笔画经过所有节点
  - 路径重复/断开变红可重来 ↔ 一笔画不可重复边的约束
  - Lv.3 多可行路径但仅 1 条成正确图案 ↔ 一笔画的多解筛选
  - 流星干扰点定时闪烁需避开时机 ↔ 节点时序干扰变种
  - Lv.4 暗星需经相邻才显现 ↔ 隐藏节点触发显现
  - Lv.5 星点缓慢漂移需动态连线 ↔ 移动节点的一笔画变体
- **差异点**：以星座描摹叙事+宁静夜空氛围替代纯逻辑解谜包装；目标"形成星座图案"而非 Flow Free 的同色配对填满网格；定位可跳过章节过渡，规模 1-3 分钟。

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 玩家不知道从哪个星点开始 | 中 | 低 | 起始星点有脉动高亮提示 |
| 漂移星点导致操作困难 | 中 | 中 | Lv.5漂移速度控制在可预判范围内 |
| 跳过后玩家不再回来体验 | 中 | 低 | 分支节点保留可回访入口 |
