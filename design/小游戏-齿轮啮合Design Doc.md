## 背景与目标

### 背景

主线章节间需要轻度过渡玩法调节节奏。房车引擎核心齿轮组松动脱落，需要选择正确齿轮重新拼装传动链，展现旅途中的机械维护日常。

### 目标

提供1-2分钟的齿轮啮合益智玩法，作为主线关卡内的分支关卡，偏静态思考型调节节奏。

### 非目标

- 不涉及PVP
- 不涉及经济产出重构
- 评价档位不影响后续剧情分支

## 核心规则

### R-01: 触发与进入

- **触发条件**：主线关卡内分支节点出现，玩家可选择进入或跳过
- **前置限制**：无（可跳过，不阻断主线推进）
- **操作流程**：点击分支节点 → 进入小游戏界面 → 开始游戏
- **状态变化**：关卡状态标记为"已进入"
- **UI 反馈**：分支节点以齿轮图标标识，带"可跳过"提示
- **异常边界**：玩家选择跳过则直接继续主线，无惩罚
- **落地点**：`level.xlsx`（LevelType 标记为小游戏分支） + `UIlevel.xlsx`

### R-02: 齿轮选择与放置

- **触发条件**：玩家从备选齿轮托盘拖拽齿轮
- **前置限制**：相邻齿轮齿数必须不同（大带小或小带大，不能同尺寸相邻）
- **操作流程**：拖拽齿轮到空位 → 放入后自动判定啮合 → 全组齿轮联动转动且输出转向正确即通关
- **状态变化**：齿轮放入空位；放对时整组开始转动
- **UI 反馈**：放对时齿轮组联动转起来，有机械咬合视觉+音效；放错时齿轮弹出+扣1s
- **异常边界**：尺寸错误齿轮弹回，扣1s时间
- **落地点**：小游戏逻辑模块

### R-03: 转向与传动比约束

- **触发条件**：Lv.2及以上关卡
- **前置限制**：输出端齿轮转向必须符合指定方向（顺时针/逆时针）
- **操作流程**：玩家需计算齿轮链路的奇偶关系（相邻齿轮转向必定相反），选择正确数量和尺寸的齿轮使输出转向正确
- **状态变化**：传动比影响输出转速
- **UI 反馈**：右上角有转向目标指示（箭头图标）
- **异常边界**：转向错误时输出齿轮反向旋转，提示重新调整
- **落地点**：小游戏逻辑模块
- **转速规则**：大带小=加速(×1.5) / 小带大=减速(×0.67) / 同尺寸=同速（但不允许出现）
- **转向规则**：相邻齿轮转向必定相反（奇数位顺时针，偶数位逆时针）

### R-04: 干扰与磨损机制

- **触发条件**：Lv.3及以上出现损坏齿轮干扰；Lv.5出现磨损倒计时
- **前置限制**：无
- **操作流程**：
  - 损坏齿轮（Lv.3）：外观正常但有裂痕标记，放入会卡住系统，需取出重来
  - 双层齿轮（Lv.4）：一个轴上有大小两个齿轮同轴传动
  - 磨损倒计时（Lv.5）：齿轮运行后逐渐磨损，15s后需在磨损前完成整个链路搭建
- **状态变化**：损坏齿轮放入后系统卡住2s + 扣5s时间
- **UI 反馈**：损坏齿轮表面有明显裂纹发光（红色细线）；磨损齿轮逐渐变色
- **异常边界**：损坏齿轮可取出重新选择
- **落地点**：小游戏逻辑模块

### R-05: 评价与重复游玩

- **触发条件**：通关结算时
- **前置限制**：无
- **操作流程**：根据失误次数和剩余时间计算评价 → 显示S/A/B/C档位
- **状态变化**：记录历史最佳评价
- **UI 反馈**：结算界面显示评价和得分
- **异常边界**：C级（超时）给保底奖励；评价仅记录展示，不影响剧情分支
- **落地点**：小游戏评价模块
- **重复游玩**：通关后可在关卡界面重新进入，支持刷新评价

## 关卡递进设计

| 梯度 | 空位数 | 备选齿轮数 | 新增要素 |
|------|--------|------------|----------|
| Lv.1 入门 | 2 | 3（1个干扰） | 仅考虑尺寸匹配（大小相邻交替），无转向要求 |
| Lv.2 初级 | 3 | 5 | 加入转向约束（输出齿轮必须顺时针转），玩家需计算奇偶关系 |
| Lv.3 中级 | 4 | 7 | 加入"损坏齿轮"干扰项（外观正常但有裂痕标记，放入会卡住系统需取出重来）；加入传动比概念（转速匹配要求） |
| Lv.4 高级 | 5 | 9 | 加入"双层齿轮"（一个轴上有大小两个齿轮同轴传动）；传动路线出现分叉 |
| Lv.5 挑战 | 6 | 11 | 全部要素叠加；加入"磨损倒计时"——齿轮运行后逐渐磨损（15s后需在磨损前完成整个链路搭建） |

## 数值框架

| 参数 | 数值 |
|------|------|
| 时限 | Lv.1: 30s / Lv.2: 40s / Lv.3: 55s / Lv.4: 70s / Lv.5: 80s |
| 齿轮尺寸 | 小(8齿): 直径40px / 中(12齿): 直径60px / 大(16齿): 直径80px |
| 转速规则 | 大带小=加速(×1.5) / 小带大=减速(×0.67) / 同尺寸=同速（但不允许出现） |
| 转向规则 | 相邻齿轮转向必定相反（奇数位顺时针，偶数位逆时针） |
| 错误放入惩罚 | 损坏齿轮放入：系统卡住2s + 扣除5s时间；尺寸错误：弹出 + 扣1s |
| 得分计算 | 基础分100 + 剩余时间×5 + 零失误奖励150分 + 传动比完美匹配50分 |
| 评价档位 | S: 零失误且剩余时间>50% / A: ≤1失误通关 / B: 通关 / C: 超时（保底奖励） |

## 美术风格参考

- **背景**：引擎舱内部微距视角，深色金属底板有油渍质感，边缘有蒸汽/热气管道
- **齿轮**：青铜/黄铜质感，有精细的齿痕建模感；不同尺寸用不同颜色环标识（小=蓝环/中=绿环/大=金环）
- **损坏齿轮**：表面有明显裂纹发光（红色细线），仔细看可辨别
- **联动效果**：放对齿轮后立即开始转动，相邻齿轮咬合处有微小火花粒子（表示正常运转）
- **UI布局**：中央为齿轮安装区域（占60%），底部为备选齿轮托盘（水平滚动），右上角为转向目标指示（箭头图标）
- **完成特效**：全部接通 → 齿轮组加速转动 → 摄像头拉远展示整个引擎 → 引擎点火启动（震屏+光效爆发）
- **参考调性**：《机械迷城》的工业美感 + 钟表内部的精密感
