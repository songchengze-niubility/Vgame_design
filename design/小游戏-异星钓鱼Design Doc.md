## 背景与目标

### 背景

主线章节间需要轻度过渡玩法调节节奏。房车停靠在不同地貌的异星水域旁时，玩家可以选择在此垂钓片刻。每片水域都有自己独特的鱼群生态，钓起的成果会为旅途补充食材与素材。

### 目标

提供1-2分钟的轻度钓鱼玩法，作为主线关卡内的分支关卡。核心体验参考 AFK2 钓鱼：抛竿等待 → 起钩进入「张力控制」小玩法 → 把鱼耐力耗尽后收杆，兼顾宁静感与轻微操作张力。

### 设计意图与体验目标

- **节奏定位**：作为「舒缓缓冲型」调节，但比纯点击钓鱼多一层「按住/松开」的轻操作，放在战斗或小游戏之后缓冲，又不让玩家昏昏欲睡。
- **核心爽点**：把鱼的耐力条从满到空压到底的过程 + 最后收杆时的出水定格，把 AFK2 式的「控线博弈」浓缩成短小平滑的奖励循环。
- **低认知门槛**：规则复用现实钓鱼直觉（抛竿→等咬钩→起钩→遛鱼），起钩后的张力条绿/黄/红区间一眼可懂。
- **轻度收集乐趣**：异星鱼类图鉴提供长线收集目标，但不影响主线推进，仅作为趣味展示和小额奖励来源。
- **设计取舍**：选择张力条轻 QTE 而非纯点击收杆，是为了在不提高操作复杂度的前提下增加「与鱼博弈」的情绪起伏；但仍保持单指按住/松开、不引入鱼竿养成或鱼饵配装。

### 非目标

- 不涉及PVP
- 不涉及经济产出重构
- 评价档位不影响后续剧情分支
- 不引入复杂养成（如鱼竿升级、鱼饵系统、钓具稀有度）
- 不做开放大地图自由寻点（本期仅在分支节点内提供若干可选水域）

## 核心规则

### 交互与容错总则

- **单指操作闭环**：全程仅「点击抛竿 → 等待浮标 → 点击起钩 → 按住/松开收杆控张力」四个动作，不依赖多指或复杂手势。
- **张力条可读**：张力值用横向条展示，绿色为安全区、黄色为警告区、红色为断线区；安全区随鱼的挣扎左右移动，玩家需按住/松开让张力停在安全区。
- **断线不惩罚整局**：单条鱼断线仅损失本次鱼获，不扣总分、不结束游戏；玩家可立即再次抛竿。
- **遛鱼时长可控**：普通鱼约3-5s耗尽耐力，稀有鱼6-8s，传说鱼10-15s；单局总时长仍控制在1-2分钟内。
- **完美收杆奖励**：全程未进入红色区把鱼钓起，额外获得完美分加成，鼓励稳定控线。
- **保底兜底**：C级为参与保底，不影响剧情分支；跳过无惩罚。

### R-01: 触发与进入

- **触发条件**：主线关卡内分支节点出现，玩家可选择进入或跳过
- **前置限制**：无（可跳过，不阻断主线推进）
- **操作流程**：点击分支节点 → 进入小游戏界面 → 选择/随机本局水域 → 开始游戏
- **状态变化**：关卡状态标记为「已进入」
- **UI 反馈**：分支节点以鱼竿/水域图标标识，带「可跳过」提示
- **异常边界**：玩家选择跳过则直接继续主线，无惩罚
- **落地点**：`level.xlsx`（LevelType 标记为小游戏分支） + `UIlevel.xlsx`

### R-02: 抛竿与等待

- **触发条件**：玩家点击「抛竿」按钮
- **前置限制**：当前未处于咬钩/遛鱼过程中
- **操作流程**：点击 → 角色做出抛竿动作 → 浮标落点在水面随机位置 → 进入等待阶段
- **状态变化**：进入「等待」状态；随机生成咬钩事件
- **UI 反馈**：浮标随微波轻轻上下浮动；远处有微光水域效果
- **异常边界**：等待阶段点击非起钩区不触发任何操作；浮标始终保持在屏幕可视范围内
- **落地点**：小游戏逻辑模块

### R-03: 咬钩判定与起钩

- **触发条件**：等待阶段到达随机生成的咬钩时间点
- **前置限制**：浮标处于「可咬钩」状态
- **操作流程**：
  - 咬钩阶段：浮标先抖动0.3-0.5s，随后猛然沉入水中（起钩窗口1.0-1.5s）
  - 玩家在窗口期内点击起钩，进入「张力控制」遛鱼阶段
  - 未起钩或超时则鱼逃走，可立即再次抛竿
- **状态变化**：成功起钩后进入「遛鱼」状态；失败则返回等待/抛竿状态
- **UI 反馈**：起钩成功时画面轻微震动、鱼线拉直、张力条 UI 从底部滑入；起钩失败时浮标弹回水面
- **异常边界**：提前点击为空竿动作，不扣分；超时逃走无惩罚
- **落地点**：小游戏逻辑模块
- **咬钩规则**：每局固定触发3-5次咬钩事件，稀有/传说鱼咬钩会伴随更明显的水花预警

### R-04: 张力控制（遛鱼）

- **触发条件**：成功起钩后
- **前置限制**：无
- **操作流程**：
  - 张力条横向显示，左侧为0张力，右侧为满张力
  - 玩家长按「收杆」按钮张力持续上升，松开则张力自然下降
  - 安全区（绿色）在张力条上移动，鱼挣扎激烈时安全区会快速移动或暂时缩小
  - 玩家需让张力指针始终保持在安全区内，鱼耐力条会缓慢下降
  - 鱼耐力清空则成功钓起；张力进入红色区累计超过0.5s则断线跑鱼
- **状态变化**：耐力清空→累计分数、图鉴+1、返回等待；断线→无得分、可再次抛竿
- **UI 反馈**：
  - 张力指针在安全区时为绿色光效，接近红色区时变为黄色警告
  - 鱼挣扎时屏幕轻微震动，鱼线有绷紧动画
  - 耐力条在张力条上方，随时间/张力稳定性减少
- **异常边界**：张力刚到红色区立即松开可挽回；安全区移出屏幕范围时仍可在边缘极限控线
- **落地点**：小游戏逻辑模块
- **张力规则**：
  - 长按收杆：张力每秒+40
  - 松开自然回落：张力每秒-30
  - 安全区宽度：普通鱼占张力条40% / 稀有鱼30% / 传说鱼20%
  - 安全区移动速度：普通鱼5点/s / 稀有鱼10点/s / 传说鱼15点/s
  - 红色断线阈值：张力>90，且累计停留超0.5s
  - 完美收杆：钓起全程从未进入红色区

### R-05: 鱼类稀有度与分数

- **触发条件**：成功把鱼耐力耗尽并钓起后
- **前置限制**：无
- **操作流程**：根据本局随机池抽取一条鱼，按稀有度给予基础分、完美收杆加成和图鉴解锁
- **状态变化**：分数累加；图鉴中该鱼解锁/计数+1
- **UI 反馈**：鱼的立绘从水面弹出并旋转展示，屏幕边缘显示本次得分；完美收杆额外显示「Perfect」徽章
- **异常边界**：图鉴已解锁的鱼重复钓起仅增加计数，不重复解锁动画
- **落地点**：小游戏逻辑模块
- **鱼类分档**：
  - 普通鱼（荧光鲫鱼/气泡虾）：基础+50分，遛鱼3-5s，出现概率60%
  - 稀有鱼（晶鳞鲈/星尾鳗）：基础+120分，遛鱼6-8s，出现概率30%
  - 传说鱼（虚空鲸幼体/彩虹磷鱼）：基础+300分，遛鱼10-15s，出现概率10%
- **完美收杆加成**：基础分×1.3（仅对该条鱼的得分生效）

### R-06: 评价与重复游玩

- **触发条件**：倒计时结束结算时
- **前置限制**：无
- **操作流程**：根据累计分数计算评价 → 显示S/A/B/C档位
- **状态变化**：记录历史最佳评价；图鉴状态保存
- **UI 反馈**：结算界面显示评价、分数、钓起鱼种列表、图鉴解锁进度和完美收杆次数
- **异常边界**：C级（未达标）仍给基础奖励；评价仅记录展示，不影响剧情分支
- **落地点**：小游戏评价模块
- **重复游玩**：通关后可在关卡界面重新进入，支持刷新评价和补充图鉴

## 关卡递进设计

| 梯度 | 时长 | 可钓鱼次数 | 水域与新增要素 |
|------|------|------------|----------------|
| Lv.1 入门 | 60s | 3-4次 | 岸边浅滩：只有普通鱼；安全区宽且移动慢；无特殊干扰 |
| Lv.2 初级 | 70s | 4次 | 荧光溪谷：加入稀有鱼；安全区移动速度提升；偶尔有微波扰动浮标 |
| Lv.3 中级 | 80s | 4-5次 | 星尘湖心：加入传说鱼；传说鱼安全区窄且移动快；加入「暗流」——安全区会突然反向移动 |
| Lv.4 高级 | 90s | 5次 | 双月湿地：普通/稀有/传说鱼混池；暗流频率提升；传说鱼出现概率提升至12% |
| Lv.5 挑战 | 100s | 5次 | 虚空海沟：传说鱼出现概率15%；安全区整体宽度再降10%；最后20秒进入「鱼群活跃期」，咬钩更频繁但张力更难控制 |

## 美术风格参考

- **背景**：异星水域——水面呈淡紫色并带荧光涟漪，远处有发光的浮岛和双月倒影，岸边停着房车一角，氛围宁静
- **钓点选择**：进入小游戏后顶部有水域名称与图标切换（浅滩/溪谷/湖心/湿地/海沟），不同水域背景色调略有差异
- **浮标**：半透明能量球浮标，咬钩时发出脉冲白光，下沉时拖出细长光尾
- **张力条 UI**：横向能量条，绿色安全区会动态移动，张力指针在条上滑动；张力接近红色时指针发光警告
- **鱼类设计**：
  - 荧光鲫鱼：青绿色半透明身体，内部有发光骨架
  - 气泡虾：橙红色外壳，被钓起时会喷出小气泡
  - 晶鳞鲈：银色大鱼，鳞片像碎钻反射星光
  - 星尾鳗：紫色鳗鱼，尾巴呈星形发光
  - 虚空鲸幼体：深蓝色半透明幼鲸，被钓起时有星空粒子特效
  - 彩虹磷鱼：全身七彩渐变，出水时撒落光点
- **角色表现**：星海或大暑坐在岸边持有能量钓竿，起钩时有后仰动作，张力高时手臂微微颤抖，钓到传说鱼时露出惊讶小表情
- **完成特效**：倒计时结束 → 所有钓起的鱼在画面下方排列成一排 → 角色举起最大的一条做展示动作 → 轻微闪光
- **UI布局**：全屏沉浸水域，张力条在屏幕下方居中，分数在顶部居中，右下角显示剩余时间和本次图鉴解锁提示
- **参考调性**：AFK Journey 钓鱼的张力控线博弈 + 《动物森友会》的宁静收集感 + 科幻异星水域的视觉新鲜感

## 玩法参考

- **参考对象**：**AFK Journey（剑与远征：启程）**钓鱼玩法——在不同水域抛竿、观察浮标起钩、进入张力控制小游戏遛鱼、收集鱼类图鉴。
- **参考对象**：**Animal Crossing（动物森友会）**钓鱼玩法——宁静等待、收集图鉴、鱼种稀有度分布。
- **对应机制**：
  - 抛竿等待 + 浮标起钩 ↔ AFK Journey / 动森核心钓鱼循环
  - 张力条「按住收杆/松开泄力」 ↔ AFK Journey 遛鱼博弈
  - 安全区随鱼挣扎移动/缩小 ↔ AFK Journey 高品质鱼的挣扎表现
  - 普通/稀有/传说鱼分档 + 图鉴收集 ↔ AFK Journey 鱼种与图鉴奖励
- **差异点**：AFK Journey 钓鱼有更长线的养成（鱼竿、鱼饵、天赋）和开放大地图钓点；本玩法为1-2分钟分支关卡，保留核心张力博弈但去除养成与配装，让体验足够轻量。

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 张力控制对休闲玩家偏难 | 中 | 中 | 安全区较宽、断线阈值0.5s缓冲、普通鱼极易成功；熟悉后可挑战传说鱼 |
| 等待阶段无聊 | 中 | 中 | 咬钩间隔短；背景有微动态和鱼影游过；可提前观察水域环境 |
| 传说鱼遛鱼时长过长 | 低 | 中 | 传说鱼10-15s，且随等级提升；可调整 |
| 图鉴收集无动力 | 低 | 低 | 图鉴仅作展示+小额解锁奖励，不做强制目标 |
