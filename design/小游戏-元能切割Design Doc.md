## 背景与目标

### 背景

主线章节间需要轻度过渡玩法调节节奏。途经异星果林补给站，星海用元能光刃帮大暑切开水果分给队友，展现旅途中的轻松日常。

### 目标

提供1分钟的切水果式反应玩法，作为主线关卡内的分支关卡，快节奏释放压力。

### 设计意图与体验目标

- **节奏定位**：作为"快节奏释放型"调节，放在慢节奏叙事段落后提神，用爽快操作对冲前面的沉闷。
- **核心爽点**：一刀多切的combo倍率爆发 + 元能结晶果触发慢动作后的高分收割窗口，形成"积累→爆发"的爽感节奏。
- **判断张力**：危险物（腐蚀果/薯片）制造"该切不该切"的瞬时判断，把纯反应玩法升级为"反应+决策"。
- **情绪收尾**：操作结束后角色围过来分食的治愈动画，对冲过程中的紧张，回归旅途日常氛围，避免玩家带着亢奋情绪进入下一段剧情。
- **设计取舍**：保留切水果核心手感但替换为异星水果+元能光刃美术，用"薯片乱入"角色向搞笑惩罚替代炸弹的直接失败感，降低挫败同时增加趣味。

### 非目标

- 不涉及PVP
- 不涉及经济产出重构
- 评价档位不影响后续剧情分支

## 核心规则

### 交互与容错总则

- **判定容错**：滑动轨迹与水果碰撞箱（圆形半径30px）相交即切中，容错圆大于视觉水果，避免擦边误判带来的"明明切到了"挫败。
- **漏切保护**：普通水果落出屏幕未切到不扣分，降低连续失误的滚雪球效应，玩家不会因前几个没切到而崩盘。
- **combo连续性**：combo仅被危险物（腐蚀果/薯片）打断，漏切普通水果不断combo，保护正反馈的连续性，鼓励大胆横切。
- **惩罚温和化**：薯片误切仅-20分+搞笑音效而非直接失败，用幽默化解挫败；腐蚀果-30分断combo但不结束游戏。
- **慢动作双赢**：元能结晶果的2s慢动作既是奖励（视觉爽感）也是高分窗口（方便刷combo），形成"切中→慢动作→收割"的正循环。
- **高难边界**：Lv.5果实风暴同屏上限10个，性能可控；幽灵果0.5s窗口可调，半透明但有微光提示，保证可预判。

### R-01: 触发与进入

- **触发条件**：主线关卡内分支节点出现，玩家可选择进入或跳过
- **前置限制**：无（可跳过，不阻断主线推进）
- **操作流程**：点击分支节点 → 进入小游戏界面 → 开始游戏
- **状态变化**：关卡状态标记为"已进入"
- **UI 反馈**：分支节点以光刃/水果图标标识，带"可跳过"提示
- **异常边界**：玩家选择跳过则直接继续主线，无惩罚
- **落地点**：`level.xlsx`（LevelType 标记为小游戏分支） + `UIlevel.xlsx`

### R-02: 切割操作与判定

- **触发条件**：水果从屏幕下方抛起
- **前置限制**：无
- **操作流程**：手指/鼠标滑动 → 滑动轨迹即为光刃路径 → 轨迹与水果碰撞箱相交即判定切中 → 达到目标分数即通关
- **状态变化**：水果被切开后分为两半向两侧飞出；分数累计
- **UI 反馈**：滑动时留下青白色能量刀痕（带消散粒子尾迹）；切开后果汁粒子溅射
- **异常边界**：水果落出屏幕未切到不扣分（普通水果）
- **落地点**：小游戏逻辑模块
- **切割判定**：滑动轨迹与水果碰撞箱（圆形，半径30px）相交即判定为切中

### R-03: 水果类型与Combo

- **触发条件**：游戏过程中水果生成
- **前置限制**：无
- **操作流程**：
  - 普通水果（晶化蜜瓜/星棘果/霜露莓）：切中+10分
  - 元能结晶果（Lv.3）：切中+25分，触发2s全屏慢动作
  - 连锁果（Lv.4）：蓝色光线串联2-3个水果，一刀切过所有才+50分，否则爆炸-15分
  - 幽灵果（Lv.5）：半透明，只在出现后0.5s内可切割+35分，之后变为腐蚀状态
- **状态变化**：一刀切多个触发combo倍率（2个×1.5 / 3个×2.0 / 4个+×3.0）
- **UI 反馈**：combo在右侧弹出带火焰特效
- **异常边界**：combo不因未切到普通水果而中断
- **落地点**：小游戏逻辑模块

### R-04: 危险物与薯片乱入

- **触发条件**：Lv.2及以上出现腐蚀果；Lv.3及以上出现薯片乱入
- **前置限制**：无
- **操作流程**：
  - 腐蚀果（暗紫色带刺）：切到-30分+断combo
  - 薯片乱入：萨摩耶薯片从屏幕底部跳起抢水果，切到-20分+搞笑音效
- **状态变化**：切到腐蚀果或薯片时combo归零
- **UI 反馈**：腐蚀果有绿色毒液滴落效果；薯片头顶有"!"气泡提示不能切
- **异常边界**：全程未切到薯片触发特殊成就
- **落地点**：小游戏逻辑模块

### R-05: 评价与重复游玩

- **触发条件**：时间结束结算时
- **前置限制**：无
- **操作流程**：根据最终分数计算评价 → 显示S/A/B/C档位
- **状态变化**：记录历史最佳评价
- **UI 反馈**：结算界面显示评价和得分
- **异常边界**：C级（未达标）仍给基础奖励；评价仅记录展示，不影响剧情分支
- **落地点**：小游戏评价模块
- **重复游玩**：通关后可在关卡界面重新进入，支持刷新评价

## 关卡递进设计

| 梯度 | 时长 | 新增要素 |
|------|------|----------|
| Lv.1 入门 | 30s | 仅普通水果（单个抛起），速度慢间隔大，无危险物 |
| Lv.2 初级 | 40s | 加入腐蚀果（暗紫色）需避开；水果开始2-3个同时抛起 |
| Lv.3 中级 | 50s | 加入元能结晶果（切中触发2s慢动作）；加入薯片乱入（不可切割）；抛起速度和角度随机性增大 |
| Lv.4 高级 | 55s | 加入"连锁果"（蓝色光线串联的2-3个水果，一刀切过所有才得分，否则爆炸扣分）；薯片出现频率提升 |
| Lv.5 挑战 | 60s | 加入"幽灵果"（半透明，只在出现后0.5s内可切割，之后变为腐蚀状态）；最后15秒为"果实风暴"——满屏水果+干扰物混合涌出 |

## 美术风格参考

- **背景**：果林补给站场景——远景有发光的异星果树，近景为木质摊位/箱子堆叠；柔和的暖光色调
- **光刃轨迹**：玩家滑动时留下明亮的青白色能量刀痕（宽约6px），带有消散粒子尾迹（0.3s淡出）
- **水果设计**（每种有独特造型）：
  - 晶化蜜瓜：翠绿色透明外壳，内部有晶体纹路，切开后内部是蓝色果肉
  - 星棘果：深紫色球体带金色斑点，切开后内部是橙色
  - 霜露莓：冰蓝色小颗粒串状，切开碎裂为多个小冰晶
  - 元能结晶果：全身发出脉冲白光，悬浮旋转
  - 腐蚀果：暗紫色带绿色毒液滴落效果，周围有烟雾
- **薯片乱入**：Q版萨摩耶从屏幕底部跳起，张嘴想吃水果，头顶有"!"气泡提示不能切
- **切割特效**：水果被切开后分为两半向两侧飞出 + 果汁粒子溅射（颜色对应水果内部颜色）
- **UI布局**：全屏沉浸游戏区，分数在顶部居中（大字），combo在右侧弹出（带火焰特效），底部有薄薄的进度条
- **完成特效**：时间结束 → 最后一刀的轨迹定格 → 所有切开的水果在桌上排列 → 角色围过来分食的Q版小动画
- **参考调性**：《水果忍者》核心手感 + 科幻异星水果的视觉新鲜感 + 治愈系收尾

## 玩法参考

- **参考对象**：**Fruit Ninja**（Halfbrick，2010，移动端）——滑动切割抛起水果、连击得分、避开炸弹的经典反应玩法。
- **对应机制**：
  - 滑动轨迹切割水果 ↔ Fruit Ninja 核心切划判定
  - Combo 一刀多切倍率 ↔ Fruit Ninja 连切 combo
  - 元能结晶果触发 2s 慢动作 ↔ Fruit Ninja 香蕉（倒计时慢动作）/石榴（高分爆发）等特效果
  - 腐蚀果/薯片不可切 ↔ Fruit Ninja 炸弹（切到扣分/断 combo）
  - 果实风暴满屏涌出 ↔ Fruit Ninja 后期高密度水果波
- **差异点**：用异星水果与元能光刃替换忍者刀光美术；引入"薯片乱入"角色向搞笑惩罚（-20+音效，非直接失败）；评价为 S/A/B/C 档而非 Fruit Ninja 的纯分数。
