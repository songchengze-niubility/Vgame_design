# 数值生产工作流单仓迁移 V2

## 目标

将旧数值框架的完整执行器、生成器、验算器、规则、参数 MD 与运行必需的人可编辑源输入纳入独立于 Vgame 客户端的 `D:/Vgame_design` Git 仓库，使数值生产不依赖外部数值目录。

## 权威边界

- 项目知识唯一入口仍为 `knowledge-base/README.md`。
- Skill 正文唯一来源仍为 `skills/`。
- 数值生产源码、运行输入和 44 份正式数值交付 Excel 均保存于 Git 管理的 `numerical-workflows/v2/`。
- 正式数值交付固定为 `numerical-workflows/v2/framework/04_数值文档/`；它是派生交付物，不是参数反向来源。
- 网页、索引、验算报告、配置镜像、历史发布归档与临时工作区均只写入 `output/`。
- 真实 SVN `Datas` 始终是可选、外部、只读配置证据；未经明确授权不得写入。

## 运行模式

1. 从 Git 管理的生产源创建全新隔离工作区。
2. 执行源表与 MD 一致性门禁。
3. 执行原 `run_all.py` 管理的 22 个生成任务。
4. 由本次生成物组装全新的 44 份数值终稿 staging。
5. 执行独立动态验算与正式目录门禁，未通过不得替换 Git 管理的 `framework/04_数值文档/`。
6. 仅在显式要求时执行配置镜像专项；真实配置依赖必须通过环境变量声明。

## 人工门禁

本迁移只证明仓库级可执行与自动门禁，不代替业务规则评审、真实配置写入授权和最终用户验收。
