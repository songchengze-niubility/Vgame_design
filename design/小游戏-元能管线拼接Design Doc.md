## 背景与目标

### 背景

主线章节间需要轻度过渡玩法调节节奏。房车能源系统管道老化破裂，需要重新规划元能传输路线，营造旅途中的维修日常感。

### 目标

提供1-3分钟的水管工式管道拼接益智玩法，作为主线关卡内的分支关卡。

### 设计意图与体验目标

- **节奏定位**：作为"路径规划型"调节，静态拼图为主，Lv.3+加入流动压力，在静与动之间形成节奏过渡。
- **核心爽点**：能量贯通全线的视觉反馈——接通瞬间青蓝色能量流从入口涌出贯通全线，配合引擎启动震动，强化"修通了"的机械实感。
- **流动即倒计时**：能量流动是"倒计时压力"的可视化，比纯数字计时更有沉浸感，玩家看到能量逼近断口自然产生紧迫感。
- **动态重规划**：腐蚀机制(Lv.4+)引入"计划被打乱"的变化性，迫使玩家临场调整，增加重玩差异。
- **设计取舍**：选择管道旋转拼接而非自由绘制，是因为网格+90°旋转提供了明确的解空间和操作确定性，降低操作歧义；流动可视化让"时间压力"具象为"能量逼近"的视觉叙事。

### 非目标

- 不涉及PVP
- 不涉及经济产出重构
- 评价档位不影响后续剧情分支

## 核心规则

### 交互与容错总则

- **操作确定性**：点击旋转90°，0.15s动画响应迅速，每次点击方向确定，无模糊旋转，操作可预期。
- **断流不失败**：能量流到断口处停止但不判定失败，玩家可继续调整管道，无惩罚性失败，鼓励反复试错。
- **腐蚀预警**：腐蚀有2s预警（格子变色闪烁），且不影响已接通段，保护玩家既有成果，给重规划时间。
- **锁定标识**：锁定管道用金色边框+锁链图标明确标识不可旋转，避免玩家误点无效操作。
- **低门槛评价**：评价B级仅需通关，无操作次数硬限制，降低完美主义压力；S/A才考查操作效率。
- **保底兜底**：C级（超时）给予保底，不阻断流程，评价仅记录展示。

### R-01: 触发与进入

- **触发条件**：主线关卡内分支节点出现，玩家可选择进入或跳过
- **前置限制**：无（可跳过，不阻断主线推进）
- **操作流程**：点击分支节点 → 进入小游戏界面 → 开始游戏
- **状态变化**：关卡状态标记为"已进入"
- **UI 反馈**：分支节点以管道图标标识，带"可跳过"提示
- **异常边界**：玩家选择跳过则直接继续主线，无惩罚
- **落地点**：`level.xlsx`（LevelType 标记为小游戏分支） + `UIlevel.xlsx`

### R-02: 管道旋转与拼接

- **触发条件**：玩家点击管道方块
- **前置限制**：锁定管道不可旋转
- **操作流程**：点击管道块旋转90° → 使能量从入口流至出口 → 接通即通关
- **状态变化**：管道方向改变；接通后能量开始流动
- **UI 反馈**：旋转有0.15s动画；接通时管道亮起青蓝色能量流
- **异常边界**：能量流到断口处停止，不判定失败，玩家可继续调整
- **落地点**：小游戏逻辑模块

### R-03: 腐蚀机制

- **触发条件**：Lv.4及以上关卡
- **前置限制**：无
- **操作流程**：管道每隔一段时间随机锈蚀一格 → 变为不可用 → 玩家需避开腐蚀区域重新规划
- **状态变化**：管道格子从可用变为锈蚀不可用
- **UI 反馈**：腐蚀预警2s（格子变色闪烁）→ 锈蚀后变为废铁灰色
- **异常边界**：腐蚀不影响已接通的管线段
- **落地点**：小游戏逻辑模块

### R-04: 评价与重复游玩

- **触发条件**：通关结算时
- **前置限制**：无
- **操作流程**：根据操作次数和剩余时间计算评价 → 显示S/A/B/C档位
- **状态变化**：记录历史最佳评价
- **UI 反馈**：结算界面显示评价和得分
- **异常边界**：评价仅记录展示，不影响剧情分支
- **落地点**：小游戏评价模块
- **重复游玩**：通关后可在关卡界面重新进入，支持刷新评价

## 关卡递进设计

| 梯度 | 网格规模 | 新增要素 |
|------|----------|----------|
| Lv.1 入门 | 3×3 | 仅直管+弯管，入口/出口固定在左右两侧 |
| Lv.2 初级 | 4×4 | 加入三通管；入口/出口位置随机（可在上下左右） |
| Lv.3 中级 | 5×5 | 加入"锁定管道"（不可旋转，必须适配）；元能从入口开始缓慢流动，到达断口前必须接通 |
| Lv.4 高级 | 5×5 | 双入口→单出口（两条管线需合流）；加入"腐蚀管道"（每10秒随机锈蚀一格，变为不可用） |
| Lv.5 挑战 | 6×6 | 单入口→双出口（需同时接通两条线路）；能量流速加快；腐蚀频率提升 |

## 数值框架

| 参数 | 数值 |
|------|------|
| 能量流速 | Lv.1-2: 不流动（纯拼图）/ Lv.3: 每3s前进一格 / Lv.4: 每2.5s / Lv.5: 每2s |
| 旋转动画时长 | 0.15s（要求操作响应迅速） |
| 腐蚀倒计时 | 腐蚀预警2s（格子变色闪烁）→ 锈蚀不可用 |
| 得分计算 | 基础分100 + 剩余格数未腐蚀×10 + 操作次数奖励（≤最优解次数×1.2则+50分） |
| 评价档位 | S: 操作次数≤最优解+2 且 剩余时间>30% / A: 通关且剩余时间>15% / B: 通关 / C: 超时未通关（给予保底） |

## 美术风格参考

- **背景**：房车底盘/引擎舱内部视角，暗色金属质感底板，边缘有螺丝铆钉细节
- **管道方块**：半透明蓝绿色管道内有流动的元能粒子光效（未接通时粒子静止呈灰蓝色）
- **能量流动**：接通时明亮的青蓝色能量流从入口涌出，带有荧光脉冲感
- **锁定管道**：金色边框 + 锁链图标标识
- **腐蚀效果**：管道表面逐渐出现锈红色斑点 → 碎裂变为废铁灰色
- **UI布局**：网格居中占屏幕70%面积，上方显示入口/出口位置指示箭头，下方为操作次数计数器
- **完成特效**：能量贯通全线 → 管道整体亮起 → 引擎启动的震动反馈 + 光效扩散
- **参考调性**：赛博机械风 + 《异星工厂》管线美学的简化版

## 玩法参考

- **参考对象**：**Pipe Mania / Pipe Dream**（The Assembly Line，1989）——旋转管道方块、在液体流到断口前接通入口到出口的经典管道解谜，本类型的定义之作。
- **对应机制**：
  - 点击管道旋转 90° 接通 ↔ Pipe Mania 核心旋转拼接
  - 锁定管道不可旋转需适配 ↔ Pipe Mania 固定起点/障碍格
  - Lv.3 起元能流动、到断口前必须接通 ↔ Pipe Mania 的流动倒计时核心
  - 三通管/双入口单出口/单入口双出口 ↔ Pipe Mania 多向分流扩展
  - 腐蚀管道随机锈蚀需重规划 ↔ 流动中的动态障碍变化
  - 接通后能量贯通全线 ↔ Pipe Mania 水流贯通反馈
- **差异点**：用元能粒子+赛博机械美术替换水管写实风；腐蚀机制叠加时间压力变体；定位为可跳过章节过渡，规模 1-3 分钟。
