## 背景与目标

### 背景

现有内容以主线推进为核心，缺乏日常短周期目标。玩家日常登录后除了刷体力关卡外，缺少轻量、主题化、带地图探索感的日常任务。需要一套每日委托系统：在大地图界面提供侧边入口，每日刷新委托任务，完成任务获得特定资源；任务节点显示在主线大地图上，按任务类型区分标识，并按章节解锁进度逐步开放未解锁区域的事件。

### 目标

在主线大地图新增每日委托侧边入口与任务节点层：每日刷新委托任务列表，任务节点按类型（剧情/小游戏/战斗/答题）显示在已解锁章节区域的地图上，完成委托获得特定资源奖励。

### 设计意图与体验目标

- **日常登录目标**：每日刷新的轻量任务，给玩家明确的"今日要做的几件小事"。
- **地图探索感**：委托任务节点直接落在主线大地图已解锁区域，引导玩家回到不同章节地图区域，激活地图复用价值。
- **章节解锁联动**：事件节点按章节解锁进度逐步开启，未解锁章节区域不生成事件，保证内容揭示节奏。
- **任务类型多样**：剧情/小游戏/战斗/答题四类，避免日常单一化。

### 非目标

- 不新增体力体系（战斗类委托沿用体力规则，其余免费）
- 不修改主线推进与首通经济
- 不改动既有节点类型定义（委托节点为独立事件层，不复用 MainLevel 节点链路）
- 不涉及周常/月常（本期仅日更，周/月常后续迭代）

## 核心规则

### 交互与容错总则

- **每日刷新**：委托任务按自然日刷新（每日 0:00 重置），未完成任务不累积到次日。
- **侧边入口常驻**：大地图右侧常驻每日委托侧边入口，显示当日剩余可领奖励数 / 总任务数。
- **地图节点动态生成**：委托任务节点每日刷新后在主线大地图已解锁区域动态生成，与主线/支线/番外节点同图显示但属独立事件层。
- **章节区域限制**：事件节点仅在玩家已解锁章节区域生成；未解锁章节区域不生成任何事件节点。
- **不可重复**：单个委托任务当日完成一次即完成，不可重复领取（小游戏/答题类可在完成前重复尝试）。

### R-01: 每日委托刷新

- **触发条件**：每日 0:00；或玩家当日首次登录时若当日未刷新则触发刷新
- **前置限制**：玩家已通关 Ch0 序章（解锁大地图）
- **操作流程**：
  - 0:00 触发 → 清空昨日未完成委托 → 按委托池配置随机抽取 N 个委托 → 生成当日委托列表 → 在已解锁章节区域生成对应任务节点
- **状态变化**：委托列表重置；任务节点重新生成；昨日节点清除
- **资源变化**：无
- **UI 反馈**：侧边入口角标更新为 `x/N`；新一天首次打开委托面板时"今日委托已刷新"轻提示
- **异常边界**：委托池配置不足 N 个时按实际数量生成并记日志；跨日玩家在线时延迟到次日首次操作触发刷新
- **落地点**：`DailyQuest.xlsx`（委托池配置） + 运行时刷新逻辑 + 任务系统

### R-02: 委托领取与查看

- **触发条件**：玩家点击大地图右侧每日委托侧边入口
- **前置限制**：无
- **操作流程**：点击侧边入口 → 滑出委托面板（右侧抽屉式）→ 展示当日委托列表（任务名、类型图标、目标、进度、奖励、定位按钮）
- **状态变化**：无
- **资源变化**：无
- **UI 反馈**：抽屉式面板从右侧滑入；每个委托卡片显示类型图标 + 进度条 + 奖励预览 + "定位"按钮（点击镜头聚焦地图上对应任务节点）
- **异常边界**：无委托时面板显示"今日暂无委托"
- **落地点**：委托面板 UI + `DailyQuest.xlsx`

### R-03: 委托任务节点

- **触发条件**：委托刷新生成任务节点后，玩家在地图上看到并可点击
- **前置限制**：任务节点所在章节区域已解锁；对应委托未完成
- **操作流程**：
  - 点击任务节点 → 弹出任务简述弹窗（任务名、类型、目标、奖励）→ 点击"前往"进入对应玩法
  - 完成玩法后回调 → 标记委托完成 → 节点播放完成动画 → 节点消失（或标"✓"保留至次日刷新）
- **状态变化**：委托状态 "未完成" → "已完成"
- **资源变化**：完成时发放委托奖励（见 R-05）
- **UI 反馈**：任务节点图标按任务类型区分（见节点标识）；未完成带轻光效引导；已完成标"✓"
- **异常边界**：玩法加载失败回退地图；任务节点所在区域若被后续操作锁定则隐藏并提示
- **落地点**：运行时任务节点生成逻辑 + `DailyQuest.xlsx` + 各玩法入口

### R-04: 任务类型与节点标识

任务类型分为四类，地图节点标识按类型区分：

| 任务类型 | type | 节点图标 | 玩法入口 | 体力 | 说明 |
|---|---|---|---|:---:|---|
| 剧情 | `story` | 对话气泡图标（蓝） | 剧情系统 | 0 | 纯剧情观看完成 |
| 小游戏 | `minigame` | 对应小游戏玩法图标（绿） | 小游戏（引用 game_id） | 0 | 完成一次小游戏（不评评价档） |
| 战斗 | `battle` | 战斗剑图标（红） | 指定关卡/专属战斗 | 10 | 通关指定战斗 |
| 答题 | `quiz` | 问号图标（紫） | 答题玩法（见 `design/答题玩法Design Doc.md`） | 0 | 完成一组答题 |

> 战斗类委托消耗体力 10（沿用主线体力），其余三类免费。战斗类委托可指定一个已有关卡 ID（复用）或专属委托战斗场景。

### R-05: 委托奖励

- **触发条件**：委托任务完成时
- **前置限制**：委托状态为"未完成"
- **操作流程**：玩法完成回调 → 读取 `DailyQuest.xlsx.reward_drop_id` → 发放奖励 → 委托标"已完成"
- **状态变化**：委托"已完成"
- **资源变化**：发放特定资源（见产出框架）
- **UI 反馈**：任务节点完成动画；委托面板对应卡片打勾 + 奖励飞出动画
- **异常边界**：reward_drop_id 缺失降级空奖励（记日志）
- **落地点**：`DailyQuest.xlsx`（reward_drop_id） + `Drop` 逻辑表

### R-06: 章节解锁进度联动

- **触发条件**：委托刷新生成任务节点时；或玩家解锁新章节时
- **前置限制**：事件节点所在章节区域已解锁（玩家已进入/通关该章首关，具体解锁口径见工作假设）
- **操作流程**：
  - 刷新时：遍历委托池 → 每个委托配置 `chapter_range`（可生成章节区间）→ 仅在玩家已解锁章节区间内生成节点
  - 解锁新章节时：不立即追加新委托（等次日刷新），但次日刷新时新解锁章节进入可生成区域
- **状态变化**：可生成事件节点的章节区域随进度扩大
- **资源变化**：无
- **UI 反馈**：未解锁章节区域地图灰态，不显示任何事件节点
- **异常边界**：委托 chapter_range 全部未解锁时该委托当日不生成（记日志）
- **落地点**：`DailyQuest.xlsx`（chapter_range） + 运行时章节解锁状态查询 + 节点生成逻辑

### R-07: 全部完成奖励

- **触发条件**：当日所有委托任务均完成
- **前置限制**：当日委托数 > 0 且全部"已完成"
- **操作流程**：最后一个委托完成 → 检查全部完成 → 弹窗发放全部完成奖励
- **状态变化**：当日"全部完成"标记
- **资源变化**：发放 `DailyQuestAllComplete.xlsx.all_complete_drop_id` 对应 Drop 组
- **UI 反馈"：专属"今日委托全部完成"弹窗 + 奖励
- **异常边界**：无全部完成奖励配置时不发（可选）
- **落地点**：`DailyQuestAllComplete.xlsx` + `Drop`

## 数值与产出框架

### 每日委托数量

| 项 | 值 | 说明 |
|---|---|---|
| 每日委托数 | 4 | 4 类各 1 个为典型，可配置 |
| 全部完成奖励 | 1 | 额外激励 |

### 奖励产出定位

委托奖励为**特定资源**，定位为日常小额补充，刻意不替代主线体力产出：

| 任务类型 | 奖励定位 | 参照 |
|---|---|---|
| 剧情 | 小额金币 + 特定资源 | 约主线常规产出 20% |
| 小游戏 | 中档材料 + 特定资源 | 约 30% |
| 战斗 | 金币 + 经验 + 特定资源 | 约主线常规 40%（含体力成本） |
| 答题 | 特定资源（主要）+ 小额钻石 | 约 20% |
| 全部完成 | 钻石 + 抽卡券碎片 + 特定资源 | 额外激励 |

> "特定资源"建议为日常稀缺的中期资源（如番外钥匙道具碎片、养成素材），与番外解锁循环形成联动。具体数值由 `DailyQuest.xlsx` 配置，经经济模拟验证。

## 配置表初版结构

### 新增表清单

| 表名 | 类型 | 说明 |
|---|---|---|
| `DailyQuest.xlsx` | 新增 | 委托池配置：任务类型、目标、章节区间、奖励 |
| `DailyQuestAllComplete.xlsx` | 新增 | 全部完成奖励配置 |
| 委托战斗配置 | 复用/新增 | 战斗类委托引用 level_id 或专属委托战斗；可复用 level.xlsx |

### DailyQuest.xlsx 字段初版结构

| 字段 | 类型 | 说明 |
|---|---|---|
| quest_id | int | 委托ID（池配置ID） |
| name | string | 委托名 |
| type | enum | story/minigame/battle/quiz |
| target_id | int | 目标玩法ID（minigame→game_id；battle→level_id；story→story_resource_id；quiz→quiz_group_id） |
| target_count | int | 目标次数（默认1） |
| chapter_range | string | 可生成章节区间（如 "1-3" 表示 Ch1~Ch3 区域可生成） |
| node_position_pool | string | 节点候选位置池（JSON/坐标列表，在对应章节区域内预设若干点位） |
| reward_drop_id | string | 奖励 Drop 组ID |
| weight | int | 抽取权重 |
| min_player_level | int | 玩家等级下限（可选） |
| description | string | 委托描述 |

### DailyQuestAllComplete.xlsx 字段初版结构

| 字段 | 类型 | 说明 |
|---|---|---|
| all_complete_id | int | ID |
| quest_count | int | 触发所需完成委托数（默认=每日委托数） |
| all_complete_drop_id | string | 全部完成奖励 Drop 组ID |
| description | string | 说明 |

### 表关系

```
DailyQuest.xlsx (委托池)
  ├─ type=story    → 剧情系统 (story_resource_id)
  ├─ type=minigame → 小游戏配置表 (game_id)
  ├─ type=battle   → level.xlsx (level_id) 或专属委托战斗
  └─ type=quiz     → 答题玩法 (quiz_group_id, 见答题玩法Design Doc)
        └─ reward_drop_id → Drop

DailyQuestAllComplete.xlsx → Drop

运行时：每日刷新 → 按章节解锁状态过滤 chapter_range → 在 node_position_pool 中选点生成任务节点
```

> 配置门禁校验：
> - type 与 target_id 对应表存在性
> - chapter_range 章节ID合法
> - node_position_pool 坐标在对应章节地图区域内

## 美术与 UI

### 侧边入口

- 大地图右侧中部常驻"每日委托"侧边入口（竖排标签 + 角标 `x/N`）
- 有未领奖励时角标红点；全部完成时角标变"✓"

### 委托面板（右侧抽屉）

- 从右侧滑入的抽屉式面板，宽度约屏幕 40%
- 顶部：今日日期 + 全部完成进度条
- 列表：委托卡片（类型图标 + 任务名 + 进度 + 奖励预览 + "定位"按钮）
- 底部：全部完成奖励预览（未完成灰态）

### 地图任务节点

- 节点图标按类型区分（剧情蓝/小游戏绿/战斗红/答题紫）
- 未完成：轻光效脉冲引导 + "!"角标
- 已完成：图标灰态 + "✓"
- 节点上方悬浮任务名短标签
- 未解锁章节区域：地图灰态，无任何事件节点

### 演出

- 点击任务节点弹任务简述弹窗（无房车演出，任务节点为事件层不移动房车）
- 完成时节点播放轻量完成动画（光效 + 勾选），不阻断
- "定位"按钮：镜头平滑移动到任务节点位置

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| 任务节点与主线/支线/番外节点地图位置重叠 | 中 | 中 | node_position_pool 预设点位避开既有节点；运行时冲突检测偏移 |
| 战斗类委托消耗体力影响主线体力经济 | 中 | 中 | 战斗委托每日上限1个；奖励定位低于主线体力产出 |
| 委托奖励特定资源冲击番外钥匙道具经济 | 中 | 高 | 委托产出钥匙道具"碎片"非整道具；经经济模拟验证产出速率 |
| 章节解锁口径不一致导致事件生成在未解锁区 | 中 | 中 | 统一章节解锁状态查询接口；门禁校验 chapter_range |
| 每日刷新时玩家在线导致节点状态错乱 | 低 | 中 | 刷新延迟到次日首次操作；在线跨日做平滑过渡 |
| 答题玩法未就绪导致答题类委托不可用 | 中 | 中 | 答题玩法与委托同期交付；委托池可配置先不放答题类 |

## 数据埋点方案

### 委托级埋点

| 埋点事件名 | 触发时机 | 上报字段 | 分析用途 |
|---|---|---|---|
| daily_quest_refresh | 每日委托刷新 | user_id, refresh_date, quest_id_list, chapter_unlocked | 分析委托分布、解锁区域 |
| daily_quest_view | 打开委托面板 | user_id, quest_count, completed_count | 分析面板打开率 |
| daily_quest_node_click | 点击地图任务节点 | user_id, quest_id, type, chapter_id | 分析节点点击率、类型偏好 |
| daily_quest_locate | 点击"定位"按钮 | user_id, quest_id, node_chapter_id | 分析定位使用率 |
| daily_quest_complete | 委托完成 | user_id, quest_id, type, time_since_refresh, reward_drop_id | 分析完成率、完成时长、类型完成差异 |
| daily_quest_all_complete | 全部完成 | user_id, refresh_date, time_to_all_complete | 分析全部完成率、耗时 |
| daily_quest_expire | 跨日未完成清除 | user_id, quest_id, type, progress | 分析放弃率、哪些委托最常未完成 |

### 章节解锁联动埋点

| 埋点事件名 | 触发时机 | 上报字段 | 分析用途 |
|---|---|---|---|
| daily_quest_chapter_unlock | 新章节解锁后次日刷新纳入 | user_id, chapter_id, new_quest_count | 分析章节解锁对委托池扩展影响 |
