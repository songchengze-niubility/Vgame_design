## 背景与目标

### 背景

主线章节间需要轻度过渡玩法调节节奏。荒漠遗迹中地鼠盗掘文物碎片，玩家用锤击机制辨识"该打/不该打"的目标，承接轻松诙谐的旅途氛围。

### 目标

提供30秒的反应辨识玩法，作为主线关卡内的分支关卡，用"看清再下手"的判断而非纯手速制造爽点。

### 设计意图与体验目标

- **节奏定位**：作为"反应辨识型"调节，30秒短局、低负担，适合放在战斗关后做节奏切换。
- **核心爽点**：好/坏/非常坏三类地鼠的辨识收益差——打错扣分、打对加分、打中非常坏地鼠爆分，形成"忍住不打"与"果断出手"的张力。
- **去挫败设计**：好地鼠仅扣10分且不结束游戏，惩罚温和；伪随机抑制连续好地鼠刷脸，杜绝"一屏幕全是好地鼠"的不可控局。
- **保底兜底**：C级（未达标）仍给基础奖励，评价档位不影响主线推进，仅记录展示。
- **设计取舍**：孔洞固定7个保证视觉可读；每孔独立概率 + 全局伪随机双轨，既保留单孔随机感又控制总体好地鼠占比，避免玩家得分过低。

### 非目标

- 不涉及PVP
- 不涉及经济产出重构
- 评价档位不影响后续剧情分支
- 不做锤子升级/道具购买（本期纯玩法）

## 核心规则

### 交互与容错总则

- **辨识优先**：三类地鼠外观差异强（好地鼠=金边笑脸、坏地鼠=灰褐贼笑、非常坏地鼠=红眼狂笑带火焰），避免"没看清就打"的冤枉扣分。
- **错打温和**：打到好地鼠仅扣10分，不掉血、不结束、不连锁，保护"再来一次"的动力。
- **漏接免责**：地鼠存在时间结束自行缩回，漏打无额外惩罚（仅不加分），引导"宁可不打不要错打"的保守策略。
- **手感跟手**：点击/拖拽锤子判定框为地鼠图形的110%（略宽松），避免"明明点到了"的判定挫败。
- **伪随机控场**：每孔独立概率 + 全局好地鼠上限 + 连续好地鼠抑制 + 低分救济四重机制，确保玩家得分分布落在合理区间。
- **保底兜底**：C级（未达标）仍给基础奖励，不阻断主线，评价仅记录展示。

### R-01: 触发与进入

- **触发条件**：主线关卡内分支节点出现，玩家可选择进入或跳过
- **前置限制**：无（可跳过，不阻断主线推进）
- **操作流程**：点击分支节点 → 进入小游戏界面 → 倒计时3秒 → 开始游戏
- **状态变化**：关卡状态标记为"已进入"
- **UI 反馈**：分支节点以锤子图标标识，带"可跳过"提示
- **异常边界**：玩家选择跳过则直接继续主线，无惩罚
- **落地点**：`level.xlsx`（LevelType 标记为小游戏分支） + `UIlevel.xlsx`

### R-02: 孔洞与地鼠生成

- **触发条件**：游戏开始后启动孔洞调度
- **前置限制**：固定7个孔洞，每孔同一时刻最多1只地鼠
- **操作流程**：
  - 7个孔洞各自维护一个"空闲计时器"，每 `spawn_check_interval` 秒（默认0.8s）独立掷一次"是否生成"判定（`spawn_prob` 默认55%）
  - 判定通过 → 该孔进入"地鼠存在"状态，按类型概率轮盘决定生成哪类地鼠
  - 地鼠存在 `mole_exist_time` 秒（默认1.2s）后未被击中则自行缩回，孔洞回到空闲
  - 玩家击中地鼠 → 立即结算分数 → 孔洞进入 `hole_cooldown` 秒（默认0.3s）冷却后回到空闲
- **状态变化**：每孔状态机 = 空闲 → 存在（地鼠类型）→ 空闲（含冷却）
- **UI 反馈**：地鼠冒出带尘土粒子；缩回带塌陷动画；冷却期孔洞边缘暗化
- **异常边界**：同一孔洞存在期间不再掷生成判定；7孔全占用时全局暂停掷点，等任意孔回到空闲再恢复
- **落地点**：小游戏逻辑模块 + 小游戏配置表（见"数值框架"）

### R-03: 地鼠类型与得分

- **触发条件**：地鼠生成时
- **前置限制**：类型概率走配置，三者之和=100%
- **操作流程**：
  - 好地鼠（笑脸金边）：击中 **扣10分**，引导"不要打"
  - 坏地鼠（灰褐贼笑）：击中 **加20分**，常规目标
  - 非常坏地鼠（红眼狂笑带火焰）：击中 **加50分**，高分目标，存在时间更短（`mole_exist_time` ×0.7）
  - 漏接：0分
- **状态变化**：累计分数；击中类型计入伪随机历史
- **UI 反馈**：击中好地鼠=灰雾+扣分红字；坏地鼠=白光+加分黄字；非常坏地鼠=爆炸特效+加分金字大弹
- **异常边界**：分数下限为0，不出现负分显示（实际可记负分用于评级，但UI显示夹紧到0）
- **落地点**：小游戏逻辑模块 + 小游戏配置表

### R-04: 伪随机控场机制

- **触发条件**：每次地鼠生成判定
- **前置限制**：本机制在配置的类型概率基础上做动态调整，目标是控制好地鼠占比、避免连续好地鼠刷脸、避免玩家得分过低
- **操作流程**（四重叠加）：
  1. **单孔连续抑制**：某孔上一次生成为好地鼠时，该孔下一次生成的"好地鼠概率"临时减半（×0.5），减下来的概率补给坏地鼠。连续2次好地鼠则该孔下一次好地鼠概率置0。
  2. **全局好地鼠上限**：全局面板统计本局已生成好地鼠占比，一旦达到 `good_mole_cap`（默认35%），后续生成强制不出现好地鼠，概率全额补给坏地鼠+非常坏地鼠（按原比例分配）。
  3. **连续错打救济**：玩家若连续 `bad_hit_streak` 次（默认3次）击中好地鼠，下一只生成的好地鼠概率临时 ×0.3，持续2次生成后恢复。
  4. **低分救济**：在 `t=10s`、`t=20s` 两个时间检查点，若当前分数 < `score_floor_at_t`（默认 t=10s 时为 80、t=20s 时为 200），则接下来 `relief_window` 秒（默认4s）内非常坏地鼠概率提升 +15%（从好地鼠概率中扣除）。
- **状态变化**：维护 `good_mole_count`、`total_spawn_count`、`last_spawn_type_per_hole[7]`、`consecutive_bad_hit`、示"`relief_active_until`
- **UI 反馈**：低分救济激活时，孔洞边缘泛起暖金光圈，提加成中"（不暴露具体机制）
- **异常边界**：伪随机只降/升概率，不强制生成某类地鼠；若所有抑制同时触发，好地鼠概率最低可到0，但坏/非常坏地鼠概率必≥原始配置值
- **落地点**：小游戏逻辑模块 + 小游戏配置表（`good_mole_cap`、`bad_hit_streak`、`score_floor_at_t`、`relief_window`）

### R-05: 评价与重复游玩

- **触发条件**：30秒倒计时结束结算时
- **前置限制**：无
- **操作流程**：根据最终分数计算评价 → 显示S/A/B/C档位 → 发放对应奖励
- **状态变化**：记录历史最佳评价
- **UI 反馈**：结算界面显示评价、得分、击中分类统计（好/坏/非常坏各打中几只）
- **异常边界**：C级（未达标）仍给基础奖励；评价仅记录展示，不影响剧情分支与主线推进
- **落地点**：小游戏评价模块 + 奖励配置表
- **重复游玩**：通关后可在关卡界面重新进入，支持刷新评价

## 数值框架

### 基础参数

| 参数 | 配置键 | 默认值 |
|------|--------|--------|
| 游戏总时长 | `game_duration` | 30s |
| 孔洞数量 | `hole_count` | 7 |
| 生成检查间隔（每孔） | `spawn_check_interval` | 0.8s |
| 单孔生成概率 | `spawn_prob` | 55% |
| 地鼠存在时间 | `mole_exist_time` | 1.2s |
| 非常坏地鼠存在时间 | `mole_exist_time_vbad` | 0.84s（=1.2×0.7） |
| 击中后孔洞冷却 | `hole_cooldown` | 0.3s |
| 判定框 | `hit_box_ratio` | 110%（地鼠图形） |
| 开局倒计时 | `start_countdown` | 3s |

### 地鼠类型概率（基础配置，和=100%）

| 地鼠类型 | 配置键 | 基础概率 | 得分 | 存在时间 |
|----------|--------|----------|------|----------|
| 好地鼠 | `prob_good` | 35% | -10 | 1.2s |
| 坏地鼠 | `prob_bad` | 50% | +20 | 1.2s |
| 非常坏地鼠 | `prob_vbad` | 15% | +50 | 0.84s |

### 伪随机参数

| 参数 | 配置键 | 默认值 |
|------|--------|--------|
| 全局好地鼠占比上限 | `good_mole_cap` | 35% |
| 单孔连续好地鼠概率衰减 | `good_streak_decay` | ×0.5 |
| 单孔连续好地鼠上限 | `good_streak_max` | 2（达上限下次置0） |
| 连续错打救济阈值 | `bad_hit_streak` | 3 |
| 连续错打救济衰减 | `bad_streak_decay` | ×0.3 |
| 连续错打救济持续 | `bad_streak_duration` | 2次生成 |
| 低分救济检查点 | `score_floor_checkpoints` | t=10s→80, t=20s→200 |
| 低分救济窗口 | `relief_window` | 4s |
| 低分救济非常坏概率提升 | `relief_vbad_boost` | +15%（从好地鼠扣） |

### 评价档位

以"目标分数" `target_score`（默认400）为基准，按比例划分：

| 档位 | 阈值 | 说明 |
|------|------|------|
| S | ≥ `target_score` ×150% （600） | 高手辨识 + 果断出手 |
| A | ≥ `target_score` ×120% （480） | 稳定辨识 |
| B | ≥ `target_score` （400） | 达标 |
| C | < `target_score` （400） | 未达标，仍给基础奖励，不阻断主线 |

> 目标分数与档位阈值需结合实机 playtest 校准，当前值为首版假设。

## 美术风格参考

- **背景**：荒漠遗迹挖掘现场，7个孔洞呈弧形排列在沙地台基上，远景有残破石柱与流沙粒子
- **好地鼠**：金边笑脸地鼠，头顶小光环，被击中时灰雾消散 + 扣分红字
- **坏地鼠**：灰褐色贼笑地鼠，叼着文物碎片，被击中时白光闪 + 加分黄字
- **非常坏地鼠**：红眼狂笑地鼠，身周带火焰粒子，存在时间更短，被击中时爆炸特效 + 加分金字大弹
- **锤子**：卡通木锤，跟随手指/鼠标，点击时下砸动画（2帧）
- **UI布局**：7孔居中排布，顶部中央倒计时与分数大字，右上角击中分类统计（好/坏/非常坏打中数），底部进度条
- **完成特效**：时间结束 → 锤子插地 → 地鼠集体探头鞠躬 → 结算面板上浮
- **参考调性**：《打地鼠》经典辨识玩法 + 《胡闹厨房》式的诙谐卡通氛围

## 玩法参考

- **参考对象**：经典 Whack-a-Mole 衍生的"辨识型打地鼠"（如《打地鼠》变体中区分好怪/坏怪的设计）。
- **对应机制**：
  - 固定孔洞 + 地鼠随机冒头 ↔ 经典打地鼠核心
  - 好/坏/非常坏三类辨识收益差 ↔ 辨识型变体的"看清再下手"
  - 存在时间限制自动缩回 ↔ 经典地鼠缩回机制
  - 伪随机抑制连续好地鼠 ↔ MOBA/抽卡中的"伪随机/怜惜"机制移植到生成端
  - 低分救济时间检查点 ↔ 节奏游戏的"动态难度调节（DDA）"
- **差异点**：四重伪随机控场（单孔抑制 + 全局上限 + 错打救济 + 低分救济）确保辨识玩法不因运气导致极端得分；30秒短局 + 不阻断主线，定位为可跳过的章节过渡而非硬核挑战。

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 伪随机参数过强导致玩法失去随机感 | 中 | 中 | 上限/衰减参数全部走配置，可热更调参；首版保守，按 playtest 放宽 |
| 三类地鼠辨识度不足引发误打挫败 | 中 | 中 | 外观差异强（金边/灰褐/红眼火焰），非常坏存在时间更短形成天然辨识压力分层 |
| 30秒过短体验单薄 | 低 | 低 | 评价档位 + 重复刷新最佳分提供复玩动机；必要时可按章节调整 `game_duration` |
| 低分救济被玩家感知"被施舍" | 低 | 低 | 仅孔洞光圈提示加成，不暴露阈值与机制细节 |

## 数据埋点方案

### 通用埋点（节点级，复用既有）

| 埋点事件名 | 触发时机 | 上报字段 | 分析用途 |
|---|---|---|---|
| minigame_node_play | 在地图节点上玩打地鼠 | user_id, node_id, game_id, level_no, grade, is_best | 分析节点级游玩与评价分布 |

### 打地鼠特有埋点

| 埋点事件名 | 触发时机 | 上报字段 | 分析用途 |
|---|---|---|---|
| wam_start | 进入打地鼠并开始倒计时 | user_id, node_id, game_id, config_version | 分析启动量与配置版本分布 |
| wam_mole_spawn | 地鼠生成 | user_id, session_id, hole_idx, mole_type, spawn_t, is_good_suppressed, relief_active | 分析生成分布、伪随机触发频率、孔洞使用率 |
| wam_mole_hit | 玩家击中地鼠 | user_id, session_id, hole_idx, mole_type, score_delta, elapsed, consecutive_bad_hit | 分析击中辨识准确率、错打连击分布、得分曲线 |
| wam_mole_escape | 地鼠存在结束未被击中 | user_id, session_id, hole_idx, mole_type, elapsed | 分析漏接率、哪类地鼠最易漏（非常坏漏接应高） |
| wam_relief_trigger | 低分救济激活 | user_id, session_id, trigger_t, score_at_trigger, checkpoint | 分析救济触发率、触发时分数分布，校准 `score_floor_at_t` |
| wam_good_cap_hit | 全局好地鼠占比上限触达 | user_id, session_id, trigger_t, good_count, total_spawn | 分析上限触达率，校准 `good_mole_cap` |
| wam_complete | 30秒结算 | user_id, session_id, final_score, grade, hit_good, hit_bad, hit_vbad, escape_count, good_mole_ratio, best_score | 分析评价分布、得分分布、辨识准确率与评级关系 |
| wam_skip | 跳过打地鼠节点 | user_id, node_id, game_id | 分析跳过率 |
| wam_replay | 重复进入刷新评价 | user_id, node_id, game_id, replay_count, prev_best_grade | 分析复玩动机 |

> 埋点设计原则：`session_id` 贯穿单局，便于还原单局生成/击中时序；伪随机相关字段（`is_good_suppressed`、`relief_active`、`good_mole_ratio`）用于评估控场机制是否达到预期得分分布。
