## 背景与目标
### 背景
现有工会战以"多BOSS周目循环 + 次数限制 + 公会总积分排名"为核心，体验偏公主连结。本次重构希望保留多BOSS周目与公会协作感，但把战斗体验、参与节奏、奖励结构向空之要塞启航靠拢：以轻松挂机为主、可切手动；成员各自独立挑战、伤害异步累计到同一BOSS；每日固定次数不累积；个人伤害榜与公会排名榜双榜发奖，兼顾个人追求与公会协作。

### 目标
- 提供以自动挂机为主、可随时切手动的轻松共斗 BOSS 体验
- 成员各自独立挑战，伤害异步累计到同一公会BOSS，降低在线协同压力
- 多BOSS周目循环、逐周目变强，保留长线推进感
- 个人伤害榜（公会内）+ 公会排名榜双榜结算，双线激励

### 非目标
- 不做实时同屏共斗（非实时在线协同）
- 不做轮流出刀/补偿刀/继承血量的公主连结式出刀机制
- 不做跨服公会BOSS（仅本服）
- 不做公会科技树/建筑升级
- 不做 BOSS 击退后的独立尾刀榜（尾刀分合并计入个人伤害与公会总积分）

## 核心规则

### R-01: 赛季周期（开两周休一周）
- **触发条件**：服务器赛季时间表驱动
- **前置限制**：公会BOSS挑战为周期性活动，非常驻
- **操作流程**：每个赛季 = 活跃期 2 周 + 休整期 1 周；活跃期内可挑战，休整期关闭挑战入口、仅可查看上赛季结算
- **状态变化**：活动状态 `休整 → 活跃 → 结算 → 休整` 循环
- **资源变化**：无
- **UI 反馈**：主页面左上方实时显示活动剩余时间与当前阶段标签
- **异常边界**：休整期强行进入 → 入口灰态并提示"休整中，下赛季于 X 开启"
- **落地点**：赛季时间配置表

### R-02: BOSS 库与周目循环（无上限）
- **触发条件**：活跃期开启 / 当前周目所有 BOSS 被击败
- **前置限制**：每赛季从 BOSS 库中随机抽取 3 个 BOSS 作为一个周目
- **操作流程**：进入公会BOSS页面 → 地图展示 3 个 BOSS → 成员可任选 BOSS 挑战 → 3 个 BOSS 全部被击败 → 刷新为下一周目的 3 个 BOSS（同库重新随机或按规则推进）→ 周目数 +1
- **状态变化**：当前周目编号 `round` 递增（从 1 开始，无上限，无限循环）；每个 BOSS 有 `存活/击退` 状态
- **资源变化**：无
- **UI 反馈**：地图显示 BOSS 形象 + 头顶血条；全清后播放周目推进动画并刷新 BOSS
- **异常边界**：不同 BOSS 可同时被不同成员挑战（并行）；周目无上限，无限循环
- **落地点**：BOSS 库配置表、周目配置表

### R-03: 周目难度递增
- **触发条件**：进入新周目
- **前置限制**：周目编号 `round` 从 1 开始
- **操作流程**：新周目 BOSS 属性按 `round` 缩放（血量、攻击、防御乘以成长系数），系数由配置表读取；越往后越强
- **状态变化**：BOSS 属性随周目提升
- **资源变化**：无
- **UI 反馈**：BOSS 页面显示当前周目数与难度等级标签
- **异常边界**：成长系数过高导致后期不可战胜 → 配置封顶或曲线放缓
- **落地点**：周目难度成长配置表

### R-04: 每日挑战次数（固定 3 次，不累积）
- **触发条件**：玩家发起挑战
- **前置限制**：玩家当日剩余挑战次数 > 0；已加入公会
- **操作流程**：点击挑战 → 校验次数 → 进入战斗 → 战斗结束（胜/败/主动退出/超时）→ 次数 -1
- **状态变化**：`daily_challenge_count` 当日已用次数 +1
- **资源变化**：-1 次挑战机会
- **UI 反馈**：右上方显示当前剩余次数；次数为 0 时挑战按钮灰态并提示"今日次数已用完"
- **异常边界**：每日次数固定 3 次，不累积到次日；每日 5:00 重置；战斗中断线按"已消耗次数"处理，重连不返还
- **落地点**：每日次数配置、玩家每日次数字段

### R-05: 战斗模式（自动为主，可切手动，限时 120s）
- **触发条件**：玩家进入 BOSS 战斗
- **前置限制**：已消耗 1 次挑战次数
- **操作流程**：进入战斗 → 默认自动战斗（角色自动普攻与释放技能）→ 战斗内提供"自动/手动"切换按钮 → 手动模式下玩家可操控走位与技能释放 → 可随时切回自动
- **状态变化**：战斗模式标记 `auto/manual`
- **资源变化**：无
- **UI 反馈**：战斗 HUD 显示当前模式；切换按钮即时生效；HUD 显示剩余战斗时间
- **异常边界**：不强制要求手动；切手动不影响伤害结算；战斗限时 120s（可配置），超时按已造成伤害结算
- **落地点**：战斗模块、模式切换控制、战斗限时配置

### R-06: 模拟战
- **触发条件**：玩家在 BOSS 挑战页点击"模拟战"按钮
- **前置限制**：玩家已加入公会；处于活跃期
- **操作流程**：进入 BOSS 战斗场景 → 使用当前周目 BOSS 的真实属性与进入瞬间的剩余血量 → 完整战斗一次 → 结算仅显示本次模拟伤害
- **状态变化**：无（不修改 BOSS 血量、不消耗正式次数、不上榜、不计入记录）
- **资源变化**：无
- **UI 反馈**：BOSS 挑战页显示"模拟战"按钮；结算界面显示"本次模拟伤害"，并提示"模拟战结果不上榜、不扣血、不保存"
- **异常边界**：战斗限时 120s（同配置），超时按已造成伤害结算；断线重连后不返还次数；BOSS 已被击退仍可进入模拟战；模拟战伤害不触发 BOSS 击退状态
- **落地点**：BOSS 挑战页入口、战斗模块（模拟战结算旁路）

### R-07: 伤害累计与个人伤害统计
- **触发条件**：单次战斗结束
- **前置限制**：战斗正常结束（含超时）
- **操作流程**：战斗结算 → 计算本次对目标 BOSS 造成的总伤害 → 上报服务器 → 累加到该 BOSS 的公会总伤害池 → 同时累加到该玩家对此 BOSS 的个人伤害与赛季个人总伤害
- **状态变化**：BOSS 剩余血量按累计伤害扣减；玩家个人伤害统计更新
- **资源变化**：无直接资源
- **UI 反馈**：结算界面显示本次伤害、对该 BOSS 累计伤害、对该 BOSS 的个人排名
- **异常边界**：BOSS 被多人同时攻击导致血量并发扣减 → 服务端串行化扣减，伤害仍全额计入；BOSS 血量归零后多余的伤害不再计入（按配置截断）
- **落地点**：伤害结算服务、BOSS 血量服务

### R-08: 积分与双榜（公会榜 + 公会内个人榜）
- **触发条件**：伤害上报 / 赛季结算
- **前置限制**：—
- **操作流程**：
  - 公会积分 = 本公会所有成员对所有 BOSS 造成的累计伤害（1 点伤害 = 1 积分）+ 所有尾刀分数，BOSS 血量即积分上限
  - 公会排名榜：按公会总积分排名（全服公会榜）
  - 个人伤害榜：仅本公会内成员伤害榜，按玩家赛季个人总伤害排名（含尾刀分数）
- **状态变化**：榜单实时刷新
- **资源变化**：无
- **UI 反馈**：排行榜页面可切换查看全服公会榜 / 本公会成员伤害榜
- **异常边界**：积分并发更新 → 服务端聚合；同分按达成时间先后排序
- **落地点**：排行榜服务

### R-09: 奖励结算（双榜发奖，含尾刀分）
- **触发条件**：活跃期结束进入结算
- **前置限制**：赛季正常结束
- **操作流程**：
  - 公会排名榜：按公会总积分档位/排名发放公会奖励（邮件发放到全员）；总积分含成员尾刀分数
  - 个人伤害榜：按公会内个人总伤害档位/排名发放个人奖励（邮件发放到本人）；伤害含尾刀分数
  - 两套奖励独立计算，可叠加领取
  - 尾刀奖励：BOSS 被击退时，造成最后一击的玩家额外获得尾刀分数 = BOSS 总血量 × 尾刀奖励比例（配置表），该分数同时计入个人赛季总伤害与公会总积分
- **状态变化**：结算完成，榜单锁定
- **资源变化**：发放货币、道具到邮件
- **UI 反馈**：结算邮件通知；报酬一览页面展示各档位奖励内容
- **异常边界**：结算时玩家离线 → 静默发邮件；同一玩家同一赛季不重复结算；公会解散时个人奖励仍发放给本人，公会奖励按规则处理
- **落地点**：奖励档位配置表、邮件系统

### R-10: 战斗记录
- **触发条件**：玩家查看战斗记录
- **前置限制**：已加入公会
- **操作流程**：主页面右下"战斗记录"入口 → 弹出本公会当日所有成员的挑战记录列表（可滑动）→ 可查看成员单次挑战的伤害详情
- **状态变化**：记录每日 5:00 清空前一天的记录
- **资源变化**：无
- **UI 反馈**：有记录/无记录两种状态；列表显示成员名、目标 BOSS、伤害、时间
- **异常边界**：记录仅保留当天；跨天清空
- **落地点**：战斗记录服务

### R-11: 公会锁定
- **触发条件**：活跃期开始
- **前置限制**：—
- **操作流程**：活跃期内禁止踢人、禁止退出公会，仅允许加入公会
- **状态变化**：公会成员锁定
- **资源变化**：无
- **UI 反馈**：相关按钮灰态并提示"公会BOSS期间不可操作"
- **异常边界**：—
- **落地点**：公会成员管理逻辑

### R-12: 解锁与入口
- **触发条件**：玩家查看入口
- **前置限制**：已加入公会且公会系统已解锁（玩家等级 ≥ 22）
- **操作流程**：满足条件 → 公会BOSS入口可点击；未满足 → 灰态提示
- **状态变化**：入口 `锁定 → 解锁`
- **资源变化**：无
- **UI 反馈**：解锁提示弹窗
- **异常边界**：非正常入口进入 → 服务端校验，未解锁拒绝
- **落地点**：Unlock.xlsx（复用公会解锁 22 级）

### R-13: UI 页面（参考工会战UI需求）
- **触发条件**：玩家进入各页面
- **前置限制**：—
- **操作流程**：
  - **主页面**：左上方时间/排名/规则入口；右上方剩余挑战次数与当前 BOSS/难度等级；左下方排名&奖励入口；右下方战斗记录；中央地图显示 3 个 BOSS 形象 + 头顶血条
  - **BOSS挑战页**：左侧 BOSS 立绘及名称；右侧 BOSS 名字/血量/介绍/个人伤害统计/击退按钮/挑战按钮/模拟战按钮；右侧下方排行按钮（单个 BOSS 的社团内伤害排名）；BOSS 被击退后显示尾刀玩家信息（头像、名称、尾刀分数）
  - **排行榜页**：全服公会排名信息 + 本公会成员伤害信息
  - **报酬一览页**：公会排名档位奖励 + 个人伤害档位奖励
- **状态变化**：—
- **资源变化**：—
- **UI 反馈**：见各子项
- **异常边界**：—
- **落地点**：UIlevel / UI 原型

## 技术方案
### 架构影响
- 复用公会系统模块，新增"公会BOSS"子模块
- 新增 BOSS 血量服务（异步累计伤害、串行扣减）
- 新增双榜排行榜服务（公会榜 + 公会内个人榜）
- 战斗模块复用现有 PVE 战斗，新增自动/手动模式切换与限时、模拟战旁路结算

### 数据变更
| 表 | 变更类型 | 说明 |
|----|----------|------|
| 公会BOSS赛季时间表 | 新增 | 活跃期/休整期时间 |
| 公会BOSS库表 | 新增 | BOSS 模板池 |
| 公会BOSS周目难度表 | 新增 | 周目成长系数 |
| 公会BOSS奖励档位表 | 新增 | 公会榜奖励 + 个人榜奖励 |
| 公会BOSS尾刀奖励配置 | 新增 | 尾刀奖励比例（相对 BOSS 总血量），如 5% |
| 每日挑战次数配置 | 新增 | 每日次数（默认3）、重置时间、战斗限时（默认120s） |
| Unlock.xlsx | 复用 | 公会解锁 22 级 |
| 玩家每日次数字段 | 新增 | daily_challenge_count |
| 玩家赛季个人伤害字段 | 新增 | season_personal_damage |
| 战斗模拟战标记 | 新增 | 标记本次战斗为正式/模拟，用于控制扣血与榜单入口 |

### 接口变更
- `GuildBossGetInfo`：返回赛季状态、当前周目、3个BOSS状态与血量、个人剩余次数
- `GuildBossChallenge`：入参 BossId；返回战斗入场数据
- `GuildBossSettle`：战斗结束上报伤害；返回本次伤害、个人累计、BOSS剩余血量
- `GuildBossGetRank`：入参 RankType(Guild/Personal)；返回榜单
- `GuildBossGetRecord`：返回本公会当日挑战记录
- `GuildBossSimulate`：入参 BossId；返回战斗入场数据（模式标记为模拟战）
- `GuildBossSettleSimulate`：战斗结束上报伤害；返回本次模拟伤害（不扣 BOSS 血量、不计入榜单）
- `GuildBossSettleSeason`：赛季结算，批量发奖

## 风险评估
| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| BOSS 血量并发扣减导致数据不一致 | 中 | 高 | 服务端串行化扣减，伤害全额计入 |
| 周目难度曲线后期不可战胜 | 中 | 中 | 成长系数可配，设封顶或放缓 |
| 个人伤害刷分（弱号高伤） | 低 | 低 | 以实际战斗伤害结算，次数封顶 |
| 双榜奖励发放量过大冲击经济 | 中 | 中 | 奖励档位独立配置，经济审查 |
| 休整期成员流失 | 低 | 低 | 休整期保留查看与预热 |

## 工作假设
| 假设 | 状态 | 澄清结论 |
|------|------|----------|
| 每日挑战次数默认 3 次、不累积 | 已确认 | 默认 3 次，每日 5:00 重置，不累积到次日 |
| 战斗限时 120s（可配置）超时按伤害结算 | 已确认 | 默认 120s，可在配置表调整，超时按已造成伤害结算 |
| 个人榜仅做公会内个人榜 | 已确认 | 不做全服个人榜，仅本公会内成员伤害榜 |
| 周目无上限 | 已确认 | 周目编号从 1 起无限递增，无封顶 |
| BOSS 被击退的尾刀奖励 | 已确认 | 最后一击玩家获得尾刀分数 = BOSS 总血量 × 尾刀奖励比例；分数同时计入个人总伤害与公会总积分；UI 显示尾刀标识 |
| 公会解散时公会奖励如何处理 | 已确认 | 个人奖励仍发放给本人，公会奖励不再发放 |
