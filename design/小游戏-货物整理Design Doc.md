## 背景与目标

### 背景

主线章节间需要轻度过渡玩法调节节奏。大暑采购完毕，需要将各种行商货物塞入房车有限的储物舱，展现旅途中的生活日常。

### 目标

提供1-3分钟的俄罗斯方块变体装箱益智玩法，作为主线关卡内的分支关卡。

### 非目标

- 不涉及PVP
- 不涉及经济产出重构
- 评价档位不影响后续剧情分支

## 核心规则

### R-01: 触发与进入

- **触发条件**：主线关卡内分支节点出现，玩家可选择进入或跳过
- **前置限制**：无（可跳过，不阻断主线推进）
- **操作流程**：点击分支节点 → 进入小游戏界面 → 开始游戏
- **状态变化**：关卡状态标记为"已进入"
- **UI 反馈**：分支节点以货箱图标标识，带"可跳过"提示
- **异常边界**：玩家选择跳过则直接继续主线，无惩罚
- **落地点**：`level.xlsx`（LevelType 标记为小游戏分支） + `UIlevel.xlsx`

### R-02: 货物放置与判定

- **触发条件**：玩家拖拽货箱到储物区
- **前置限制**：货箱不可重叠；不可放置在被占用格子
- **操作流程**：拖拽货箱 → 双击旋转90° → 放入储物格 → 全部放入即通关
- **状态变化**：货箱占据对应格子
- **UI 反馈**：货物放入时有轻微吸附动画（snap to grid）+ 短促"咔嗒"声
- **异常边界**：无法放置的位置货箱弹回原位
- **落地点**：小游戏逻辑模块

### R-03: 特殊货物约束

- **触发条件**：Lv.3及以上关卡出现特殊标记货物
- **前置限制**：需满足对应约束才能放置
- **操作流程**：
  - 易碎品：不能被其他货物的角接触，需留一格缓冲
  - 重物（Lv.4）：必须放在下半区
  - 温控货物（Lv.5）：冷热不能相邻
- **状态变化**：违反约束时无法放置
- **UI 反馈**：违反约束时货箱边框闪红色
- **异常边界**：约束冲突时给出文字提示
- **落地点**：小游戏逻辑模块

### R-04: 评价与重复游玩

- **触发条件**：通关结算时
- **前置限制**：无
- **操作流程**：根据放入货物数和剩余时间计算评价 → 显示S/A/B/C档位
- **状态变化**：记录历史最佳评价
- **UI 反馈**：结算界面显示评价和得分
- **异常边界**：C级评价也不阻断流程（大暑说"剩下的绑车顶吧"）；评价仅记录展示，不影响剧情分支
- **落地点**：小游戏评价模块
- **重复游玩**：通关后可在关卡界面重新进入，支持刷新评价

## 关卡递进设计

| 梯度 | 储物空间 | 货物数 | 新增要素 |
|------|----------|--------|----------|
| Lv.1 入门 | 4×4格 | 4件 | 全部为规则形状（2×1, 2×2, 1×3），容错空间大 |
| Lv.2 初级 | 5×4格 | 6件 | 加入L形/T形货物；必须精确放置才能全部装入 |
| Lv.3 中级 | 5×5格 | 8件 | 加入"易碎品"标记（这些货物不能被其他货物的角接触，需留一格缓冲） |
| Lv.4 高级 | 6×5格 | 10件 | 加入"重物在下"规则（标记为重物的必须放在下半区）；部分格子被管道/设备占用不可放置 |
| Lv.5 挑战 | 6×6格 | 12件 | 加入"温控货物"（冷热不能相邻）；时间压力下大暑催促台词加速节奏感 |

## 数值框架

| 参数 | 数值 |
|------|------|
| 时限 | Lv.1: 45s / Lv.2: 60s / Lv.3: 75s / Lv.4: 90s / Lv.5: 100s |
| 格子尺寸 | 视觉上约60×60px（适配手机单手操作） |
| 得分计算 | 已放入货物数×50 + 剩余时间×3 + 全部放入奖励200分 |
| 评价档位 | S: 全部放入且剩余时间>40% / A: 全部放入 / B: 放入≥80% / C: 放入<80% |
| 容错机制 | C级评价也不阻断流程（大暑说"剩下的绑车顶吧"） |

## 美术风格参考

- **背景**：房车尾部储物舱打开的视角，能看到舱内金属隔板和绑带
- **货箱外观**：每种货物有独特的科幻包装设计——晶矿用六边形冷蓝容器，食材用暖橙色保温箱，机械零件用军绿色弹药箱风格
- **储物格子**：深灰色底板 + 浅色网格线，不可用格子标为红色斜纹
- **放置反馈**：货物放入时有轻微吸附动画（snap to grid）+ 短促的"咔嗒"质感
- **UI布局**：左侧为储物舱（占60%屏幕），右侧为待放入货物列表（可上下滚动），上方为时间条
- **完成特效**：最后一件放入 → 舱门自动关闭动画 → 大暑竖拇指
- **参考调性**：《收纳大师》的满足感 + 科幻货运美学
