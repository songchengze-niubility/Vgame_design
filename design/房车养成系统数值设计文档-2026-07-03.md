## 设计原则

房车养成分成两层：

| 层级 | 数值职责 | 生效范围 |
|---|---|---|
| 房车整备 / 升级 | 固定基础属性：生命、攻击、防御 | 账号全局，对所有角色生效 |
| 出行指南 / 天赋树 | 基础属性百分比 + 二级属性 + 职业机制属性 | 按角色职业生效 |

明确拆分：

| 属性类型 | 落点 |
|---|---|
| 生命 / 攻击 / 防御固定值 | 只在房车升级给 |
| 生命% / 攻击% / 防御% | 可以在天赋树给 |
| 暴击、暴伤、格挡、冷却、能量、护盾、治疗、标签伤害等 | 放在天赋树 |

路径拓扑改为单线。每个职业各自一条出行指南线，阶段内节点从前到后依次解锁，不做三分支选择。

单线顺序原则：

| 顺序 | 设计目的 |
|---:|---|
| 1 | 先给一个基础百分比节点，保证进入阶段后有稳定成长反馈 |
| 2 | 立刻插入一个二级属性节点，避免阶段开头全是基础百分比 |
| 3-6 | 百分比节点与二级属性穿插，形成小目标和阶段惊喜 |
| 末节点 | 放本阶段最有感知的二级属性，作为阶段收束和下一阶段门槛 |

阶段内单线节点：

| 阶段 | 单线顺序 |
|---|---|
| 基础 | 生命% -> 暴击等级 -> 攻击% -> 防御% -> 伤害加成 |
| 中级 | 攻击% -> 暴伤等级 -> 防御% -> 能量回复等级 -> 生命% -> 冷却缩减等级 |
| 高级 | 攻击% -> 暴击等级 -> 生命% -> 暴伤等级 -> 防御% -> 能量回复等级 -> 冷却缩减等级 |
| 精通 | 攻击% -> 暴击等级 -> 生命% -> 暴伤等级 -> 防御% -> 能量回复等级 -> 冷却缩减等级 -> 伤害加成 |

阶段推进建议改为“上一阶段末节点激活 + 房车等级”双门槛：

| 解锁 | 房车等级 | 节点条件 |
|---|---:|---|
| 中级 | 15 | 基础最后节点“伤害加成”已激活 |
| 高级 | 35 | 中级最后节点“冷却缩减等级”已激活 |
| 精通 | 50 | 高级最后节点“冷却缩减等级”已激活 |

阶段满点说明：

| 阶段 | 百分比节点满点 | 一次性节点点数 | 满阶段点数 |
|---|---:|---:|---:|
| 基础 | 3+3+3 | 2 | 11 |
| 中级 | 4+4+4 | 3 | 15 |
| 高级 | 5+5+5 | 4 | 19 |
| 精通 | 5+5+5 | 5 | 20 |

玩家可以不把百分比节点升满，但必须沿单线激活到阶段末节点才能进入下一阶段。全满是长期追求，不是阶段推进门槛。
