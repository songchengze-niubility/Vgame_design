## 背景与目标

### 背景

现有主线为单一线性节点链（横版跑酷 + Loop 波次战斗，5 章 60 关），节点类型单一，缺乏节奏调节与教学承载：战斗疲劳无法在章节内缓解、新玩法教学只能靠弹窗文案、支线剧情无处挂载。需在不破坏主线推进轴与首通经济的前提下，接入支线/小游戏/引导三类节点，并在节点切换时加入轻量演出增强旅途感。

### 目标

在现有 `MainLevel` 地图上新增支线/小游戏/引导三类独立节点，并在所有节点间切换时播放轻量房车移动/闪现演出，形成"公路旅行"的连贯感。

### 设计意图与体验目标

- **节奏调节**：支线/小游戏作为"调剂节点"穿插在战斗节点间，避免连续战斗疲劳，让章节节奏张弛有度。
- **旅途叙事**：房车在节点间移动/闪现，强化"开着房车旅行"的核心世界观，让地图不再是静态节点列表。
- **教学去文案化**：引导关卡把新玩法教学从弹窗文案升级为"上手玩一次"，降低认知成本。
- **主线纯净**：新增节点不阻断主线、不计入章节进度、不改首通经济，主线推进轴保持原样，新内容是"可选附加层"。

### 非目标

- 不修改主线关卡推进公式与首通奖励数值
- 不重做章节地图编辑器（复用现有 MainLevel 节点布局体系扩展）
- 不涉及高难主线/困难模式
- 不新增体力体系（沿用现有体力，仅调整各类节点消耗）

## 节点拓扑与类型扩展

### 拓扑关系

三类新增节点作为**地图上的独立节点**与主线节点并存于同一张 `MainLevel` 地图，而非嵌套在主线节点内的分支入口。房车可在主线节点与支线/小游戏/引导节点之间移动。

```
[主线A]──[支线A']──[主线B]──[小游戏B']──[主线C(Boss)]
              └─[引导C']
```

- 支线/小游戏/引导节点挂在相邻主线节点旁，解锁依赖该主线节点通关
- 主线节点链路保持原有 NextLevel 线性关系不变，新节点为"旁挂可选"
- 节点间切换均触发房车演出（move 或 flash）

### 节点类型对比

| 节点类型 | NodeType | 解锁条件 | 是否阻断主线 | 体力消耗 | 可重复 | 产出定位 |
|---|---|---|:---:|:---:|:---:|---|
| 主线 | `main` | 前一关通关（原有） | 是 | 10 | 可刷 | 核心推进+首通/常规产出 |
| 支线 | `side` | 相邻主线节点通关 | 否 | 10 | 可重玩(无产出) | 一次性首通产出+剧情 |
| 小游戏 | `minigame` | 相邻主线节点通关 | 否 | 0 | 可刷评价 | 评价档位产出 |
| 引导 | `tutorial` | 对应玩法首次解锁时 | 否 | 0 | 可重复复习 | 无产出，仅教学 |

## 核心规则

### 交互与容错总则

- **节点可选不强制**：支线/小游戏/引导节点均为可选，不解锁也不影响主线推进，玩家可全程跳过。
- **解锁可视化**：解锁节点在地图上从灰态变为亮态并带"NEW"角标，避免玩家漏看。
- **演出可跳过**：所有节点切换演出默认可跳过，跳过无任何惩罚，尊重重复游玩的玩家。
- **链路校验**：新增节点配置后必须校验 NextNode 链完整、无孤岛、无死锁，门禁脚本纳入检查。

### R-01: 支线关卡

- **触发条件**：玩家在地图上选择已解锁的支线节点
- **前置限制**：相邻主线节点已通关；体力 ≥ 10
- **操作流程**：点击支线节点 → 房车演出到节点 → 检查体力 → 加载支线场景 → 战斗/剧情 → 通关结算
- **状态变化**：首次通关后节点标记"已完成"；支线状态独立于主线进度
- **资源变化**：扣除体力 10；**首通**发放独立奖励配置（SideReward，一次性）；**重复进入**仅复看剧情，无任何产出
- **UI 反馈**：支线节点以分支图标标识；已完成节点显示"✓"；未完成显示首通奖励预览
- **异常边界**：体力不足弹窗提示；支线场景加载失败回退地图；已完成的支线可重复进入但不重复发奖
- **落地点**：`MainLevel.xlsx`（节点布局，NodeType=side） + `UIlevel.xlsx`（节点 UI） + 新增 `SideLevel.xlsx`（支线定义） + 新增 `SideReward.xlsx`（支线独立奖励）

### R-02: 小游戏关卡

- **触发条件**：玩家在地图上选择已解锁的小游戏节点
- **前置限制**：相邻主线节点已通关；无体力要求
- **操作流程**：点击小游戏节点 → 房车演出到节点 → 进入小游戏界面（可跳过） → 玩小游戏 → 通关结算评价
- **状态变化**：记录该小游戏节点的历史最佳评价；节点状态独立于主线进度
- **资源变化**：**不扣除体力**；按评价档位(S/A/B/C)发放对应评价掉落组奖励；重复游玩可刷新评价并再次获得对应档位产出
- **UI 反馈**：小游戏节点以对应玩法图标标识；显示历史最佳评价星标
- **异常边界**：玩家选择跳过小游戏则直接继续，无惩罚；C 级(保底)仍给基础奖励
- **落地点**：`MainLevel.xlsx`（NodeType=minigame） + `UIlevel.xlsx` + 小游戏配置表（game_id 引用，见 `design/小游戏-*`） + 评价掉落组（复用 Drop 系统）

### R-03: 玩法引导关卡

- **触发条件**：对应玩法首次解锁时强制触发首次进入；之后玩家可主动重复进入复习
- **前置限制**：对应玩法已解锁（由 SystemOpen 控制）；无体力要求
- **操作流程**：
  - 首次：玩法解锁 → 自动跳转引导节点 → 房车演出 → 教学关卡(带引导UI高亮/手势提示) → 完成教学 → 返回地图
  - 复习：玩家主动点击引导节点 → 房车演出 → 教学关卡 → 返回地图
- **状态变化**：首次完成后该玩法正式开放；引导节点标记"已完成"，常驻地图可重复进入
- **资源变化**：**不扣除体力**；**无任何产出**（纯教学，不发奖励）
- **UI 反馈**：引导节点以"?"图标标识；首次强制触发时地图镜头聚焦该节点并高亮；已完成后图标变为"i"（信息/复习）
- **异常边界**：首次强制触发不可跳过（必须完成教学才能开放玩法）；复习进入可随时退出；教学关卡内无失败判定
- **落地点**：`MainLevel.xlsx`（NodeType=tutorial） + `UIlevel.xlsx` + 新增 `TutorialLevel.xlsx`（引导关定义，引用教学目标玩法 ID）

### R-04: 节点切换演出

- **触发条件**：玩家从一个节点切换到另一节点（含主线→主线、主线→支线/小游戏/引导、反向）
- **前置限制**：目标节点已解锁
- **操作流程**：点击目标节点 → 播放房车演出(move 或 flash) → 到达目标节点 → 进入对应关卡/UI
- **状态变化**：房车在地图上的位置更新为目标节点坐标
- **资源变化**：无（演出本身不消耗资源）
- **UI 反馈**：
  - `move` 模式：房车沿直线/短曲线平移到下一节点，带轻微尾尘粒子，约 0.6~1.0s
  - `flash` 模式：房车淡出 → 短暂黑屏/白屏过渡 → 在目标节点淡入，约 0.3~0.5s
  - 章间切换(章末 Boss → 下一章首关)：使用 `flash` + 略长黑屏过渡(约 0.8s)，配章节标题淡入
- **异常边界**：演出可点击跳过，跳过后直接到达目标节点；演出期间禁止其他操作
- **落地点**：新增 `LevelTransition.xlsx`（节点间演出配置：FromNode/ToNode/Mode/Duration/Skippable）

### R-05: 节点解锁链路

- **触发条件**：相邻主线节点通关时检查旁挂节点
- **前置限制**：旁挂节点的 ParentMainNodeId 指向的主线节点已通关
- **操作流程**：主线节点通关 → 遍历该节点的旁挂节点 → 满足解锁条件则置为已解锁 → 地图上灰态转亮态 + NEW 角标
- **状态变化**：旁挂节点状态 从"未解锁"→"已解锁"
- **资源变化**：无
- **UI 反馈**：解锁瞬间地图镜头微聚焦新节点 + "NEW"角标弹跳动画 + 轻提示音
- **异常边界**：ParentMainNodeId 配置缺失时该节点永不解锁（配置门禁拦截）；同一主线节点可旁挂多个节点，按配置顺序依次解锁
- **落地点**：`MainLevel.xlsx`（ParentMainNodeId 字段） + 运行时节点解锁逻辑

### R-06: 奖励与产出

- **触发条件**：支线/小游戏节点通关结算时
- **前置限制**：支线首通需节点状态为"未完成"；小游戏任意次均可
- **操作流程**：
  - 支线首通：读取 `SideReward.xlsx` 对应 DropId → 发放一次性首通奖励 → 节点标记"已完成"
  - 支线重复：仅复看剧情，不发奖
  - 小游戏：按评价档位读取对应评价掉落组 → 发放档位产出（可重复）
  - 引导关：无产出
- **状态变化**：支线节点"已完成"标记；小游戏历史最佳评价更新
- **资源变化**：见数值与产出框架
- **UI 反馈**：结算界面区分展示"首通奖励"(支线) / "评价奖励"(小游戏) / "教学完成"(引导)
- **异常边界**：DropId 不存在降级空奖励(记日志)；支线已完成再次进入不弹结算
- **落地点**：`SideReward.xlsx`（支线） + 小游戏评价表 reward_group_id(复用 Drop) + `Drop` 逻辑表

### R-07: 体力与扫荡

- **触发条件**：进入节点前校验
- **前置限制**：见各节点体力要求
- **操作流程**：
  - 支线：消耗体力 10，通关后支持扫荡（仅复看产出为零，扫荡仅用于快速复看剧情占位）
  - 小游戏：不耗体力，按评价刷新可无限重玩
  - 引导关：免费，可无限重入
- **状态变化**：体力数值扣减（仅支线）
- **资源变化**：支线扣 10 体力
- **UI 反馈**：节点面板标注体力消耗(支线)或"免费"(小游戏/引导)
- **异常边界**：体力不足仅对支线生效；小游戏/引导关无体力门槛
- **落地点**：`level.xlsx`/`SideLevel.xlsx` Vitality 字段 + 运行时体力校验

### R-08: 章节进度计算

- **触发条件**：章节内任意节点通关后重算进度
- **前置限制**：无
- **操作流程**：章节进度 = 已通关主线节点数 / 章节主线节点总数；支线/小游戏/引导节点**不计入**分子与分母
- **状态变化**：章节进度百分比更新
- **资源变化**：进度达 20%/40%/60%/80%/100% 触发 ChapterTasks 奖励（原有逻辑不变）
- **UI 反馈**：章节进度条仅反映主线进度
- **异常边界**：支线/小游戏全部跳过不影响进度推进；进度计算口径与原有完全一致
- **落地点**：运行时进度计算逻辑（新增节点需标记 is_count_progress=false）

## 节点切换演出设计

### 演出模式

演出刻意保持轻量，不做复杂分镜，仅两种模式：

| 模式 | Mode | 适用场景 | 时长 | 说明 |
|---|---|---|---|---|
| 移动 | `move` | 同章节内相邻节点切换 | 0.6~1.0s | 房车沿直线/短曲线平移到目标节点，带尾尘粒子 |
| 闪现 | `flash` | 章间切换(章末→下章首关) / 远距离节点 | 0.3~0.5s(章间0.8s) | 房车淡出→黑屏过渡→目标节点淡入，章间配章节标题 |

### 演出规则

- **默认可跳过**：演出期间点击屏幕直接跳到目标节点，无惩罚
- **禁止并发操作**：演出期间禁用地图点击/菜单，避免状态错乱
- **资源轻量**：move 模式仅复用现有房车立绘 + 简单位移动画，不新增骨骼动画；flash 模式仅黑屏/白屏遮罩 + 淡入淡出
- **章间标题**：章间 flash 过渡时叠加下一章章节标题(配字体淡入)，强化"进入新篇章"感

### 状态机（简化）

```
Idle → (选择目标节点) → Playing(move/flash) → (演出结束/跳过) → Idle(在目标节点)
```

无中间状态，演出是一次性播放，结束即到位。

## 数值与产出框架

### 体力消耗对比

| 节点类型 | 体力消耗 | 扫荡 | 说明 |
|---|:---:|:---:|---|
| 主线 | 10 | 支持 | 原有 |
| 支线 | 10 | 不支持(无重复产出) | 首通耗体力，重复无产出故无扫荡意义 |
| 小游戏 | 0 | 不适用 | 免费，按评价重玩 |
| 引导 | 0 | 不适用 | 免费，可重复复习 |

### 产出对比

| 节点类型 | 首通产出 | 重复产出 | 产出来源 | 计入章节进度 |
|---|---|---|---|:---:|
| 主线 | 钻石+金币+经验+材料(原有) | 经验+材料(原有) | `level.xlsx` FirstRewardDrop/FallRewardDrop | 是 |
| 支线 | 独立奖励配置(一次性) | **无** | `SideReward.xlsx`(单独配置，不复用主线Drop) | 否 |
| 小游戏 | 评价档位产出 | 评价档位产出(同首通) | 小游戏评价表 reward_group_id → Drop | 否 |
| 引导 | 无 | 无 | — | 否 |

### 支线首通产出档位建议

支线走**单独奖励配置**，不复用主线 Drop 组，数值由 `SideReward.xlsx` 独立配置。建议档位（以主线同级首通为参照基线 100%）：

| 档位 | 相对主线同级首通 | 定位 |
|---|:---:|---|
| 标准 | ~80% | 常规支线，略低于主线首通 |
| 丰厚 | ~120% | 关键剧情支线，略高于主线首通 |
| 稀缺 | 含专属道具/碎片 | 角色支线，产出该角色养成素材 |

> 支线为**一次性首通产出**，无重复产出，不存在"刷支线"的经济循环，无需做重复产出平衡。

### 小游戏评价产出档位建议

| 评价 | 产出定位 | 参照 |
|---|---|---|
| S | 高档材料+少量钻石 | 约主线同级常规产出的 100% |
| A | 中档材料 | 约 70% |
| B | 低档材料 | 约 50% |
| C(保底) | 基础材料 | 约 30%，不阻断 |

> 小游戏免费可刷，故单次产出刻意低于主线体力产出，避免"白嫖替代刷主线"。具体数值由小游戏评价表 reward_group_id 引用 Drop 组配置。

## 配置表初版结构（落地点汇总）

### 新增/扩展表清单

| 表名 | 类型 | 说明 |
|---|---|---|
| `MainLevel.xlsx` | 扩展 | 在现有节点表基础上加 NodeType/ParentMainNodeId/IsCountProgress 字段，承载4类节点 |
| `SideLevel.xlsx` | 新增 | 支线关卡定义：支线剧情ID/推荐战力/场景资源/首通奖励引用 |
| `SideReward.xlsx` | 新增 | 支线独立奖励配置（单独配置，不复用主线Drop组），一次性首通产出 |
| `TutorialLevel.xlsx` | 新增 | 引导关卡定义：教学目标玩法ID/首次强制触发标记/引导UI资源 |
| `LevelTransition.xlsx` | 新增 | 节点间演出配置：FromNode/ToNode/Mode/Duration/Skippable |
| 小游戏配置表 | 复用 | minigame 节点引用 game_id(101~108)，详见 `Output/小游戏配置表_初版结构.xlsx` |
| `UIlevel.xlsx` | 扩展 | 加 NodeType 展示/节点图标/解锁角标资源 |

### 表关系

```
MainLevel.xlsx (节点布局)
  ├─ NodeType=main   → level.xlsx (原有主线关卡)
  ├─ NodeType=side   → SideLevel.xlsx → SideReward.xlsx (首通一次性)
  ├─ NodeType=minigame → 小游戏配置表 (game_id) → 评价表 → Drop
  └─ NodeType=tutorial → TutorialLevel.xlsx (引用教学目标玩法ID)

LevelTransition.xlsx (节点间演出)
  └─ FromNode/ToNode 引用 MainLevel 节点ID
```

### 字段初版结构

详细字段定义见 `Output/主线关卡扩展配置表_初版结构.xlsx`，此处给出关键字段速查：

**MainLevel.xlsx（扩展字段）**

| 字段 | 类型 | 说明 |
|---|---|---|
| NodeId | int | 节点ID(原有) |
| NodeType | enum | 节点类型 main/side/minigame/tutorial |
| ParentMainNodeId | int | 旁挂节点依赖的主线节点ID(主线节点此字段为空) |
| IsCountProgress | bool | 是否计入章节进度(主线=true,其余=false) |
| NextNode | int | 下一节点ID(主线链路) |

**SideLevel.xlsx**

| 字段 | 类型 | 说明 |
|---|---|---|
| side_id | int | 支线ID |

## 美术与演出参考

- **节点图标**：主线(战斗剑)/支线(分支符)/小游戏(对应玩法图标)/引导("?"/"i")，未解锁灰态，已解锁亮态+NEW角标
- **房车演出**：
  - move：复用现有房车立绘，沿地图路径平移，配尾尘粒子(轻量)，不做骨骼动画
  - flash：黑屏/白屏遮罩淡入淡出，章间叠加章节标题(字体淡入)
- **地图氛围**：保持现有章节地图风格，新节点旁挂位置避免遮挡主线节点
- **参考对象**：**公主连结(Princess Connect!)** 主线地图小剧场小人移动——轻量、可跳过、不抢戏的节点切换演出
- **参考调性**：旅行公路片的"过场感"，用最简演出传递"从A到B"的空间位移

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| 新增节点导致 MainLevel 链路断链/孤岛 | 中 | 高 | 配置门禁校验 NextNode 链完整 + ParentMainNodeId 有效性 |
| 支线独立奖励配置漏配导致空奖励 | 中 | 中 | SideReward 配置门禁校验 drop_group_id 存在；运行时降级空奖励记日志 |
| 小游戏免费刷产出冲击主线体力经济 | 中 | 高 | 小游戏单次产出刻意低于主线体力产出；走 Drop 组可统一调控 |
| 引导关首次强制触发打断主线节奏 | 中 | 中 | 强制触发仅在玩法解锁瞬间，时长控制在1分钟内；复习可跳过 |
| 房车演出 move 模式路径穿模/错位 | 低 | 低 | move 仅做直线/短曲线，路径由两节点坐标直接插值，不依赖复杂路径资源 |
| 新节点不计进度导致玩家误以为卡关 | 中 | 低 | 地图上未完成的新节点带明确"可选"标识，不与主线进度条挂钩 |
