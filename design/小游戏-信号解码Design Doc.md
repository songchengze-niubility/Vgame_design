## 背景与目标

### 背景

主线章节间需要轻度过渡玩法调节节奏。房车电台截获一段加密通讯，可能是前方补给站/遗迹坐标/求救信号，玩家需要破译信息。

### 目标

提供1-3分钟的密码推理益智玩法，作为主线关卡内的分支关卡，增加旅途探索感。

### 设计意图与体验目标

- **节奏定位**：作为"推理思考型"调节，放慢节奏增加探索感，适合放在动作段落后让玩家用脑而非用手。
- **核心爽点**：规律发现后的"顿悟"快感——从看似无意义的符号中破解出完整信息，配合电台播报的叙事回报，强化"我破译了信号"的成就感。
- **难度靠规则而非时间**：Lv.1-2无脑查表建立信心，Lv.3+才需发现规律，递进靠"规则复杂度"而非"时间压迫"，尊重思考型玩家。
- **兜底防卡关**：提示系统（揭示一个符号+降档为A）+ C级部分翻译奖励，确保推理能力弱的玩家也能推进，不因卡关弃游戏。
- **设计取舍**：选择密码破译而非纯解谜，是因为"截获信号→破译坐标"强叙事驱动，破译结果可直接关联剧情（补给站/遗迹/求救），增强世界观代入。

### 非目标

- 不涉及PVP
- 不涉及经济产出重构
- 评价档位不影响后续剧情分支

## 核心规则

### 交互与容错总则

- **点选输入**：从选项点选符号填入翻译区，而非手写输入，避免输入法干扰和识别误差，操作零门槛。
- **状态清晰**：已确认符号白色固定显示，待定符号闪烁光标，玩家随时知道"哪些定了、哪些还在试"，状态一目了然。
- **错误不即死**：错误只扣减尝试次数不直接失败，给玩家逐步排除的推理空间，符合"试错破译"的真实逻辑。
- **提示降档不失败**：提示后评价上限降为A级而非判失败，鼓励玩家遇到瓶颈时主动求助，而非死磕弃游。
- **可跳过无惩罚**：尊重不喜欢推理的玩家，跳过直接继续主线无任何惩罚，不强制体验。
- **保底兜底**：C级（未解出）给予部分翻译奖励，不阻断流程，评价仅记录展示。

### R-01: 触发与进入

- **触发条件**：主线关卡内分支节点出现，玩家可选择进入或跳过
- **前置限制**：无（可跳过，不阻断主线推进）
- **操作流程**：点击分支节点 → 进入小游戏界面 → 开始游戏
- **状态变化**：关卡状态标记为"已进入"
- **UI 反馈**：分支节点以电台信号图标标识，带"可跳过"提示
- **异常边界**：玩家选择跳过则直接继续主线，无惩罚
- **落地点**：`level.xlsx`（LevelType 标记为小游戏分支） + `UIlevel.xlsx`

### R-02: 解码操作与判定

- **触发条件**：玩家选择符号填入翻译区
- **前置限制**：必须在尝试次数耗尽前完成
- **操作流程**：查看密码表/规律提示 → 从选项中点选符号到对应翻译位置 → 提交判定 → 正确则通关
- **状态变化**：已确认的符号变为白色固定显示；待定符号闪烁光标
- **UI 反馈**：正确符号变金色；错误符号变红并扣减尝试次数
- **异常边界**：尝试次数耗尽但未解出，给予部分翻译奖励，不阻断流程
- **落地点**：小游戏逻辑模块

### R-03: 提示系统

- **触发条件**：玩家主动点击提示按钮
- **前置限制**：每关仅可使用1次
- **操作流程**：点击提示 → 揭示一个符号的正确对应 → 评价上限降为A级
- **状态变化**：该符号标记为已提示
- **UI 反馈**：被提示的符号高亮显示
- **异常边界**：已使用提示后再次点击无响应
- **落地点**：小游戏逻辑模块

### R-04: 评价与重复游玩

- **触发条件**：通关结算时
- **前置限制**：无
- **操作流程**：根据尝试次数和是否使用提示计算评价 → 显示S/A/B/C档位
- **状态变化**：记录历史最佳评价
- **UI 反馈**：结算界面显示评价和得分
- **异常边界**：C级（未解出）给予部分翻译奖励；评价仅记录展示，不影响剧情分支
- **落地点**：小游戏评价模块
- **重复游玩**：通关后可在关卡界面重新进入，支持刷新评价

## 关卡递进设计

| 梯度 | 密码规则 | 新增要素 |
|------|----------|----------|
| Lv.1 入门 | 直接替换——每个符号对应一个固定文字，完整密码表给出 | 纯查表翻译，6个符号 |
| Lv.2 初级 | 密码表给出80%对应关系，剩余20%需要从上下文推断 | 8个符号，需要推理1-2个 |
| Lv.3 中级 | 偏移密码——符号与文字存在固定偏移规律（如每个符号代表后移2位的文字），需先发现规律 | 10个符号，密码表仅给提示 |
| Lv.4 高级 | 双层加密——先做符号替换，再做顺序重排（给出重排规则提示） | 12个符号 |
| Lv.5 挑战 | 混合规则——信号分为3段，每段使用不同加密规则（需识别分段+分别解码） | 15个符号 |

## 数值框架

| 参数 | 数值 |
|------|------|
| 尝试次数 | Lv.1-2: 5次 / Lv.3-4: 4次 / Lv.5: 3次 |
| 时限 | Lv.1: 30s / Lv.2: 40s / Lv.3: 60s / Lv.4: 75s / Lv.5: 90s |
| 提示系统 | 每关可使用1次提示（揭示一个符号的正确对应），使用后评价上限降为A |
| 得分计算 | 正确解码100分 + 剩余尝试次数×30 + 未使用提示×50 |
| 评价档位 | S: 首次尝试正确且未用提示 / A: 2次内正确或用了提示但首次正确 / B: 3次内正确 / C: 最终未解出（给予部分翻译奖励） |

## 美术风格参考

- **背景**：房车驾驶舱内电台面板特写，周围有旋钮、信号灯、波形显示器
- **密码表**：复古科幻风的全息投影面板，符号为几何图形组合（三角+圆+线条的变体），字体为等宽科幻字体
- **加密信号**：以绿色荧光文字显示在顶部屏幕（类似老式终端显示器）
- **翻译区**：下方有空白格子等待填入，已确认的文字变为白色，待定的闪烁光标
- **UI布局**：上1/3为加密信号显示，中间为密码表/规律提示区，下1/3为玩家操作的翻译区
- **完成特效**：解码成功 → 绿色文字变为金色 → 电台播报语音读出信息内容
- **参考调性**：《Papers Please》的文书工作感 + 科幻电台的氛围感

## 玩法参考

- **参考对象**：**Tunic**（Andrew Shouldice，2022）——核心 meta 谜题为破译一本外文手册：通过符号替换 + 上下文推理逐步解读规则。辅以 **Fez**（Polytron，2012）的"先发现规律再解码"（含数字/字母体系）思路。
- **对应机制**：
  - Lv.1 直接替换查表 ↔ Tunic 早期逐字对照图文破译
  - Lv.2 密码表 80% 需推断剩余 ↔ Tunic 用上下文补全未知符号
  - Lv.3 偏移密码需先发现规律 ↔ Fez 先悟出规则再统一解码
  - Lv.4 双层加密（替换+重排）↔ Tunic 多层信息嵌套
  - Lv.5 分段不同规则 ↔ 多套密码体系并存
  - 尝试次数限制 + 1 次提示降档 ↔ 容错+兜底（区别于 Tunic 的无限制试错）
- **差异点**：本玩法给尝试次数与提示兜底、可跳过不阻断主线；规模为 1-3 分钟小谜题，远小于 Tunic/Fez 的全程 meta 解谜；美术走科幻电台终端而非异世界手册。

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 密码规律过于隐晦导致卡关 | 中 | 中 | 提示系统兜底；C级不阻断流程 |
| 玩家对推理玩法不感兴趣 | 中 | 低 | 可跳过；跳过无惩罚 |
| 高难度密码尝试次数不足 | 低 | 中 | Lv递进中尝试次数合理衰减 |
