## 3. 核心口径

### PVPVE-DMG-001：水晶生命

```text
水晶最终生命 = 10000 + 炮台生命加成
```

本文档中的基础生命占比均以 `10000` 为分母，只用于直观比较；真实对局还要计入炮台生命加成。

### PVPVE-DMG-002：水晶单次受伤

当前运行逻辑中，怪物每次有效命中水晶都会额外叠加一次炮台攻击加成：

```text
固定伤害单次实际掉血 ≈ 配置固定伤害 + 炮台攻击加成
```

因此，不能只按子弹基础伤害判断远程怪威胁。多颗子弹分别命中时，炮台攻击加成也会分别结算。

### PVPVE-DMG-003：伤害配置边界

- 怪物碰撞伤害同时作用于玩家角色和水晶，当前配置没有独立的“仅水晶伤害”字段。
- 本轮使用 PVPVE 专用怪物 Prefab，避免修改其他玩法共用的怪物实体。
- 精英射击使用 PVPVE 专用子弹 `5100101`，不得直接修改旧怪物共用子弹 `5120101`。
- `ArenaMonsterMultiplier.AttackMultiplier` 不作为本轮水晶固定伤害的主要调节手段，因为固定碰撞伤害和固定子弹伤害不直接由该倍率决定。

## 4. 六类怪物最终目标值

| 怪物 | ID | 碰撞伤害 | 远程伤害 | 无炮台加成时的单次/整轮预算 | 伤害定位 |
|---|---:|---:|---:|---:|---|
| 普通怪 | `50001` | `500` | 无 | `500`，基础水晶的 5% | 基准压力 |
| 冲刺怪 | `50002` | `800` | 无 | `800`，基础水晶的 8% | 快速抵达、高单次撞击 |
| 普通射击怪 | `50003` | `200` | `300/发` | 一发加碰撞约 `500` | 依靠持续射击积累压力 |
| 辅助怪 | `50004` | `200` | 无 | `200`，基础水晶的 2% | 低直伤，价值主要来自加速辅助 |
| 精英射击怪 | `51001` | `400` | `100/颗 × 9颗` | 九颗全中 `900`；加碰撞最高 `1300` | 高优先级散射威胁 |
| 巨型盾兵 | `51002` | `1000` | 无 | `1000`，基础水晶的 10% | 高生存、高撞击、保护怪群 |

### 角色差异结果

- 普通怪提供稳定、易理解的基准伤害。
- 冲刺怪伤害高于普通怪，并通过更快抵达制造突然漏怪惩罚。
- 普通射击怪单发和碰撞都不高，但存活时间越长，累计伤害越高。
- 辅助怪自身直伤最低，主要通过加速其他怪物放大整波压力。
- 精英射击怪按一整轮九发分配伤害，禁止把高伤害值配置到单颗子弹上。
- 巨型盾兵具有本组最高的单次碰撞伤害，同时依靠生命和护盾承担后期推进职责。

## 5. 精英射击怪九发伤害模型

设：

- `N` = 一轮中实际命中水晶的子弹数，范围 `0～9`。
- `B` = 当前炮台攻击加成。

仅计算一轮射击：

```text
精英射击一轮伤害 = N × (100 + B)
```

若射击后又撞击水晶：

```text
精英完整漏怪伤害 = N × (100 + B) + (400 + B)
```

| 炮台攻击加成 B | 命中3颗并发生碰撞 | 命中9颗并发生碰撞 | 风险判断 |
|---:|---:|---:|---|
| `0` | `700` | `1300` | 符合预期 |
| `300` | `1900` | `4300` | 九颗全中风险较高 |
| `600` | `3100` | `7300` | 九颗全中不可接受 |

结论：`100/颗`是当前上限建议，不再提高。是否需要限制九颗对子弹大体积水晶的实际命中数，必须通过实机验证决定。

## 8. 验证标准

### 静态验证

- 六个怪物 ID、Prefab和技能引用对应正确。
- 普通射击怪使用 `5000301`，精英射击怪使用PVP专用 `5100101`。
- 场景生成数据中的碰撞伤害与本文档目标值一致。
- 不直接修改生成的 `LogicData.txt/.bytes`。

### 实机验证

分别在炮台攻击加成 `0/300/600` 三档测试：

1. 每只怪单独漏到水晶，记录碰撞实际掉血。
2. 普通射击怪记录到达水晶前的射击次数和累计掉血。
3. 精英射击怪至少测试20次齐射，记录每轮实际命中水晶的子弹数量分布。
4. 验证精英射击怪九颗子弹是否分别叠加炮台攻击。
5. 验证碰撞伤害调整后，玩家角色受到的同源伤害是否仍可接受。

### 体验标准

- 普通怪作为伤害基准，玩家能直观看懂漏怪代价。
- 冲刺怪的单次威胁明显高于普通怪，但不应单只决定胜负。
- 射击怪的威胁来自持续存活，而不是单颗子弹爆发。
- 辅助怪和巨盾的功能收益与直接伤害叠加后，不应形成无解组合。
- 精英射击怪九发全中的极端情况不能在中高炮台攻击档位直接清空健康水晶。
