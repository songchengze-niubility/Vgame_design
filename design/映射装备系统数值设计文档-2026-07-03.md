## 1. 设计目标

本次调整的目标是把映射装备从“经验升级型装备”改为“掉落等级 + 品质 + 合成 + 制作 + 洗练”的长线随机养成系统。

核心体验方向：

- 装备不再升级，直接掉落固定等级装备，等级以 5 级为一档。
- 装备副本不直接掉装备，而是掉对应等级池的宝箱，每个宝箱开 1 件装备。
- 红装和金装允许较早出现，但后续主要通过装备等级区分强度。
- 后期仍保留蓝宝箱和紫宝箱少量产出，维持低中阶装备生态，用于合成、分解和过渡。
- 制作系统提供“指定等级 + 指定部位 + 随机品质”的定向追求。
- 合成系统提供 9 合 1 的低阶装备消耗路径。
- 分解系统提供金币；仅红装额外给装备高级材料。
- 装备高级材料用于红装副属性洗练和锁词条洗练，不进入普通制作循环。

## 2. 系统循环总览

```text
装备副本钥匙
-> 装备副本
-> 宝箱 + 独立制作材料掉落
-> 宝箱开出装备
-> 装备穿戴 / 9合1合成 / 分解
-> 红装分解产出装备高级材料
-> 装备高级材料用于红装副属性洗练
```

```text
制作材料 + 金币
-> 指定装备等级
-> 指定装备部位
-> 随机装备品质
```

设计分工：

| 模块 | 主要职责 |
|---|---|
| 装备副本 | 日常装备与制作材料主来源 |
| 宝箱 | 承载装备随机惊喜 |
| 制作材料 | 承载指定等级、指定部位的定向制作进度 |
| 合成 | 消耗低阶装备，向当前开放等级段推进 |
| 分解 | 回收非目标装备，提供金币；红装提供高级材料 |
| 红装洗练 | 后期红装副属性追深 |

## 3. 基础规则

### 3.1 装备等级

装备等级固定为 5 级一档：

```text
5 / 10 / 15 / 20 / 25 / 30 / 35 / 40 / 45 / 50 / 55 / 60
```

装备不再通过经验升级。装备强度由以下内容共同决定：

```text
装备等级 + 装备品质 + 部位主属性 + 副属性
```

### 3.2 装备品质

品质共 5 档：

```text
绿 < 蓝 < 紫 < 金 < 红
```

新增绿色品质装备，定位为蓝色以下的基础过渡装备。

### 3.3 品质系数

| 品质 | 主属性品质系数 | 副属性品质系数 |
|---|---:|---:|
| 绿 | 0.20 | 0.50 |
| 蓝 | 0.30 | 0.60 |
| 紫 | 0.45 | 0.70 |
| 金 | 0.70 | 0.85 |
| 红 | 1.00 | 1.00 |

设计说明：

- 主属性品质差距更大，用于体现装备品质的核心价值。
- 副属性品质差距较小，避免副属性随机性过度放大品质差距。
- 红装可以提前出现，但低等级红装不会直接压过高等级金装和紫装。

## 5. 宝箱规则

### 5.1 宝箱档位

宝箱分 5 档：

```text
绿宝箱 / 蓝宝箱 / 紫宝箱 / 金宝箱 / 红宝箱
```

每个宝箱开出 1 件装备，不开出制作材料。

| 宝箱 | 开出品质 | 品质权重 |
|---|---|---:|
| 绿宝箱 | 绿色装备 / 蓝色装备 | 80% / 20% |
| 蓝宝箱 | 蓝色装备 / 紫色装备 | 78% / 22% |
| 紫宝箱 | 紫色装备 / 金色装备 | 76% / 24% |
| 金宝箱 | 金色装备 | 100% |
| 红宝箱 | 红色装备 | 100% |

说明：

- 红装由红宝箱必定产出。
- 金宝箱改为必定产出金装，不再内置红装权重。
- 为不改变掉落期望，原金宝箱概率按 82% / 18% 拆分为新金宝箱概率与红宝箱概率。
- 拆分公式：`新金宝箱概率 = 原金宝箱概率 * 82%`；`红宝箱概率 = 原金宝箱概率 * 18%`。

## 15. 当前结论

当前方案已经形成完整的映射装备产出与消耗闭环：

```text
副本钥匙限制日常进入次数
宝箱提供装备随机掉落
制作材料提供定向追求
合成消耗低阶装备
分解回收金币
红装分解进入洗练追深
```

数值体验上：

- 前期拆装金币体感提高。
- 后期分解金币已明显压低。
- 红装后期可稳定获得，但洗练受装备高级材料限制。
- 制作材料常驻节奏偏稳，不会快速让玩家定向毕业。
- 首通奖励承担一次性推进感，主要给宝箱和制作材料，不破坏洗练材料闭环。
