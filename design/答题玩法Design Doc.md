## 背景与目标

### 背景

每日委托系统新增四类任务类型，其中"答题"为现有项目未实装的新玩法。需要一个轻量答题玩法，作为委托任务类型之一，也可作为可复用的独立玩法（后续可挂载到番外剧情节点、活动等）。

### 目标

设计一套题库配置驱动的轻量答题玩法：从题库组抽取若干题目，玩家选择答案，判定对错，完成一组答题即视为通关，用于承载委托任务与未来复用场景。

### 设计意图与体验目标

- **轻量**：单次答题 3-5 题，1-2 分钟完成，低认知负担。
- **配置驱动**：题库按题库组(quiz_group)管理，题目类型/难度/题干/选项/答案均配置化，便于扩展。
- **可复用**：答题玩法不绑定委托，通过 quiz_group_id 被委托/番外/活动引用。
- **世界观承载**：题目内容可承载世界观/设定科普，与番外世界观补足定位呼应。

### 非目标

- 不做排行榜/计时竞速（本期纯完成制）
- 不做题库编辑器（配置表驱动即可）
- 不涉及多人答题

## 核心规则

### 交互与容错总则

- **配置驱动**：所有题目由 `Quiz.xlsx`（题库）+ `QuizGroup.xlsx`（题库组）配置，运行时按组抽取。
- **无体力**：答题免费。
- **无失败**：答错不中断，记为错误，完成全部题目即通关（不设必须全对的硬门槛，由奖励档位区分）。
- **可重试**：未完成前可重复进入重答；完成后按调用方约定是否可重复（委托场景当日完成即锁定）。

### R-01: 答题流程

- **触发条件**：调用方传入 quiz_group_id（如委托任务节点点击"前往"）
- **前置限制**：quiz_group_id 存在且题库组内题目数 ≥ 1
- **操作流程**：
  - 加载题库组 → 按规则抽取 N 题 → 进入答题界面 → 逐题展示题干+选项 → 玩家选择 → 即时判定对错（对✓/错✗反馈）→ 下一题 → 全部完成 → 结算
- **状态变化**：记录本次答题正确数 / 总题数
- **资源变化**：无直接资源（奖励由调用方按结果发放）
- **UI 反馈**：题干 + 选项卡片；选择后正确选项高亮绿、错误选项高亮红；顶部进度 `第 x/N 题`；结算显示正确率
- **异常边界**：题库组题目数不足 N 时按实际数量；题目资源缺失跳过该题并记日志
- **落地点**：`QuizGroup.xlsx` + `Quiz.xlsx` + 答题 UI

### R-02: 题目抽取规则

- **触发条件**：进入答题
- **前置限制**：题库组有效
- **操作流程**：
  - 默认随机抽取，按 `QuizGroup.xlsx.draw_count` 取题数
  - 可配置按难度分层抽取（如易2+中2+难1）
  - 同次答题不重复抽同一题
- **状态变化**：无
- **资源变化**：无
- **UI 反馈**：无
- **异常边界**：题库组题目数 < draw_count 时取全部
- **落地点**：`QuizGroup.xlsx`（draw_count / difficulty_split）

### R-03: 题目类型

| 题型 | type | 说明 |
|---|---|---|
| 单选 | `single` | 4 选 1，1 个正确答案 |
| 多选 | `multi` | 4 选 N，多个正确答案，全对才计正确 |
| 判断 | `judge` | 对/错二选一 |

### R-04: 结算与奖励

- **触发条件**：完成全部题目
- **前置限制**：无
- **操作流程**：结算 → 展示正确率 → 回调调用方（上报正确数/总题数）→ 调用方按自身规则发奖
- **状态变化**：无（奖励由调用方决定）
- **资源变化**：无直接（调用方发放）
- **UI 反馈**：结算界面显示正确数/总题数、正确率、各题对错回顾
- **异常边界**：调用方未配置奖励则仅展示结算
- **落地点**：答题结算 UI + 调用方奖励逻辑

> 委托场景：完成一组答题即视为委托完成，发放 `DailyQuest.xlsx.reward_drop_id`（不按正确率分档，降低日常压力）。未来复用场景可按正确率分档发奖。

## 配置表初版结构

### 新增表清单

| 表名 | 类型 | 说明 |
|---|---|---|
| `QuizGroup.xlsx` | 新增 | 题库组：抽取规则、题数、难度分层 |
| `Quiz.xlsx` | 新增 | 题库：题干、题型、选项、答案、难度、世界观标签 |

### QuizGroup.xlsx 字段初版结构

| 字段 | 类型 | 说明 |
|---|---|---|
| quiz_group_id | int | 题库组ID |
| name | string | 题库组名 |
| draw_count | int | 抽取题数 |
| difficulty_split | string | 难度分层（如 "easy:2,mid:2,hard:1"，可选） |
| question_pool | string | 题目ID池（逗号分隔，留空则取该组全部） |
| description | string | 说明 |

### Quiz.xlsx 字段初版结构

| 字段 | 类型 | 说明 |
|---|---|---|
| quiz_id | int | 题目ID |
| group_id | int | 所属题库组ID |
| type | enum | single/multi/judge |
| difficulty | enum | easy/mid/hard |
| question | string | 题干 |
| option_a | string | 选项A |
| option_b | string | 选项B |
| option_c | string | 选项C（judge型可空） |
| option_d | string | 选项D（judge型可空） |
| answer | string | 正确答案（single: "A"/"B"/...；multi: "A,B"；judge: "T"/"F"） |
| explanation | string | 解析（可选，答错时展示） |
| lore_tag | string | 世界观标签（可选，用于题目主题分类） |

### 表关系

```
QuizGroup.xlsx (题库组)
  └─ question_pool / group_id → Quiz.xlsx (题目)
        └─ 运行时按 draw_count / difficulty_split 抽取

调用方（委托/番外/活动）→ quiz_group_id → 答题玩法 → 结算回调
```

> 配置门禁校验：
> - Quiz.answer 选项引用合法（single 单值、multi 多值、judge T/F）
> - QuizGroup.question_pool 中 quiz_id 存在且 group_id 一致
> - draw_count ≤ 题库组题目数

## 美术与 UI

- **答题界面**：题干居上，选项卡片纵向排列，选择后即时反馈动画
- **反馈**：正确选项绿色 + ✓ 音效；错误选项红色 + ✗ 音效，同时正确选项高亮
- **进度**：顶部进度点 `●●○○○`
- **结算**：正确率大字 + 各题对错列表 + 解析折叠查看
- **风格**：沿用项目整体 UI 风格，答题卡片用对话/卷轴质感

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| 题库内容错误（答案配置错） | 中 | 中 | 配置门禁校验 answer 合法性；题库评审流程 |
| 题库数量不足导致重复体验 | 中 | 低 | 题库组按主题分组，初期每组 ≥10 题，持续补充 |
| 多选题判定过严影响体验 | 低 | 低 | 多选全对才计正确，但委托场景不按正确率发奖，降低压力 |

## 工作假设

| 假设 | 状态 | 澄清结论 |
|---|---|---|
| 答题免费、无失败、完成即通关 | 已确认 | 委托场景不按正确率分档 |
| 题型含单选/多选/判断 | 已确认 | |
| 题库配置驱动，按组抽取 | 已确认 | |
| 答题可被委托/番外/活动复用 | 已确认 | 通过 quiz_group_id 引用 |

## 数据埋点方案

| 埋点事件名 | 触发时机 | 上报字段 | 分析用途 |
|---|---|---|---|
| quiz_start | 进入答题 | user_id, quiz_group_id, source(委托/番外/活动), draw_count | 分析答题启动来源 |
| quiz_answer | 单题作答 | user_id, quiz_id, group_id, chosen, is_correct, time_spent | 分析题目难度、作答时长、错误率 |
| quiz_complete | 答题结算 | user_id, quiz_group_id, correct_count, total_count, accuracy | 分析正确率分布 |
| quiz_retry | 重复进入答题 | user_id, quiz_group_id, retry_count | 分析重试率 |
