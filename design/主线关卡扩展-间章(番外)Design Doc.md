## 背景与目标

### 背景

现有主线为 5 章 60 关线性节点链，已接入支线(side)/小游戏(minigame)/引导(tutorial) 三类旁挂节点。但章节之间缺乏集中补足世界观的叙事段落，且现有旁挂内容均为章节内部局部调剂。需要一种位于章节之间、带主题、结构与主线对齐（主线/支线/宝箱/剧情/小游戏）的"番外"段落，用于世界观补足。

### 目标

在章节大地图**上方**排布番外节点入口，玩家**集齐指定钥匙道具后消耗道具解锁**番外；解锁后番外内部结构与主线相同，分为番外主线关卡、番外支线、番外宝箱、番外剧情、番外小游戏五类节点。未获得解锁道具时，点击道具弹出道具获取途径弹窗，点击途径可跳转至对应房车舱室位置。

### 设计意图与体验目标

- **世界观补足**：把主线无法展开的设定集中在一个主题下交付。
- **结构对齐主线**：番外内部复用主线五类节点体验（主线/支线/宝箱/剧情/小游戏），降低玩家学习成本。
- **解锁即目标**：用钥匙道具作为番外解锁门槛，道具获取引导玩家回流房车舱室养成/玩法，形成"日常产出道具 → 攒齐解锁番外"的中长期目标。
- **可选不阻断**：番外完全可选，不解锁不影响主线推进。

### 非目标

- 不修改主线推进公式、首通奖励数值、章节进度计算口径
- 不改主线章间 flash 演出
- 不强制玩家进入番外
- 不新增体力体系（沿用各节点既有体力规则）
- 不重做章节地图编辑器（复用 MainLevel 节点布局体系扩展）

## 番外定位与拓扑

### 地图排布

番外入口及番外内部节点排布在**章节大地图上方**区域，与主线节点链（地图中部/下方）分离，形成独立的"番外带"。

```
═══════════════════════════════════════════════════  ← 番外带（地图上方）
  [番外入口🔒]──[番外主线]──[宝箱]──[剧情]──[支线]──[小游戏]──[番外主线Boss]
       ▲                                          │
       │ (解锁后move进入)                          │ (完成后常驻可重访)
═══════════════════════════════════════════════════
  [Ch(n) 主线 …… Ch(n) Boss]──flash──>[Ch(n+1) 首关]   ← 主线带（地图中/下方）
```

- 番外入口位于对应章节大地图上方，解锁前显示锁定态 + 所需钥匙道具图标
- 解锁后房车 move 到番外入口，进入番外带
- 番外带内节点链路结构与主线一致（线性 + 旁挂）
- 主线章间 flash 独立播放，与番外无关

### 番外 vs 主线 vs 既有支线

| 维度 | 主线 | 既有支线(side) | 番外 |
|---|---|---|---|
| 位置 | 地图中/下方 | 旁挂主线节点 | 地图上方番外带 |
| 解锁 | 前一关通关 | 相邻主线节点通关 | 集齐钥匙道具消耗解锁 |
| 内部结构 | 主线关卡 | 单节点 | 主线/支线/宝箱/剧情/小游戏五类 |
| 计入章节进度 | 是 | 否 | 否 |
| 产出 | 首通+常规 | 首通一次性 | 各节点首通 + 番外完成里程碑 |

## 核心规则

### 交互与容错总则

- **完全可选**：番外不解锁下一章、不阻断任何主线操作，玩家可全程跳过。
- **地图常驻**：解锁后番外带永久可见可进入，玩家可随时回头。
- **复用既有节点规则**：番外内的支线/小游戏节点沿用 `主线关卡扩展-支线·小游戏·引导` 文档 R-01~R-08；宝箱/剧情/番外主线为本文档新增。
- **链路校验**：番外容器表的 node_id_list 必须均为 MainLevel 已存在节点，门禁校验无孤岛、无跨章错挂、NodeType 合法。

### R-01: 番外解锁（钥匙道具消耗）

- **触发条件**：玩家在番外入口点击"解锁"按钮
- **前置限制**：玩家持有该番外所需钥匙道具 ≥ 1（单个钥匙道具消耗解锁）
- **操作流程**：
  - 入口锁定态显示所需钥匙道具图标 + 持有数 `0/1`
  - 点击入口 → 弹出解锁确认弹窗（展示道具、番外主题、奖励预览）→ 确认 → 扣除钥匙道具 ×1 → 番外状态置"已解锁" → 入口转亮态 + 房车 move 进入
- **状态变化**：番外 "未解锁" → "已解锁"；钥匙道具 -1
- **资源变化**：消耗钥匙道具 ×1（道具ID 由 `Interlude.xlsx.unlock_item_id` 指定）
- **UI 反馈**：解锁瞬间入口锁碎裂动画 + 番外标题牌弹跳 + 主题短旋律
- **异常边界**：钥匙道具不足时"解锁"按钮灰态，点击提示"道具不足"；道具扣除与解锁状态写入需事务化，失败回滚
- **落地点**：`Interlude.xlsx`（unlock_item_id） + 道具表 + 运行时解锁逻辑

### R-02: 道具获取途径弹窗与跳转

- **触发条件**：玩家在番外入口（未持有钥匙道具时）点击道具图标，或在解锁弹窗中点击道具
- **前置限制**：钥匙道具持有数 = 0
- **操作流程**：
  - 点击道具 → 弹出"道具获取途径"弹窗：展示道具图标、名称、说明，以及 1~N 条获取途径（每条含途径描述 + "前往"按钮 + 目标房车舱室ID）
  - 点击"前往" → 关闭弹窗 → 跳转至对应房车舱室位置（房车内部对应功能舱室界面）
- **状态变化**：无
- **资源变化**：无
- **UI 反馈**：途径弹窗以列表形式展示，每条途径标注产出概率/数量参考；"前往"按钮高亮
- **异常边界**：途径对应舱室未开放（SystemOpen 未触发）时"前往"按钮灰态并提示解锁条件；无任何途径配置时弹窗显示"暂无获取途径"
- **落地点**：`Interlude.xlsx`（unlock_item_id） + 道具表（item.source_list，途径来源） + 房车舱室跳转接口

### R-03: 番外进入与离开

- **触发条件**：玩家点击已解锁的番外入口节点
- **前置限制**：番外已解锁
- **操作流程**：
  - 进入：点击入口 → 房车 move 演出到入口 → 播放番外标题演出（标题淡入，约 0.8s，可跳过） → 进入番外首节点
  - 番外内节点间切换：沿用既有节点切换演出（move）
  - 离开：玩家点击主线节点 → 从番外节点 flash 到目标主线节点
- **状态变化**：房车位置更新；番外内已通关节点标"✓"
- **资源变化**：仅按进入的具体节点类型扣体力（见各节点规则）
- **UI 反馈**：番外带用半透明主题色背板与主线带区分；番外标题牌常驻番外带左端
- **异常边界**：番外未解锁时点击入口触发 R-01/R-02 流程而非进入
- **落地点**：`MainLevel.xlsx` + `LevelTransition.xlsx`（move/flash） + 番外标题演出资源

### R-04: 番外主线关卡（新增 leveltype）

- **触发条件**：玩家选择番外带内番外主线节点
- **前置限制**：番外主线节点前置节点已通关；体力 ≥ 10
- **操作流程**：复用主线关卡 R-01 流程（选关→检查体力→加载场景→战斗→通关结算）
- **状态变化**：通关后节点标"已通关"；首通触发首通奖励
- **资源变化**：扣体力 10；首通发 `InterludeMainLevel.xlsx.first_reward_drop`；重复发 `fall_reward_drop`
- **UI 反馈**：番外主线节点用专属图标（番外主题色战斗图标）；面板显示推荐战力、奖励预览
- **异常边界**：体力不足弹窗；加载失败回退番外带
- **落地点**：`level.xlsx` 新增 **leveltype 枚举值 `interlude_main`** + `InterludeMainLevel.xlsx`（番外主线定义） + `UIlevel.xlsx`

> **leveltype 扩展**：在 `level.xlsx` 现有 leveltype 字段新增枚举值 `interlude_main`，用于标识番外主线关卡，与主线 main 区分以便结算、产出、地图图标差异化处理。

### R-05: 番外支线 / 小游戏（复用）

- 完全复用 `主线关卡扩展-支线·小游戏·引导` R-01（side）/ R-02（minigame）规则
- 番外内 side 节点：体力 10，首通一次性 `SideReward`，重复仅复看剧情
- 番外内 minigame 节点：免费，按评价发产出，可重复
- 仅地图位置位于番外带，配置上 `ParentMainNodeId` 指向番外主线节点（而非主线节点），由 `Interlude.node_id_list` 归组
- **落地点**：`SideLevel.xlsx` / `SideReward.xlsx` / 小游戏配置表（既有，不改结构）

### R-06: 番外宝箱节点（新增 NodeType=chest）

- **触发条件**：玩家选择番外带内宝箱节点
- **前置限制**：宝箱节点前置节点已通关；无体力要求
- **操作流程**：点击宝箱节点 → 房车 move 到节点 → 播放开箱动画 → 发放宝箱奖励 → 节点标"已开启"
- **状态变化**：宝箱节点 "未开启" → "已开启"（一次性）
- **资源变化**：**不扣体力**；发放 `ChestLevel.xlsx.chest_drop_id` 对应 Drop 组（一次性）
- **UI 反馈**：宝箱节点用宝箱图标；未开启显示光效，已开启显示"已开启"灰态
- **异常边界**：DropId 缺失降级空奖励（记日志）；已开启宝箱不可重复开启
- **落地点**：`MainLevel.xlsx`（**NodeType=chest**） + 新增 `ChestLevel.xlsx` + `Drop`

### R-07: 番外剧情节点（新增 NodeType=story）

- **触发条件**：玩家选择番外带内剧情节点
- **前置限制**：剧情节点前置节点已通关；无体力要求
- **操作流程**：点击剧情节点 → 房车 move 到节点 → 播放纯剧情（对话/演出，无战斗） → 完成 → 节点标"已阅"
- **状态变化**：剧情节点 "未阅" → "已阅"
- **资源变化**：**不扣体力**；**无产出**（纯叙事，不发奖励）
- **UI 反馈**：剧情节点用对话气泡图标；已阅显示"✓"；可重复进入复看剧情
- **异常边界**：剧情资源缺失时弹提示并标记已阅避免卡链路；可重复进入
- **落地点**：`MainLevel.xlsx`（**NodeType=story**） + 新增 `StoryLevel.xlsx`（剧情资源引用） + 剧情系统

### R-08: 番外完成里程碑奖励

- **触发条件**：番外内**所有番外主线节点 + 所有支线节点**均首通完成（宝箱/剧情/小游戏不强制）
- **前置限制**：番外已解锁；全部番外主线 + 支线节点"已完成"
- **操作流程**：最后一个 required 节点首通结算后 → 检查完成条件 → 达标弹窗发放番外完成奖励 → 番外标题牌变"✓ 已完成"
- **状态变化**：番外 "已解锁" → "已完成"
- **资源变化**：发放 `Interlude.xlsx.complete_reward_drop_id` 对应 Drop 组（一次性）
- **UI 反馈**：专属"番外完结"结算界面：主题插画 + 完成奖励 + "番外完结"文案
- **异常边界**：complete_reward_drop_id 缺失降级空奖励；宝箱未开/剧情未阅/小游戏未达 S 不阻断完成
- **落地点**：`Interlude.xlsx`（complete_reward_drop_id） + `Drop` + 专属结算 UI

### R-09: 番外与章节进度

- 番外所有节点 `IsCountProgress=false`，**不计入章节进度分子与分母**
- 沿用既有 R-08 进度计算口径，番外全部跳过不影响任何章节进度
- **落地点**：`MainLevel.xlsx`（IsCountProgress=false）

## 番外内容设计框架

### 节点构成建议

单个番外典型由 5-9 个节点组成，整体体验时长 10-20 分钟：

| 节点角色 | 类型 | 数量 | 作用 |
|---|---|:---:|---|
| 开场 | 番外主线 | 1 | 引入主题，一场战斗 |
| 展开 | 剧情 | 1-2 | 纯叙事铺陈世界观 |
| 调剂 | 小游戏 | 1-2 | 互动玩法调节节奏 |
| 探索 | 宝箱 | 1-2 | 探索奖励，低压力 |
| 分支 | 支线 | 0-2 | 旁挂支线，额外剧情+战斗 |
| 收束 | 番外主线(Boss) | 1 | 收束主题，触发番外完成 |

### 主题与世界观补足方向

| 主题方向 | 示例 | 补足的世界观 |
|---|---|---|
| NPC 前史 | "番外·老兵的旧照片" | 同行 NPC 过往与动机 |
| 区域风土 | "番外·荒原驿站" | 途经区域生态、居民、风俗 |
| 势力暗线 | "番外·信号塔下" | 敌对势力内部矛盾或第三方势力 |
| 另一视角 | "番外·城破那夜" | 主线事件从配角/平民视角重述 |
| 旅途插曲 | "番外·暴风雪困车" | 房车旅途突发事件，纯人物互动 |

### 钥匙道具产出设计

钥匙道具是番外解锁的中长期目标载体，其产出挂载到房车舱室玩法，引导玩家回流日常玩法：

| 番外 | 钥匙道具 | 获取途径（房车舱室）示例 |
|---|---|---|
| 番外1 | 荒原驿站的旧钥匙 | 温泉玩法产出 / 爬塔层数奖励 / 研究所产出 |
| 番外2 | 老兵的铁牌 | 角色经验副本 / 公会BOSS挑战 / 商店兑换 |
| 番外3 | 信号塔碎片 | 小游戏评价奖励 / 签到 / 通行证 |

> 钥匙道具产出跨度建议 3-7 天日常产出可攒齐，形成"日常 → 道具 → 番外"的中期循环。具体数值由道具表 source_list 配置，经经济模拟验证。

### 番外完成奖励档位建议

以番外内全部番外主线 + 支线首通总和为基线 100%：

| 档位 | 相对基线 | 定位 |
|---|:---:|---|
| 标准 | ~30% | 常规番外，小额补充 |
| 丰厚 | ~60% | 关键剧情番外，含抽卡券 ×1 |
| 稀缺 | 含专属道具/碎片 | 角色主题番外，产出该角色养成素材 |

### 表关系

```
Interlude.xlsx (番外容器)
  ├─ unlock_item_id          → 道具表 (钥匙道具, 含 source_list → 房车舱室)
  ├─ entrance_node_id        → MainLevel.xlsx (番外入口节点)
  ├─ node_id_list            → MainLevel.xlsx (番外内节点列表)
  │     ├─ NodeType=interlude_main → level.xlsx(leveltype=interlude_main) → InterludeMainLevel.xlsx
  │     ├─ NodeType=side          → SideLevel.xlsx → SideReward.xlsx
  │     ├─ NodeType=minigame      → 小游戏配置表 → 评价表 → Drop
  │     ├─ NodeType=chest         → ChestLevel.xlsx → Drop
  │     └─ NodeType=story         → StoryLevel.xlsx → 剧情系统
  └─ complete_reward_drop_id → Drop (番外完成里程碑)

LevelTransition.xlsx
  └─ 主线→番外入口(move) / 番外内节点(move) / 番外→主线(flash)
```

## 美术与演出

### 番外带视觉

- **地图上方番外带**：半透明主题色蒙版区域，与主线带上下分区
- **入口锁定态**：番外入口显示锁图标 + 钥匙道具图标 + 持有数 `0/1`
- **标题牌**：解锁后立"番外·{主题名}"标题牌，弹跳 + 主题短旋律
- **节点图标**：番外主线（主题色战斗图标）/ 支线（分支符）/ 小游戏（玩法图标）/ 宝箱（宝箱图标）/ 剧情（对话气泡图标）
- **完成态**：番外完成后标题牌加"✓"，番外带主题色转金

### 道具获取途径弹窗

- 弹窗标题：道具图标 + 名称 + 说明
- 途径列表：每条含途径图标、描述、产出参考、"前往"按钮
- "前往"按钮：跳转房车舱室，未开放舱室灰态显示解锁条件

### 演出

| 场景 | 模式 | 时长 | 说明 |
|---|---|---|---|
| 主线 → 番外入口 | move | 0.6~1.0s | 房车上行驶入番外带 |
| 番外标题演出 | 专属 | ~0.8s | 标题牌淡入 + 主题短旋律，可跳过 |
| 番外内节点间 | move | 0.6~1.0s | 复用既有 |
| 宝箱开启 | 专属 | ~1.0s | 开箱动画 + 光效 |
| 番外 → 主线节点 | flash | 0.3~0.5s | 离开番外回主线 |
| 番外完结结算 | 专属 | — | 主题插画 + 完成奖励 + "番外完结"文案 |

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| 钥匙道具产出失控导致番外解锁过快/过慢 | 高 | 高 | 道具 source_list 经经济模拟验证；产出跨度 3-7 天可攒齐 |
| 新增 NodeType=chest/story 与 leveltype=interlude_main 影响既有节点链路 | 中 | 高 | 配置门禁校验 NodeType 合法性与 leveltype 对应关系；新增值不影响既有枚举 |
| 番外带挤占地图上方空间，不同分辨率适配 | 中 | 中 | 番外带单独区域，支持上下滚动/缩放；分辨率适配测试 |
| 番外主线复用 level.xlsx 但 leveltype 新增导致既有查询逻辑误判 | 中 | 中 | leveltype=interlude_main 在主线进度/首通经济计算中显式排除 |
| 道具获取途径跳转目标舱室未开放造成死路 | 中 | 中 | "前往"按钮按 SystemOpen 校验，未开放灰态提示 |
| 番外完成奖励 + 各节点首通叠加产出过高 | 中 | 中 | 完成奖励控制在 30%-60%；走 Drop 组统一调控 |
| 玩家忽略番外导致世界观补足失效 | 高 | 低 | 可选设计本不强制；靠地图上方醒目位置 + 道具目标引导 + 完成奖励诱导 |
