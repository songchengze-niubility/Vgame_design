## 背景与目标

### 背景

主线章节间需要轻度过渡玩法调节节奏。房车穿越荒漠风暴带，飞沙走石中需要灵活躲避碎片，营造旅途中的危险穿越感。

### 目标

提供1-2分钟的反应躲避玩法，作为主线关卡内的分支关卡，在剧情紧张段落后释放压力。

### 设计意图与体验目标

- **节奏定位**：作为"反应紧张型"调节，在剧情平静段落后制造起伏，用操作紧张感承接叙事张力。
- **核心爽点**：极限穿梭+收集能量碎片的风险收益平衡——玩家在躲避中主动冒险拾取加分，形成"贪与稳"的张力。
- **去弹幕化挫败**：3次护盾+70%宽松判定，区别于传统弹幕的一击必杀，给玩家"侥幸生还"的容错空间，降低挫败。
- **安全感设计**：沙暴波有明确的安全缝隙（光束提示），传达"解法存在"的确定性，而非纯随机不可预判的绝望。
- **设计取舍**：选择房车而非角色作为躲避主体，强化"驾驶穿越风暴"的旅途叙事；障碍物用70%判定框，视觉擦边但判定未撞，制造刺激而非挫败。

### 非目标

- 不涉及PVP
- 不涉及经济产出重构
- 评价档位不影响后续剧情分支

## 核心规则

### 交互与容错总则

- **防遮挡**：房车跟随手指但有偏移量，手指不完全遮挡房车，避免"看不到自己"的误操作。
- **宽松判定**：碰撞判定为实际图形的70%，视觉撞到但判定未撞时给玩家"侥幸生还"的正向体验，而非"明明躲开了"的冤枉失败。
- **无敌防连击**：被撞后1s无敌闪烁，防止连续撞击瞬间清空3次护盾，给玩家调整走位的喘息。
- **无解规避**：障碍生成有最小间距保证可达安全区，杜绝"四面八方同时封死"的无解局面。
- **手感可调**：惯性0.1s可调为0直接跟随，适应不同玩家手感偏好；沙暴波安全缝隙=房车高度×2.5，确保可通过。
- **保底兜底**：C级（未存活到目标时间）也给保底奖励，不阻断主线推进。

### R-01: 触发与进入

- **触发条件**：主线关卡内分支节点出现，玩家可选择进入或跳过
- **前置限制**：无（可跳过，不阻断主线推进）
- **操作流程**：点击分支节点 → 进入小游戏界面 → 开始游戏
- **状态变化**：关卡状态标记为"已进入"
- **UI 反馈**：分支节点以风暴图标标识，带"可跳过"提示
- **异常边界**：玩家选择跳过则直接继续主线，无惩罚
- **落地点**：`level.xlsx`（LevelType 标记为小游戏分支） + `UIlevel.xlsx`

### R-02: 移动与躲避

- **触发条件**：游戏开始后障碍物生成
- **前置限制**：房车移动范围限定在游戏区域内
- **操作流程**：拖拽房车移动 → 躲避飞来的障碍物 → 收集能量碎片加分 → 存活到目标时间即通关
- **状态变化**：碰撞时减少1次护盾；0次护盾时游戏结束
- **UI 反馈**：被撞后护盾闪红色碎裂，1s无敌闪烁；能量碎片有高辨识度光圈
- **异常边界**：碰撞判定为实际图形的70%（宽松判定，降低挫败感）
- **落地点**：小游戏逻辑模块

### R-03: 特殊障碍机制

- **触发条件**：Lv.3及以上关卡
- **前置限制**：无
- **操作流程**：
  - 沙暴波（Lv.3）：全屏横向扫过，需移动到安全缝隙
  - 追踪碎片（Lv.4）：缓慢追踪玩家位置，需绕开
  - 视野缩小（Lv.4）：模拟沙暴遮蔽，可视范围缩小
  - 风暴核心（Lv.5最后10s）：障碍物从四面八方涌来，密度翻倍
- **状态变化**：障碍物类型和密度随关卡递增
- **UI 反馈**：沙暴波有光束提示安全缝隙；追踪碎片有暗紫色尾焰
- **异常边界**：特殊障碍不叠加同屏过多导致无法躲避
- **落地点**：小游戏逻辑模块

### R-04: 评价与重复游玩

- **触发条件**：通关或游戏结束结算时
- **前置限制**：无
- **操作流程**：根据碰撞次数和收集分数计算评价 → 显示S/A/B/C档位
- **状态变化**：记录历史最佳评价
- **UI 反馈**：结算界面显示评价和得分
- **异常边界**：C级（未存活到目标时间）也给保底奖励；评价仅记录展示，不影响剧情分支
- **落地点**：小游戏评价模块
- **重复游玩**：通关后可在关卡界面重新进入，支持刷新评价

## 关卡递进设计

| 梯度 | 存活时间 | 新增要素 |
|------|----------|----------|
| Lv.1 入门 | 20s | 仅岩石（直线飞来，速度慢），能量碎片固定出现 |
| Lv.2 初级 | 30s | 加入铁片（斜线飞来，速度中等）；障碍物密度+30% |
| Lv.3 中级 | 40s | 加入"沙暴波"（全屏横向扫过，需移动到安全缝隙）；能量碎片变为移动状态 |
| Lv.4 高级 | 50s | 加入"追踪碎片"（缓慢追踪玩家位置，需绕开）；视野范围缩小（模拟沙暴遮蔽） |
| Lv.5 挑战 | 60s | 全部要素叠加；最后10秒为"风暴核心"——障碍物从四面八方涌来，密度翻倍 |

## 数值框架

| 参数 | 数值 |
|------|------|
| 房车移动速度 | 跟随手指，最大速度600px/s，有0.1s惯性延迟 |
| 障碍物速度 | 岩石: 200px/s / 铁片: 350px/s / 追踪碎片: 150px/s |
| 障碍物生成频率 | Lv.1: 每1.5s / Lv.3: 每0.8s / Lv.5: 每0.5s |
| 沙暴波 | 宽度=屏幕高度80%，安全缝隙=房车高度×2.5 |
| 碰撞判定 | 房车碰撞箱为实际图形的70%（宽松判定，降低挫败感） |
| 能量碎片 | 每个+50分，每5秒生成1个 |
| 生命机制 | 3次碰撞机会（被撞后1s无敌闪烁），0次时结束 |
| 得分计算 | 存活时间×10 + 能量碎片收集数×50 + 零碰撞奖励300分 |
| 评价档位 | S: 0碰撞通关 / A: ≤1碰撞通关 / B: ≤2碰撞通关 / C: 未存活到目标时间 |

## 美术风格参考

- **背景**：黄褐色沙暴环境，能见度低，远景模糊，有沙粒粒子持续飘动
- **房车**：卡通化的侧面剪影，带有元能护盾光效（被撞后护盾闪红色碎裂）
- **障碍物**：岩石为深褐色多边形块 / 铁片为银灰色旋转锐器 / 追踪碎片为暗紫色带尾焰
- **能量碎片**：明亮的青蓝色菱形结晶，带脉冲光圈（高辨识度）
- **沙暴波**：浓密的土黄色横条快速扫过，安全缝隙处颜色较浅有光束提示
- **UI布局**：全屏游戏区域，左上角3个护盾图标表示生命，右上角分数，底部有进度条（剩余时间）
- **完成特效**：存活到最后 → 沙暴逐渐消散 → 远方出现新地标建筑的剪影 → 胜利音效
- **参考调性**：《几何冲刺》的紧迫感（降低版）+ 末日荒漠电影氛围

## 玩法参考

- **参考对象**：**东方Project（Touhou）** 弹幕躲避的安全缝隙穿越机制（降密度版）；整体属轻量 dodge/bullet-hell-lite 品类。
- **对应机制**：
  - 全屏房车移动躲避飞来障碍 ↔ 弹幕躲避的自由移动规避
  - 沙暴波需移动到安全缝隙 ↔ Touhou 弹幕墙中的安全间隙穿越
  - 追踪碎片缓慢追玩家 ↔ 追踪型弹幕/敌机
  - 视野缩小模拟沙暴遮蔽 ↔ 弹幕关卡的视野/状态干扰
  - 风暴核心四面八方密度翻倍 ↔ 高密度弹幕 finale
  - 3 次护盾 + 70% 宽松判定 ↔ 降低挫败感的容错设计（区别于弹幕一击即死）
- **差异点**：用 70% 判定框+3 次护盾替代弹幕的一击必杀，密度大幅降低；定位为可跳过的章节过渡而非硬核 STG；美术走末日荒漠而非东方的幻想乡。
