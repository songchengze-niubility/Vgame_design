## 1. 背景与目标

### 1.1 背景

房车设备是房车养成中的新增长期模块。玩家升级房车内的五种设备，使其持续生产基础资源，并通过定期领取、工作台合成和储藏架载货量提升形成房车日常经营循环。

### 1.2 目标

1. 为房车提供独立于房车本体整备和出行指南的持续养成线。
2. 通过金币、玩家经验、体力、邮票精力和加工零件补充基础资源，但不取代原有稳定供给玩法。
3. 通过房车建材形成设备升级消耗；每个目标等级只消耗一种品质，低/中/高级按等级阶段切换。
4. 通过储藏架连接跑商，通过工作台连接基础经验材料制作及成长材料向上合成。
5. 允许玩家自由选择设备升级顺序，不设置房车本体等级门槛。

### 1.3 非目标

- 本文结论同步至 `06_最终配置` 评审镜像；不修改 Vgame SVN 真实配置。
- 房车建材沿用正式ItemId 3028/3029/3030；策划称呼为低/中/高级舱室建材。
- 本文不确定房车建材的正式产出玩法和日均投放量。
- 本文不开放高级经验材料、专武突破材料、抽卡资源或房车零件的工作台合成；角色升阶、能效与房车舱室材料仅允许同系向上合成。
- 本文暂不处理产出小数、取整和显示精度规则。

## 3. 玩家循环

```text
获取房车建材
  -> 自由选择设备并升级
  -> 设备连续生产资源
  -> 定期领取 / 一键领取
  -> 工作台把加工零件合成为基础经验材料，并将多余成长材料同系向上合成
  -> 储藏架提高跑商单次载货量
  -> 继续参与成长与跑商玩法
```

## 4. 核心规则

### RV-EQ-R01：设备等级

- 五个设备分别独立养成，等级上限均为10级。
- 设备升级不受房车本体等级限制。
- 玩家可集中升级单一设备，也可平均升级全部设备。
- 当前设备升级只消耗房车建材，不消耗房车零件。
- 每个目标等级只允许配置一种房车建材；Lv2-Lv4使用低级、Lv5-Lv7使用中级、Lv8-Lv10使用高级。
- 房车建材不足时不能升级；不扣除部分材料。

### RV-EQ-R02：持续生产与领取

- 五个设备均按时间连续生产。
- 表内“日产量”表示持续生产24小时的理论产量，不表示每日刷新时一次发放。
- 达到最大累积时长后停止继续累积，领取后恢复生产。
- 一键领取按各设备当前实际累积数量一次性发放。
- 体力和邮票精力的一次性领取允许突破持有上限；超过上限后，对应自然恢复暂停，直到持有量重新低于上限。
- 本期暂不确定小数产出和领取取整规则。

### RV-EQ-R03：工作台合成

- 工作台生产加工零件，加工零件用于合成基础经验类材料。
- 工作台同时开放能效材料、角色升阶材料和房车舱室材料的同系向上合成。
- 所有配方随工作台开放，不设置配方等级限制。
- 支持批量合成，不额外消耗金币，不设置每日合成次数上限。
- 能效材料必须保持相同职业与相同材料线，普通/稀有/史诗依次以`2合1`升至下一档。
- 角色升阶材料必须保持攻击/防御/辅助职业类型，低阶与中阶依次以`3合1`升至下一档。
- 房车舱室材料按简式设备图纸→精校设备图纸→星旅设备图纸，以`3合1`向上合成。
- 只允许向上合成，不开放向下分解；不允许跨职业、跨材料线混合，自选箱不参与合成。
- 工作台不合成高级经验材料、专武突破材料、体力、邮票精力、抽卡资源或房车零件。

### RV-EQ-R04：储藏架与跑商

- 储藏架同时提供持续金币产出和跑商单次载货量提升。
- 储藏架不增加跑商商店每日货物供给量。
- 每件跑商商品占用1点载货量。
- 跑商订单发车过程中升级储藏架，新载货量从下一次发车开始生效。
- 满级载货量由30提高至36；按当前跑商方案，目标是将全周期利润效率提高约9%～11%，将正常毕业时间由约89天下调至约81天。

### RV-EQ-R05：驾驶台满级转化

- 玩家未达到等级上限时，驾驶台产出直接增加玩家经验。
- 玩家达到等级上限后，驾驶台后续产出进入溢出经验池，不重复增加玩家经验。
- 溢出经验用于兑换基础补充资源，规则见第8节。

## 7. 工作台合成配方

加工零件当前统一按约40个=`1钻石价值`核算，仅作为数值定价基准。

### 7.1 加工零件配方

| 配方 | 产出ItemId | 加工零件消耗 | 产出 |
|---|---:|---:|---|
| 低阶记录盘 | 100 | 20 | 1个；提供500角色经验 |
| 中阶记录盘 | 101 | 80 | 1个；提供2,000角色经验 |
| 泛黄档案 | 108 | 20 | 1个；提供1,000专武经验 |

满级工作台日产624加工零件：

- 全部制作低级经验材料时，最多可制作31份并剩余4个加工零件。
- 全部制作邮票经验时，可获得1,500点邮票经验并剩余24个加工零件；按长期平均价值折算约为1,560点/天。
- 一张传说旅券从零升满需要40,000旅券经验，满级工作台按长期平均约26天补足一张的升级经验。

### 7.2 向上合成通用规则

- 合成仅消耗同系低档材料，不额外消耗金币，不设置配方等级或每日次数限制。
- 支持批量合成；自选箱不作为输入或输出。
- 只允许向上合成，不提供逆向分解或跨职业、跨材料线兑换。
- `DeviceCraft.xlsx`使用产出ItemId作为`CraftId`；现有Schema默认每次产出1个目标道具。
- 配方按页签区分：1基础材料、2能效、3角色升阶、4舱室材料。

## 11. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 设备无房车等级门槛后单线速升 | 玩家可能过早取得80体力或36载货量 | 通过高品质建材投放节奏、升级成本和来源开放节奏形成软门槛 |
| 金币持续增发 | 降低其他金币玩法价值并削弱金币消耗压力 | 并入全局金币产销，重点验证30/60/90日累计净增量 |
| 体力持续增发 | 放大资源副本全部产出 | 按完整体力价值而非单一体力数验算 |
| 邮票精力持续增发 | 加快旅券副本与旅券养成 | 与96点/天自然恢复基线合并核算 |
| 工作台挤压经验副本 | 基础经验材料来源过多 | 只开放低、中级经验材料，并以约15.6钻/天作为Lv.10产值上限 |
| 能效连续向上合成损耗较高 | 玩家可能误以为合成等值 | UI明确展示输入/产出数量并二次确认；保留直接高档投放的价值优势 |
| 低档材料可转高档 | 后期材料缺口被提前填补 | 仅同系向上合成且不可逆；通过2合1/3合1控制转换效率 |
| 载货量使跑商提前毕业 | 跑商等级周期过短 | 满级只到36，并按设备真实成长天数复算89天基线 |
| 多设备离线结算不一致 | 玩家领取量错误或跨日异常 | 服务端统一使用时间戳结算并增加跨日、满仓、回拨测试 |
